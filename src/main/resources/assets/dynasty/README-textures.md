Place your PNG textures from the Desktop into these paths inside the mod project resources.

- `pujingprotect.png` -> `src/main/resources/assets/examplemod/textures/item/pujingprotect.png`
- `jingweiprotect.png` -> `src/main/resources/assets/examplemod/textures/item/jingweiprotect.png`
- `zgprotect.png` -> `src/main/resources/assets/examplemod/textures/item/zgprotect.png`

For the armor worn texture (model layers), copy `zgprotect.png` to both:

- `src/main/resources/assets/examplemod/textures/models/armor/renminbi_layer_1.png`
- `src/main/resources/assets/examplemod/textures/models/armor/renminbi_layer_2.png`

After copying the files, run your Gradle build or start the client to see the textures.
