# 六阶段自然生存验收：首条开局路线计划

本轮先从新私有世界真实空手开局。固定种子20261023，不挑种子、不用旧档；正常难度、默认游戏规则、无作弊、无奖励箱。QA只驱动客户端输入和读取证据，不发物品、不补任务、不传送、不改天气/时间/血饥饿、不生成靶怪或矿物。

选定路线是树木→木板/木棍→木矛→工作台/木镐→自然圆石→原配方消耗木矛制作石戈，再继续熔炉/铜铁。先制作武器不等于完成原主线：当前木矛任务依赖铁镐/水桶等前置，保留真实顺序并记录被锁状态。布衣胸甲需8丝绸，即72根线；全套216根线，不能默认开局已有布衣。玉料/竹甲过渡另需自然玉矿、铁工具、竹子和前驱布衣，不能把木矛换石戈时间偷换成该2–3小时目标。

阶段S0记录出生位置、原生赠送说明书和根任务；S1步行砍树并实际拾取、合成木矛；S2放置工作台、制作木镐采石、实扣旧木矛升级；S3自然木炭/火把/箱子/熔炉与原任务提交；S4自然采铜铁、烧炼、补食物照明和武器升级；S5来源齐备后才能衡量布衣/竹甲/玉料过渡。未达段明确保留缺口。原六阶段15分段的QA材料结果只作历史接口证据，六阶段自然流程不因此通过。

每个输入与事件记录UTC、单调墙钟、服务器tick、位置、背包前后、配方/掉落/任务变化。主动移动/采集/制作、界面操作、检查、闲置和暂停分别统计；不空等凑时长，不额外要求真人。原生登录赠物与真实任务奖励允许，但标记为生产来源；任何非原有QA赠物为0。

不重做Rawls生态生成率/分布实验，只记录这条路线偶遇的自然生物及掉落。生产Java/资源/任务/配方不改；任何未来正式修复先另行对应1000实现研究。现有任务参考只读复用。完整当前1259节点前置、配方成本、六阶段范围、证据字段和研究适用性在同目录plan.json；现主表只读，不复用旧表哈希冒称当前一致。
