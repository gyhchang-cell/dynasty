# 旧 Forge 方案归档（已撤回）

此方案已按用户要求从实际游戏目录撤回，不再作为交付方案。现在使用主助手的 1.7 外置 F3 方案。以下仅保留旧实现的说明。

这是现有外置连点助手的独立配套模组，不向游戏注入本机进程，也不要求服务端安装。
它直接读取当前游戏中的灵敏度、键位、位置、朝向、手持方块及落地状态；不依赖鼠标 DPI 或屏幕像素换算。
角度按当前灵敏度的角步长量化，每刻重新读取灵敏度。

## 当前交付状态

- 已编译为 Java 8 字节码，针对 Forge 1.8.9-11.15.1.2318。
- 已通过 600 次模拟起跳／落地周期、停止条件、5 种灵敏度共 7205 次角度检查和反射辅助层测试。
- **尚未游戏实测。不能把这些测试当作连续搭桥成功的证据。**
- 按实际落地恢复下一次起跳，空中转身后搜索可见的方块水平侧面，通过原版右键入口放置；不是只按定时器循环跳跃。
- 功能不能保证防掉落或服务器接受放置，也没有防检测保证。

## 用法

1. 在启动器中选择新增的 `1.8.9-TellyForge`，完全重启游戏进入这个版本。
2. 先在单人创造模式的平坦边缘测试。需要普通完整方块（如羊毛、石头），不支持半砖、台阶、水面、药水移动效果或斜向路径。
3. 手持方块，站在方块边缘，朝正东／南／西／北中的搭桥方向，准星方向与正方向相差不超过 8°。不用自己摆放回头的俯视角。
4. **按住 V 开始，松开 V 停止。** 不用按住鼠标；不需要开启外置助手。
5. V 期间不要同时按移动键或手动改变视角。手动移动、打开菜单、切出游戏、死亡、换世界、无完整方块、偏离路径或超时均停止本次搭桥；松开 V 后才能重新开始。

松开或停止会恢复移动键的实际硬件状态。不会自动换物品栏，不会自动寻找起跳点，也不能从已经落空的位置恢复。
本地提示仅显示在自己的 HUD，不发送服务器聊天。

外置助手的连点开关、Esc、重生／换世界状态保持逻辑不受此模组控制。搭桥的停止状态单独处理。
搭桥使用游戏的逐刻放置入口，不更改外置助手已设定的 CPS 或节奏。

## 构建

设置 `TELLY_FORGE_JAR` 为本机 Forge 1.8.9 jar 路径，然后执行 `bash build.sh`。
构建需要支持 `--release 8` 的 JDK；产物无需重新映射，因为游戏类访问使用 Forge 的 SRG 反射名，并提供 MCP 开发别名。
SRG 名称核对自 Forge Maven 的 `de.oceanlabs.mcp:mcp_stable:22-1.8.9`。
运行时无源码下载、网络请求、聊天传输、外部命令或反作弊绕过代码。

## 卸载

删除当前游戏目录 `mods/1.8.9/mcmacro-telly-1.8.9-0.1.0.jar` 即可卸载。
启动原版 `1.8.9` 不会加载这个 Forge 模组。
