## 修复范围

- 删除 `SwordRightInput`、`releaseUse`、自动右键松开及其超时重试逻辑。
- 剑斗事件处理遇到右键按下、松开、拖动立即返回透传，不更改类型、按钮号、坐标或修饰键，不关闭开关。不再把右拖拽改成鼠标移动；仅观察其时间以防用过期瞄准快照攻击。

- 单独 `rightDown=true` 不影响自动左键。真正 `using=true` 时不取消原生使用，也不发送游戏会消耗的左键；开关保持开启，待更晚游戏刻确认原生使用结束后自动恢复，不需再次点击开关。
- 使用开始时清理待确认攻击状态，避免被原生使用消耗的点击在 0.45 秒后错误关闭剑斗。支持非鼠标右键的使用键绑定，不猜测或修改它。
- 持物识别、现代读数断流恢复、目标/距离/冷却/菜单/失焦保护保持。重生锚及搭路本身的独立输入策略未改；此次“右键原生”指剑斗不再接管，不代表关闭其他功能。
