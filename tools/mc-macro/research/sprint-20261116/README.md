# 跨版本自动疾跑候选 — 2026-11-16

目标：界面与 Control 独立控制强制疾跑，和连点、主手物品无关。读取当前客户端实际的疾跑逻辑开关，恢复被菜单、死亡/换世界或其他输入清除的按键请求。

## 变化与依据

- 原通用路径依赖版本判定，完整读数仅支持 26.1；旧版还存在连点启动时另一条疾跑写入路径。两条写入路径会争用输入所有权。
- 26.1 保留完整状态读数；其他 Java 客户端新增独立 Java 8 只读组件。根据 `key.sprint` 注册表与字段结构寻找绑定，不硬编码混淆名称。
- LWJGL2 读取 Mouse.isGrabbed；LWJGL3 通过游戏执行器读取 GLFW 光标捕获状态。未识别、读数过期或菜单中暂停，不进行盲目 toggle。
- 按住模式只在逻辑状态丢失后恢复；切换模式等待逻辑开关确认，不因站立或未实际奔跑而反复切换。
- 菜单返回后重新读本实例 options.txt，等待读数和捕获稳定；丢弃失焦实例的异步配置结果。连点启动也使用统一控制器。
- 强制疾跑开启时，剑斗控制器不为可选暴击主动释放 W。保留手动瞄准和其他攻击条件。
- 通用路径仅证明“疾跑请求保持”，不以逻辑键按下冒充实际运动中疾跑。

## 检查与交付范围

执行 `python3 research/sprint-20261116/validate.py`。测试日志位于 `.build/candidates/sprint-20261116/`；签名、可执行文件及源码哈希在 `build-receipt.json`。
