## 打开与授权

1. 打开 `dist/mcPvPmax.app`，也可把它复制到“应用程序”文件夹后再打开。尽量在固定位置使用，便于系统保留权限。
2. 点击“检查并申请权限”，在系统设置 → 隐私与安全性中，为本应用开启“辅助功能”和“输入监控”。系统权限需由你亲自授予。
3. 回到程序再次检查权限；若监听仍未连接，完全退出程序后重新打开。
4. 启动 Minecraft 并进入游戏。默认自动识别游戏进程；无法识别自定义客户端时，在下拉框里手动绑定它的 Java 游戏进程。不要绑定启动器或其他 Java 程序。手动绑定仅对当前进程有效，游戏重启后需重选。

## 操作

- 在游戏前台按数字 1 左侧的反引号键 ` 开启，再按一次关闭。可在程序里修改开关键，按键位置不依赖输入法。
- 开启后按住左键就连点左键，按住右键就连点右键，同时按住可双键同时连点；松开哪一键就停止哪一键，不影响另一键。每次重新启用后需重新按下鼠标键。左右键分别使用相同的 CPS 范围（默认各 15–20 CPS，并非两键合计）。
- 默认 CPS 为 15–20，可输入 1–40 之间的上下限并保存；设为相同值即固定 CPS。区间模式使用缓慢变化的目标速度叠加小幅局部变化，左右键各自独立；每个计划间隔严格在 CPS 上下限对应的范围内，不加停顿，按下时长也在该周期内变化。相同上下限仍保持固定点击间隔。系统调度延迟不会用补发点击突发追赶。短时间计数可能因计数窗口和系统调度出现波动，不承诺每个自然秒都恰好落在范围内。
- 勾选“启用时保持疾跑”后，程序仅在已启用且游戏处于前台时保持疾跑键；无需按住左键也会保持疾跑。取消勾选即可只使用连点。
- 默认疾跑键为左 Control。若遇到 Control + 左键被当作右键，改选 R，并在 Minecraft 控制设置里把疾跑键同步改为 R。若版本提供疾跑“切换／按住”选项，请设为“按住”。
- 总开关开启后持续保持就绪，没有运行时长限制。松开鼠标只停止对应键的点击。切出游戏、锁屏、睡眠或监听中断时暂停输入并释放疾跑键，总开关保留；回到游戏恢复就绪，再次真实按住鼠标才连点。再次按开关键、点“立即停止”或退出助手才手动关闭。Esc 不再关闭功能；切换世界和死亡重生保留总开关，加载后按硬件实际按住状态继续工作。
- 普通连点不因 Esc、T、/、E 改变总开关状态。启用下方搭路功能时，R、T 和聊天输入另按搭路规则处理。游戏内菜单同样遵循“按住才连点”，需要单次点击菜单时可先用开关键关闭助手。Esc 仅在助手的快捷键录制界面用于取消录制。
- 菜单栏“MC ○ / MC ●”表示关闭／开启。关闭设置窗口后程序仍在菜单栏，可选“退出”彻底关闭。

## Speed Telly 1.8.4（平桥／升高双模式）

桌面 `MC连点助手.app` 与 `dist` 为 1.8.4（build 14）。支持原版 Java 1.8.9，无需 Forge 或服务器组件。已授权的辅助功能、输入监控不重复显示申请按钮；主流程不要求 F3 或屏幕录制。普通 CPS 配置保留为 15–18，搭路点击上限 18。

1. 手持完整方块，关闭创造飞行，站在有完整方块支撑、可助跑的位置，朝需要搭路的方向。
2. **T 切换模式**，也可在设置中选择。平桥保持桥面高度；Speed Telly 首段平搭，后续每跳升高一格。模式保存到本机，搭路中切换在下一跳生效，空中不会改变本跳目标高度。长按 T 的重复事件不会连续切换。
3. **按住 R 持续搭路**：先读取状态、校准鼠标和调整起点，再沿桥线助跑、起跳、转身放块、回正。无需开启普通连点总开关。R 的重复事件不会启动多个任务。
4. **起跳后松开 R，完成本跳、落地回正并消退惯性后停止。** 后续循环助跑中松开也会潜行制动后收尾；首次起跳之前松开则取消。收尾中重新按 R 可继续。切出游戏、手动接管、点“立即停止”、切换世界或读数失效仍立即释放输入。
5. 搭路期间暂停普通连点和自动疾跑，结束后保留原有总开关状态。R、T 不可与移动、跳跃、潜行、疾跑等必要键位冲突。启用搭路功能时 T 被用于切换模式；聊天使用 `/` 打开后删除斜杠，聊天期间不切换模式。

首段目标是向前延伸 **4 个新方块位置**，不是声称玩家中心单次位移恰好达到 4 格。平桥后续以 3–4 格为目标，升高模式正常以 3 格为主，时间不足时允许单独一轮 2 格调整。不会为凑数在失去落点后强补点击。平桥每轮靠近已确认桥面前缘再起跳；升高切回平桥时，先落地回正，重新留出助跑距离，避免从低速悬边直接起跳。

灵敏度和键位来自当前实例 options.txt，并通过实际相对鼠标移动校准。固定向左回头、向右回正。转向重定目标时保持位置和速度连续；放块期间连续跟踪目标面，允许准星经过有效放置区时点击，不必锁定面中心。去掉落地前突然提高追踪强度的做法；保留连续的小数角度和运动速度，减少分段停顿与末尾补大角。未添加随机抖动。

放块需要实际命中面、已发送角度、点击间隔、方块确认和剩余空中时间共同满足。未被游戏消费的原生点击按点击上限重试，不等待长超时；每跳格数以实际观察到的新方块计算，不以右键次数计算。输入事件保留控制器持有的修饰键，避免鼠标事件清空 Control 导致疾跑丢失。

只读 Java 组件读取坐标、速度、落地和附近方块，不转换游戏类、不修改玩家字段，也不调用放块或移动 API。动作由 macOS 原生键鼠事件执行。读数通过带随机会话令牌的本机回环 UDP 传输；停止连接后终止读取，重启游戏卸载组件。需要本机 JDK 9 以上的 Attach 工具；本机使用 JDK 21 连接 Java 8 游戏。

## 实现和边界

普通连点使用独立编写的 AppKit / Core Graphics 实现；Speed Telly 另有上述本地只读组件。1.2 版本通过 IOHIDManager 读取物理鼠标按钮，每次连点前检查硬件仍处于按住状态；Quartz 点击事件不能启用或维持连点。读取不到鼠标硬件时保持关闭，不退回自动连点。程序同时为自身生成的输入打标记并检查来源进程。

游戏识别仅在本机读取候选进程的命令行，不上传、写日志或保存命令行。CPS 与开关键、疾跑设置保存在本机用户偏好中。自动识别覆盖常见原版、Forge、Fabric 和部分 Lunar 启动入口，自定义客户端可手动绑定。

1.3 版本为左 Control 补齐通用和左侧专用修饰键标记，兼容 LWJGL 2 的 flagsChanged 处理。1.5 版本改为每约 0.9 秒通过一次短暂松开（至少 75 毫秒）再按下，重新触发疾跑，避免世界切换、重生等清空游戏按键状态后重复按下被忽略；恢复由前台看门狗持续驱动，不依赖重新开关。疾跑不依赖鼠标按住，也不因鼠标硬件暂时无法读取而禁用；鼠标连点仍必须经过硬件按住检查。依据： https://github.com/LWJGL/lwjgl/blob/master/src/native/macosx/org_lwjgl_opengl_Display.m （flagsChanged 对 kVK_Control 使用 NSControlLeftKeyMask）。

“保持疾跑”是保持按键输入，不能覆盖游戏或服务器决定的疾跑限制。系统合成输入能否被特定客户端接受，需要在实际客户端验证。

应用采用本地临时签名，未做 Apple Developer ID 签名与公证。安装包不包含外部运行时；普通连点不需要 Python、Node.js 或 Java，Speed Telly 需要本机 JDK。
