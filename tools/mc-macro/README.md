# MC 连点助手

独立 macOS 应用，界面为简体中文。当前安装包适用于 Apple Silicon（M1/M2/M3/M4 等），macOS 13 或更新版本。

## 打开与授权

1. 打开 `dist/MC连点助手.app`，也可把它复制到“应用程序”文件夹后再打开。尽量在固定位置使用，便于系统保留权限。
2. 点击“检查并申请权限”，在系统设置 → 隐私与安全性中，为本应用开启“辅助功能”和“输入监控”。系统权限需由你亲自授予。
3. 回到程序再次检查权限；若监听仍未连接，完全退出程序后重新打开。
4. 启动 Minecraft 并进入游戏。默认自动识别游戏进程；无法识别自定义客户端时，在下拉框里手动绑定它的 Java 游戏进程。不要绑定启动器或其他 Java 程序。手动绑定仅对当前进程有效，游戏重启后需重选。

## 操作

- 在游戏前台按数字 1 左侧的反引号键 ` 开启，再按一次关闭。可在程序里修改开关键，按键位置不依赖输入法。
- 开启后按住左键就连点左键，按住右键就连点右键，同时按住可双键同时连点；松开哪一键就停止哪一键，不影响另一键。每次重新启用后需重新按下鼠标键。左右键分别使用相同的 CPS 范围（默认各 15–20 CPS，并非两键合计）。
- 默认 CPS 为 15–20，可输入 1–40 之间的上下限并保存；设为相同值即固定 CPS。区间模式会在每个周期选取目标速度，短时间计数可能因计数窗口和系统调度出现波动，不承诺每个自然秒都恰好落在范围内。
- 勾选“启用时保持疾跑”后，程序仅在已启用且游戏处于前台时保持疾跑键；无需按住左键也会保持疾跑。取消勾选即可只使用连点。
- 默认疾跑键为左 Control。若遇到 Control + 左键被当作右键，改选 R，并在 Minecraft 控制设置里把疾跑键同步改为 R。若版本提供疾跑“切换／按住”选项，请设为“按住”。
- 切到其他程序、锁屏、睡眠、游戏退出、输入监听中断、退出助手时，程序会停止连点并释放自己按下的疾跑键。返回游戏后需重新按开关键，不会自动恢复。
- Esc 紧急停止；T、/、E 会关闭宏并让原按键继续传给游戏。关闭聊天／背包后需重新开启。若你修改了游戏聊天、背包键，或通过其他方式打开菜单，助手无法自动读取游戏界面，请先手动停用。
- 菜单栏“MC ○ / MC ●”表示关闭／开启。关闭设置窗口后程序仍在菜单栏，可选“退出”彻底关闭。

## 实现和边界

独立编写的 AppKit / Core Graphics 实现，不向游戏安装模组。1.2 版本通过 IOHIDManager 读取物理鼠标按钮，每次连点前检查硬件仍处于按住状态；Quartz 点击事件不能启用或维持连点。读取不到鼠标硬件时保持关闭，不退回自动连点。程序同时为自身生成的输入打标记并检查来源进程。

游戏识别仅在本机读取候选进程的命令行，不上传、写日志或保存命令行。CPS 与开关键、疾跑设置保存在本机用户偏好中。自动识别覆盖常见原版、Forge、Fabric 和部分 Lunar 启动入口，自定义客户端可手动绑定。

“保持疾跑”是保持按键输入，不能覆盖游戏或服务器决定的疾跑限制。系统合成输入能否被特定客户端接受，需要在实际客户端验证。

应用采用本地临时签名，未做 Apple Developer ID 签名与公证。安装包不包含外部运行时，不需要安装 Python、Node.js 或 Java 来运行助手。

## 构建与验证

执行 `bash build.sh` 生成 `.app` 和 ZIP。需要 Apple Command Line Tools。脚本在此机器的 Swift 6.1 上使用已有的 macOS 15.5 SDK；若 SDK 缺少 MacErrors.h，使用项目内 VFS 覆盖补齐，校验 SHA-256，不修改系统 SDK。兼容头文件来自公开 SDK 镜像：

https://github.com/phracker/MacOSX-SDKs/blob/master/MacOSX11.3.sdk/System/Library/Frameworks/CoreServices.framework/Versions/A/Frameworks/CarbonCore.framework/Versions/A/Headers/MacErrors.h

已通过：源代码编译、输入策略测试（关闭、失焦、松手、停止、非法 CPS、游戏与启动器区分）、应用包配置和签名校验、应用启动及中文界面布局、界面拒绝错误区间和保存默认设置。

交付时尚未授予系统输入权限，也没有运行中的 Minecraft；游戏内实际 CPS、疾跑、Control 点击兼容性、切出游戏释放行为尚未实测。
