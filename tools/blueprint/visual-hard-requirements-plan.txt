物理输入和初值：
  每实体/维度独立状态；固定 dt=0.05s，每客户端 tick 最多推进一次。
  输入为实体局部速度/加速度、bodyYaw 角速度，以及上臂/前臂锚点运动。

  旋转目标由加速度反方向和重力投影产生；不是仅用 sin(tickCount) 冒充惯性。
  初调：近段 k=80 s^-2、damping=14 s^-1，远段 k=55、damping=11。
  近段 pitch/roll 限幅 10°，远段 18°；响应按两链各自父段传递。
  采用固定步半隐式积分，超时最多补4步；暂停不积时、传送/换维度重置。
  远段延迟/超调由状态积分产生，不用固定相位动画代替。
  死亡一开始程序偏移归零，既有空袍死亡 clip 全权接管，不能又把袖子拉回手臂。

五、山魈：由真实壁面法向驱动的贴壁四足姿态与爪接触

当前已确认：服务端同步CLIMBING布尔并设置向上速度；客户端仅选择run。
没有壁面法向、视觉root贴壁变换或爪端接触约束。单写固定-65° pitch不能补齐。

A. 窄小而明确的服务端状态扩展（解除冻结后需主代理协调，不可客户端猜伤害）

新增可跟踪同步的 climb face/anchor 状态，而非每tick广播粒子或整份NBT：
  climbFace: BYTE，0无效，1..4为N/S/E/W实际BlockHitResult侧面。
  climbSurface: BlockPos，可选接触点局部坐标量化；仅入墙/换面/脱离时dirty同步。
  climbEpoch: long，开始贴壁的server gameTime，用于观察者一致的步态相位。
体积仅接近自身AABB扩张0.25的墙面；每4tick或碰撞方向变化时重采样。
分别从胸与前爪高度向速度/目标平面方向短raycast；ClipContext.Block.COLLIDER，
Fluid.NONE；拒绝Y轴面、空碰撞shape、超出可触及范围的命中。
优先保留上一有效壁面，只有新面明显更近或旧面失效才换，避免墙角左右抖动。
水平碰撞本身不是法向；不能用玩家方向直接代替wall normal。
死亡、跳扑脱离、失去可碰撞壁面、换维度时清掉face/anchor；当前死亡onClimbable
保护必须保留。客户端只消费该状态画姿态，不自行启动攀爬/投石/伤害。

B. 根姿态的可验证坐标构造

N = 实际侧面向外法向（由同步Direction得出）；F = 世界向上切向(0,1,0)。
R = normalize(F × N)。目标墙面局部坐标基为 [R, N, -F]：
  模型 +X -> R，+Y背部外侧 -> N，-Z面朝前 -> F（沿墙向上）。
先抵消renderer已有entity/bodyYaw变换：Qlocal = inverse(Qentity) * Qwall。
不能同时又改entityYaw再重复乘一次墙面yaw。四个朝向都用同一个构造验证。
以实体pos+(0,0.5,0)投影到真实壁面，得到视觉model origin；加N*0.02block安全间隙。
实体服务端位置/碰撞箱不动。视觉平移限定≤0.75block，否则放弃接触并平滑退出。
从地面到墙面用6tick shortest-path quaternion slerp；转角先释放摆动腿再换面。
若视图根pitch数值正确但爪伸进墙，仍不算通过，必须验证世界接触点。

  后：thigh -> knee -> shin -> ankle -> foot -> foot_contact(new empty)
