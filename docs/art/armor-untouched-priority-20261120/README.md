# 盔甲优先级复核与 Summer Love 穿戴参考

当前目标索引覆盖 7 套四槽共 28 件。逐件核验运行源图标、物品模型和对应穿戴图的哈希，并把 14 张现有穿戴图与项目内保存的 v15 重画稿逐张比对。结果为 16 件图标有 v25/v29 获选原稿，布衣、皮甲、鲛绡的 12 件图标有 v15 重画版本。14 张穿戴图与 v15 重画稿一致。此范围没有确认从未改过的目标。这一结论针对现有目标索引，不能外推到 Dynasty 的所有盔甲或当前玩家客户端。

优先级只适用于随后核实了授权和参考门槛的穿戴 UV 修复。第一是锦衣，袖片底盖和侧边像素断开，同时有深紫米白交领与穿戴紫褐金线不一致的问题。第二组是布衣、皮甲、鲛绡、竹甲，共有同一处袖口断开，组内先处理布衣作为最朴素的基准。第三组是朱砂和鸿蒙，已有材质对照差异，动笔前先核实哪些差异来自设计意图和哪些来自穿戴贴图。排序不改变库存图标的保护状态。

锦衣和布衣可查 Eidolon 术士袍的深浅衣襟与袖口。皮甲可查暮林巨魔皮甲、漫游者皮甲的材料边界。竹甲可查已经独立验收的 Roots Wildwood/Sylvan 的横节和绑带，结合本项目原有竹材风格。鲛绡可查现有 Aquamirae 穿戴的冷色材质分区。朱砂、鸿蒙后续以获选图标自身材质为准。上述关联用于具体判断，学习组和换色不能加成正式参考数。

新看完 WizardsReborn Summer Love 的头花、裙装、双靴三张图标及普通臂、细臂穿戴图。图标在浅蓝底布上用冷白横带和较深的下边缘区分衣襟、裙摆与鞋底，袖部轮廓仍保持方块人的肩臂比例。穿戴声明映射 HEAD、CHEST、FEET 三槽，沿用 Magnificent Maid 的裙摆附着规则，胸槽带左右裙摆。库存无裤子皮肤映射。普通臂和细臂按同一设计；它与 Magnificent Maid 共用几何，局部图案及透明区不同，先归为同一服装家族，新增独立信用为零。可参考其胸袖与下摆的区分方式，不能把这套 128×64 专用图集当成 Dynasty 的 64×32 图集，也未实测穿戴画面。

参考门槛依旧未通过。当前保存的是目标优先级、已验证的维修证据和新的离线参考，未开始生产贴图。
