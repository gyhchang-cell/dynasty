# 仅金合欢活板门 → 红树木展示架外观

本机个人资源适配。直接使用已安装 Minecraft 26.2 中的原版红树木展示架图像与几何，不使用 AI 重绘此纹理。

已放到 `Dynasty 王朝/resourcepacks/Dynasty-Acacia-Mangrove-Shelf.zip`。
在正在玩的实例里：选项 → 资源包 → 启用 Dynasty-Acacia-Mangrove-Shelf → 完成。资源重载后生效，无需重建或重开世界。当前系统未允许自动控制 Java 游戏窗口，因此尚未代为启用。

范围仅 5 个包内文件：元数据、私有命名贴图、私有命名模型、金合欢活板门物品模型、金合欢活板门方块状态。覆盖全部 16 组朝向/开合/上下半部外观。水浸、红石、方块 ID、配方、碰撞和交互仍是原版金合欢活板门；不是移植带物品存储功能的展示架。外观突出部分较碰撞薄板厚 2 像素。

它是实例级资源包，因此该实例各存档都能显示，但没有编辑任何存档，也没有同步上一批贴图/盔甲/功能方块。移除资源包即可还原。
