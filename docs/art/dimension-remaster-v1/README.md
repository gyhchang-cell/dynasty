# 人物修正与维度建筑重绘

## 人物

龙帝、九霄天将、玉甲卫、冥卒的头部 UV：西侧水平反向映射，使两侧耳朵均靠近面部；后脑使用独立头盔/头发区域，不再复用侧耳。原美术未重新生成，仅修正模型所需的映射。

关羽：恢复上轮误删的靠近脸部的上段刀杆和尖头，仅删除刀头/红缨下方余杆，并缩短连接套筒。保留原握持轴、手指、刀刃、浮雕与红缨。清障体积同步调整。几何交叉检查通过，不能据此承诺所有实战动作绝不穿模。

## 方块

王朝命名空间现有22张方块纹理全部分别重绘，接入128×128版本：3种矿石、玉块、青铜块、宫砖、汉白玉、朱红柱两面、宫灯、龙椅、祭坛、召唤祭坛、编钟、太鼓、香炉、屏风、匾额、4种传送门。

使用内置 imagegen，非网上下载素材。原稿在 sources/；[提示词记录](prompts.md)。PackRemasterAssets 的 block 模式仅做尺寸与不透明 RGB 格式适配，保持生成图内容。before/block/ 保存旧纹理，after/block/ 保存最终纹理。未覆盖 Minecraft 或其他模组的方块贴图，也未把原版地形材料注册成新方块。

## 建筑

- 共用建筑工具：四面屋瓦按屋脊方向排列，硬山顶南北坡向分开，灯笼收敛到首层檐角，减少逐层堆灯。
- 主殿：琉璃重檐、外柱廊、格窗、柱头、檐灯与入口台阶。
- 书院：讲堂和两侧厢房的琉璃瓦顶，降低院墙并增加门柱灯，打开讲堂和厢房入口，补对称格窗。
- 长城关隘：城楼和两侧角楼替换为有坡向的瓦顶。

未改变建筑生成频率、维度注册、传送逻辑和战利品配置。布局修改仅作用于以后新生成的建筑；既有方块可直接显示新纹理，不强行改造旧存档。不是把所有建筑逐栋重做；本轮针对共用构件及上述重点建筑。
