# 白虹贯日·祥云献瑞

cod3 奇观 #21。原三条细弧线替换为穿过原版太阳的阶梯白虹、上下开口的淡金白虹弧、四组带镂空卷头的如意云。四种硬边颜色，77 个四边形，低于目录预算 80；不使用平滑圆环、模糊贴图、屏幕滤镜或服务器视觉实体。

## 参考

制作前实际查看 100 张 [Skyrim 白天及天气对照截图](https://stepmodifications.org/wiki/SkyrimSE:Weather_Compares)，来源作者为 TechAngel85 和 z929669。五张二十图联系表已逐张查看：001–020 检查晴空与山地对比，021–040 检查云层和地景留白，041–060 比较晴天/厚云遮挡，061–080 检查浅色云的边界，081–100 比较雪地、荒野和雾中辨识度。它们是同一游戏的 100 张不同捕获，不是 100 款游戏，也未声称看过动画视频。

参考图、下载脚本及联系表仅在 `build/cod3-sun-halo-20261018/references`；`references.json` 保留来源、尺寸与 100 个不同文件哈希。只提取天空构图、疏密及明暗对比，没有复制图像像素。方块阶梯、云头和云尾均由本项目代码原创构造。

## 实际接入

`ScenicEventDefinition.of(21)` → `ScenicEvents` → `Cod3VisualPacket` → `Cod3VfxRenderer` → `ScenicSkyRenderer.drawSun` → `ScenicSunHalo.mesh`。

沿用真实主世界、正午 5500–6500 tick、晴天触发，以及 600 tick 寿命。天空可见性保留到一轮事件能自然结束，并在离开白昼窗口或下雨时渐隐。区域与种子、起始时钟仍由服务端保存；光学天象依据原版太阳角度投影，各观察者不会因为站在不同位置而看到白虹偏离太阳。它没有跟随准星，转头可离开视野，世界实体深度测试仍生效。

与极光和流星共用距离/寿命淡出、透明面排序、近面保护、已有重复包合并和退出清理。太阳天象单独定义白昼可见性和造型，不改变两种夜景的时段。目录要求单档 LOD，近、中、远及 MINIMAL 均保留 77 面轮廓，不增加粒子。云纹按服务器年龄和种子缓慢移动，重进观察范围不重启动画。

本项是代码生成的环境天象，不是生物模型或物品图标，因此无需伪造 geo.json、骨架动画或纹理 PNG。`ScenicSunHalo.java` 即可编辑源及正式生成器；预览入口也调用同一几何。没有修改战斗、任务、奖励、季节或自然触发概率。

## 检查

`SunHaloGeometryQa.java` 直接采样正式几何 1,525 帧，核对预算、边界、四边形透明度、相同种子/时钟、太阳对齐、天气和距离衰减。既有极光和流星共 4,550 帧回归通过。联合九项专用服测试通过，覆盖实际包编解码、保存恢复、迟到观察者和过期清理。

`solar-frame.png` 与 `motion.webp` 是正式几何的软件投影，不是游戏截图；动图是加速采样。原生客户端 17 个场景、34 次开关对照截图已通过并人工复查，包含四方向、近远/MINIMAL、夜晚/雨天、重载、迟到观察、近面、太阳前后时段、转头、离开范围及实体屋顶遮挡。落叶后续修正只改变 `ScenicLeafRenderer`，白虹及共用生产类与已验收运行字节一致。凭据见 `../../cod3/verification-20261018-day-foliage.json`。
