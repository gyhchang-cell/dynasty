# Eidolon 骨王甲的胸披风与护腿分槽

从项目内固定的 Eidolon Repraised 提交 `f53707d478f91496a07c9646f603d433a273d57f` 补读骨王甲。原生登记有三件，`bonelord_helm`、`bonelord_chestplate`、`bonelord_greaves` 分属头、胸、腿，没有该套脚槽注册。核对 12 个归档条目并实际查看三张物品图标及一张 128×64 穿戴原图。

物品客户端扩展把实际装备槽交给 BonelordArmorModel，四肢和躯干共用实体图集。胸槽选择躯干和双臂，披风从躯干沿 `chest → hood → cape` 继承，模型只在胸槽更新这条披风的摆动。腿槽选双护腿与基类的骨盆节点。该骨盆节点在基类创建时为空，骨王模型没有添加任何骨盆几何。单穿护腿的源码路径因此不会选中胸片，也不会选中披风。此判断不包括第三方覆盖或实机动态遮挡。

原图对照标出胸片正面 [8,38,19,44)、披风主片 [70,11,82,27) 及护胫正面 [74,29,78,37)。这些是原始图集像素矩形，旋转与姿态尚未投影。可以把此例和 Electrum 的胸槽下摆放在一起对照。骨王甲的长披风仍归胸槽，而 Tidesinger 的腰扣由护腿槽显式启用。与同项目 Warlock 三件布袍比较，骨王的两件独立胫甲属于腿槽，披风则是胸根的可动子件。和 Remnant 的自定义头盔加其余标准层相比，骨王头、胸、腿都由专用模型消费。

骨王甲当前账本尚未发现同名条目，可作为独立候选。骨质外观及胸披风机制仍需与其它骨甲、披风甲逐套去重和验收，暂不新增正式计数。五套目标继续按原版两层边界验收，不将第三方专用骨架当作改动方案。本轮沿用上批胸纹坐标与验收结论，未重新逐像素检查这 36 像素。
