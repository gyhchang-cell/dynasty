# 极北天幕·极光飞羽

2026-10-18；对应 cod3 奇观 #15。原四条细光线改成三层世界空间帘幕和近处阶梯飞羽。此对象是环境 VFX，不是生物，所以沿用 `RenderLevelStageEvent` 平面几何，不创建人形、GeoAnimatable、碰撞或 AI。

## 参考

已实际查看 [Step 的 Skyrim 夜间天气对照](https://stepmodifications.org/wiki/SkyrimSE:Weather_Compares) 中 100 张独立文件（见 `references.json` 的 URL、编号与 SHA256），分五张 20 格联系表检查。100 指画面数，不是游戏数；包括极光及没有极光的夜空、云层和雪地对照。联系表只留在本机 `build/cod3-aurora-20261018/references/`，不会打包或作为纹理使用。

- 001–020：森林、海岸与山谷；明亮下缘、较暗上层和中央夜空留白。
- 021–040：树林遮挡与雪谷；紫色不宜压过青色主体，地形仍应清楚。
- 041–060：沿海和松林的云层对照；少量轮廓比满屏发光更合适。
- 061–080：不同云量下的分离帘带；用数层错位表达纵深。
- 081–100：雪坡、云夜与雾岸；雨雾不应继续显示醒目的极光。

借鉴构图和对比关系，代码、配色和飞羽全部原创；不复制游戏贴图、模型或后处理。

## 实际加载链

`ScenicEventDefinition.of(15)` → `ScenicEvents` 保存/广播原编号 `scenic_15` → `Cod3VfxRenderer` → `ScenicSkyRenderer` → `ScenicAurora.mesh`。

- 时长 1800 tick，沿用世界锚点、seed、start、旁观范围和已有总预算。
- 近/中/远最多 276/168/48 个面；远档和 MINIMAL 不绘制飞羽。
- 每个飞羽的随机轨迹独立，同 seed、同服务端年龄保持一致；切 LOD 保留已有羽毛轨迹。
- 两端 80 tick 淡入淡出；区域末端 32 格淡出；白天和下雨抑制；不改世界天空、雾、亮度和相机。
- 硬边离散青玉、青蓝分区，无借用贴图、模糊贴图、噪点和 bloom。平面距离排序，近裁剪前淡出/剔除；使用现有状态保护和深度测试。
