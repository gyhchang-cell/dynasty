# Banglum 与 Metallurgium 开面盔和腰线

沿用 Mythic Metals 1.20.1 固定提交 `2118186af2d5d418d2d41b91a4583ade6a1c39f6`，核对 29 个源码及资源条目。实际查看两套八个库存图标、两张活动头盔图和两张护腿图的腰部裁片。原来源图只用于对照。

两个 ArmorSet 都只为 HELMET 构造专门的类，其他三个槽由基类创建。两个头盔均继承 HallowedArmor，通过同一 Fabric 注册过滤进入专用渲染，分别选用 `banglum_model.png` 和 `metallurgium_model.png`。模型注册的图集均为 64×32。护腿读标准命名的第 2 层。该消费路由与已核实的 Runite、Hallowed 同族，当前不追加独立机制计数。

Banglum 两根小角和头壳分开，主头面下半部有连续四行透明区，前后腰带为连续底部五行。可用于青铜与将军的「额部保留小量结构，眼鼻下方完全打开」的对照。Metallurgium 用分段额角留住金属轮廓，左右颊边较长，中部开口保持连通。护腿腰带背部底部五行铺满，前片最上行只保留四个中央像素，呈窄扣向上突出的形状。可用于天将、玄天的腰扣画法对照，额角本身属于专用模型几何。

图页为原像素裁片，实机脸部遮挡、颜色和转角仍未验证。已有五套的编辑范围和保护区继续沿用。制作门槛仍未通过。
