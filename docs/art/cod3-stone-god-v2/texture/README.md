# 神人开山 · 原创逐面像素贴图

已按冻结 UV 绘制并发布 `src/main/resources/assets/dynasty/textures/entity/scenic/stone_god.png`。1024² 原生图集，420 个独立面，36 个实际离散色；没有降采样、量化、柔光、随机噪点或第三方像素。`author_atlas.py` 为可复现原稿。

岩灰大色面与分段岩层构成主体，关节退暗；面部雕刻清晰，玉色只用于既有眼部，暗铜用于冠带和腰饰。斧柄为纵向木纹，斧刃采用三档硬边石色。窄面不强塞细节。

`validate_texture.py` 核对三档模型共 960 个面：UV、材质、骨骼、体块原点/尺寸/旋转/支点与冻结数据一致；420 岛无重叠，逐边 1px 挤出吻合。几何、动画、UV 锁、模型源和幽冥古舰贴图哈希未变化。生产 PNG 与本目录原稿逐字节一致。

`overview.png`、五角度、无光/弱光/灰色/黑剪影、三档 LOD、64/112/192m 和五个动画时刻均来自最终 PNG 的逐面最近邻软件采样。检查中主体层次、腰冠和木柄可区分，远档简化面部符合现有模型。软件弱光不等于真实夜景；预览不是游戏截图。

本次不运行 JVM、构建或客户端，不改模型、UV、动画、Java、清单或其他素材。主聊天负责 bbmodel 嵌图（如需）、整合构建和真实客户端的雾/夜景/过滤/LOD/握持动画验收，详见 TEXTURE_READY.json。
