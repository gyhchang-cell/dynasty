# 玄冰蓝洞：100张新增参考

198张候选画面、10张联系表逐页查看后选100张，SHA256排除此前cod3记录。数字指画面，不是100个模组。来源见references.json。

Profundis的冰洞同时展示有/无夜视，对比说明自然可读性不能靠夜视预览代替；Spelunker’s Charm II冰洞强调厚冰壳与细长钟乳冰的对比；Subterranean Wilderness Revival与CliffTree的冻洞用深蓝冰、浅雪层分出地板/顶面。Ecospherical Depths的冰湖下光点提示光源宜嵌入矿物而非铺满洞穴。其余洞穴对照顶底连接、通路留空和局部矿物簇。

计划用于本地原创冰花：修正旧四向花瓣悬空的问题，构成连续阶梯花托；顶面冰锥必须实际连接洞顶；白色矿物通道与冰花分区，不添加随机碎片或镜头/发光遮罩。不复制来源资产。
