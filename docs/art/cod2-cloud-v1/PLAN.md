# 云砖制作前说明

目标仅为追加清单 fading_cloud_tile：云砖，踩踏后逐渐失碰撞再恢复。完整冲霄隐仙观不因此完成。

顶层16×4×16、第二层12×6×12、底层8×6×8，三层粗阶梯轮廓配顶面2单位厚十字云纹。保持方块上表面在16，便于连续踏步。有限白底/青灰/浅玉/深蓝四色，实际16×16PNG、2×2色岛、白边、不采白底。保存Java方块模型及bbmodel，四向与黑剪影检查。

原生房间时钟驱动，无独立人形骨架：踩踏后20tick预警收缩到75%，40tick消散失碰撞，36tick恢复生长后重新承重。复用现有FLOOR防夹保护；有人占据方块时保持无碰撞且不突然显现。只新增注册与自己的云砖渲染分支，不改其他战斗、任务、AI与既有地板逻辑。人物和小Boss未在本批修改，不虚报参考角色研究。

先做静态资源与原生服务端回归，再一次静音隔离客户端集中检查四视图、真实踩踏/下落/恢复承重及重载。生产构建使用独立输出，避免旧内部类残留。完成后只删除独立云砖一行。
