## 实际来源、槽位与分层

实际阅读 `AtumItems`177–188的12个Supplier：`desert_helmet/chest/legs/boots_iron/gold/diamond`，依次构造HELMET/CHESTPLATE/LEGGINGS/BOOTS；铁/金/钻石使用原版对应ArmorMaterials，耐久倍率分别增加10%/20%/15%，不据图标华丽程度替代真实用途。注册helper把名字与Supplier交给ITEM_DEFERRED，Atum构造器经registerDeferredRegistries挂modBus。

`WandererDyeableArmor`全文实读，继承 `TexturedArmorItem`、实现DyeableLeatherItem；默认颜色14869989，display.color数值NBT可覆盖。`TexturedArmorItem`全文实读：hasRender默认false；这12项没有setHasRender，按LEGS选2，其他槽选1，非null type添加_overlay。不能把这套与Ra/Atem的自定义几何混用。

12份原生模型JSON全部解析：parent为item/generated，layer0为可染布料基础图，layer1为固定金属图。Atum.setupClient调用ClientHandler.init；其颜色回调在tintIndex>0返回-1，其余读取getColor，注册名单包含全部12个ID。原生图标24PNG均16×16；实际穿戴12PNG均64×32。与D59的Wanderer单层图标不同，这12项确实声明双层。

版本文件实际读取为MC1.20.4、NeoForge20.4.232、Atum2.3.0；不是Dynasty Forge1.20.1可直接加载证明。当前批没有固定到该版本完整Vanilla/NeoForge实际渲染几何，因此不把继承的标准UV矩形、简单颜色乘法合成或静态绑定称为精确穿戴消费者验收。

## 实图观察与可借鉴点

已实际查看：24张Desert原生图标的分层页、12张穿戴图集页、12件默认色数学合成诊断页；另重新查看D59实际被模型引用的4个Wanderer图标，区分8张未被该模型引用的wanderer_armor_*图标候选。共40张原生PNG在本轮页面中实际观察，不把全部解压PNG称为都已看过。

1. 头盔的底层只是顶带与两侧下垂布条，金属覆盖层形成短横额箍；中心面孔开口清楚。名称和材料靠物理分区识别，不依靠光效。
2. 胸甲是短宽的原版胸甲轮廓，肩部只作小阶梯；灰布下摆没有扩大为人物躯干。金属主胸片面积大、侧暗边集中，细节预算小。
3. 护腿的固定层构成腰围与两条直腿，分腿负空间贯通，基础布料只在踝部少量露出。不能单看稀疏layer0就误判图标没做完。
4. 双靴用短L鞋底与分离的筒口表达，固定金属片覆盖前方；可借鉴紧凑比例和材料层次，不能照搬其造型或把碎开的层单独当最终图标。
5. 穿戴图集底层的头部是大面积浅布，短块灰白明暗；胸部底层覆盖稀疏，主要胸片由覆盖层承担。整块材质与短亮边比密纹更适合作为当前布/皮甲材质组织参考。
6. 覆盖层在头部侧面矩形形成连续窄额带，在身体正背矩形形成大胸背片，袖/腿局部则是小护片。应分别检查接缝位置，不把单张UV留白当缺件。
7. 五张原始矩形页实际查看了head、hat、body、arm、leg。hat对应区域全空；head主要内容在layer1而非layer2；躯干和腿的基础/覆盖图形互补。这里只说原始矩形像素，不声称精确身体遮挡、左右镜像、实际朝向和接缝已验。
8. 对cloth/sea_silk的可用原则是布料大面、窄边和短块明暗；对bamboo/brocade/cinnabar是分清基础材质与装饰层。Dynasty当前普通ArmorItem不支持这套染色接口，不能只添加_overlay文件就宣称已接入，也不为模仿参考擅改代码。鸿蒙已认可原稿继续保护，不用这套朴素设计统一重做。

## 去重：不是三种新设计

`material-variant-dedup.json`对三材质的四槽和两层图集逐RGBA/alpha比较：12组对应资源的alpha轮廓全部相同；四组基础图标逐RGBA相同；overlay的铁/金/钻石差异主要是材质色。它们合并为至多1个待审完整设计族，不把12件、36PNG、360矩形、9张页面或颜色拆成独立设计。

又与D59 Wanderer的真实原生图标和4张穿戴图字节比较：同为覆面布帽、布料衬底/固定饰边的近亲结构，但Desert加入金属胸背片/直腿/护靴；alpha和RGBA确有差异，只能支持具体差别描述，不能单靠哈希不同授予语义独立信用。D59已读这套共用染色接口与贴图选择器，此次复用不新增实现参考计数。候选与旧账本完整族的全局语义独立性仍交主协调验收，本轮新增正式信用0。
