# 后羿弓：立体虚影与多层结界

本轮保留已认可的连续阵纹，追加以下效果：

- 脚下法阵在空中继续显示。最高档半径从 5 格扩大到 6.5 格，增加两层旋转阵纹。
- 飞行中的王朝箭带小法阵；天狼弓以上档位提供 6 格范围、前向视锥内的可见敌对生物引导，不锁玩家或动物，不穿墙锁定。
- 射日弓、后羿弓、朱雀弓的箭首次命中生成持续 3 秒的大阵。范围与对应脚下法阵一致，竖直检测范围为命中点上下 3 格。
- 命中阵仅爆发一次，每个范围内非玩家生物承受其最大生命值 50% 的伤害。普通护甲、抗性、保护附魔不降低这项伤害；特殊模组的无敌或取消伤害机制仍可能阻止命中。穿透箭不重复爆发。
- 后羿弓拉弓时，玩家头顶出现小八卦，身后约 4 格的位置出现 10 格高的体积模型；2 秒内自下而上形成。弓、弦、箭、冠饰、肩甲、披风、腿部均为立体几何。
- 后羿虚影占据的位置会真实破坏挡住它的普通方块并尝试掉落物品。检测使用与模型共享的形体，每半秒处理一次。不会破坏容器、带方块实体的机器、液体、不可破坏方块，也遵守服务端和 Forge 破坏保护事件。
- 飞行中最高档弓的护盾与推斥继续生效；保留先前的 6 秒上限与冷却。

`preview.png` 使用实际模型与阵纹定义导出，是几何预览，不是游戏实拍。

## 验证

Forge GameTest 在独立测试世界通过四项检查：空中护盾、最大生命值 50% 的单次范围伤害/玩家排除/范围边界、虚影限定清障与容器/基岩保留、自动锁敌的方向/速度保持/墙壁遮挡。
