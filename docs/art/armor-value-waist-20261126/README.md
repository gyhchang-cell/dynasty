# 五套旧甲的胸腰明暗与小尺寸辨识

对照五套 Dynasty 旧稿与五套已保存的第三方四槽盔甲穿戴图，共 20 张原生图集。按已验证的槽位读取两层，核查躯干前、背与双侧原始裁片。正面另作 4×6 面积平均预览，统一底色，只用于比较小面积图案的辨识度。真实距离、照明和动作下的遮挡另待实机。

Elder Souls 青铜的胸部上段与护腿腰带亮度中值同为 122，Aether Valkyrie 两处同为 187。两套都把腰带留在第二层底部，上方透明，缩略后仍能靠胸片和横带的轮廓分清部位。Elder Souls 绿宝石的腰带比胸部更亮，也通过同样的分层保住轮廓。它适合研究亮色集中方式，绿宝石高饱和度不直接用于玉甲。

Dynasty 目标躯干前、两侧和背的矩形分别为 [20,20,28,32)、[16,20,20,32)、[28,20,32,32)、[32,20,40,32)。V20–26 为上段，V27–31 为候选腰段。五套第二层的正面上段均是 56/56 个非透明像素，且各自与胸甲上段的明度中值相同。五套外部对照在这一段均为 0/56。这里记录各区整体情况，精确胸纹像素沿用原收据。

| 套装 | 后续缩略复核重点 |
|---|---|
| 青铜甲 | 第一层保留红铜胸纹。第二层用轮廓清楚的低铜腰带，侧面亮边成块，背面少量亮点。Mythic 和 Elder Souls 青铜都可复用。 |
| 将军铠 | 深灰胸甲和腰带可以明度相近，靠胸片垂直轮廓和腰带横向轮廓分开。酒红点继续归胸槽。参考 Elder Souls 青铜同明度分件。 |
| 玉甲 | 保留柔和青玉大面。下段用同色深绿接缝和少量浅色，避免套用亮绿绿宝石的饱和度或保留整个亮胸纹。 |
| 天将云铠 | Neptune 只作蓝色大面读形参考。浅边保持小面积，侧背接续保住冷蓝色块。 |
| 玄天真龙甲 | 参考 Valkyrie 的小面积金属亮点。保留自身深蓝、金、青身份，第二层腰扣与第一层胸前核心采用不同轮廓。 |

Elder Souls 两套各有四槽登记、物品模型及保存的穿戴纹理方法记录。早期原资源清单仍标作候选，本次使用后续的静态绑定图。Valkyrie、Neptune、Elder Souls 青铜和绿宝石均在旧账本。Mythic Metals 青铜已经有同一套的四槽记录，其机制与原版模板组近似。Yucutan Jade、Deep Aether Skyjade、Jerotes 铜、Ice and Fire 铜已按旧账本逐套去重，当前项目内只保有库存图和来源指纹，缺可绑定的穿戴图，保留待补证。
