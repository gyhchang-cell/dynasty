# 混元原版轮廓返修与五套未改盔甲

用户认可v25其他三套创新，指出混元偏离原版感，并要求一次多做。本轮24件：混元4件返修，青龙、朱雀、玄武、白虎、天罡各4件首次重绘。保留鸿蒙、紫微、北斗、麒麟和精致旧图。只改物品图标与对应加载模型，不改穿戴UV、数值、配方、ID或逻辑。

## 设计依据

已检查现有图标与DynastyArmorMaterials的四象/道门定位，确认这些旧图是未重绘的同族简陋资产。以原版下界合金图标作为第二输入，约16–20逻辑像素的大方块轮廓；不把原稿实际缩小。延续v24已实际查看的1000张去重盔甲图标与神灵金参考，未声称本轮重新研究1000套项目。

- 混元：删除大玉环、鼓起的圆肩、弯曲护腿纹样，改成宽短板甲和少量玉绿/古铜色块。
- 青龙：少数大鳞片、短钝额鳍，避免密鳞和龙头雕塑。
- 朱雀：红色大羽形甲片与短羽脊，保持盔甲轮廓。
- 玄武：厚实方甲、少数直线分片，强调防护。
- 白虎：银白甲与少数深色阶梯虎纹，不画兽脸。
- 天罡：蓝钢、短直金框、少量符形结构，区别北斗星纹。

## 制作与证据

内置imagegen逐件编辑。plan.json、generation/*.json记录每件提示词/输出路径，sources保存获选完整原稿。只裁透明外边距并补2px透明边，主体RGBA保留；汇总图片才缩放。install.py通过统一publish_originals注册最新批次。publish_local.py以旧文件哈希守卫及备份，仅更新现有本地JAR/导出中的49个资源条目，其他ZIP负载逐项保持。native.log、source-check、DELIVERY、installed-readback、final-check记录实际检查。after.png、comparison.png及inventory-32px.png均为实际资源预览，不是游戏截图。无窗口检查不等同实机验收。

## 本轮复查记录

- 最初混元胸甲仍有圆肩、护腿仍有弯纹，未采用；已另外生成更接近原版的方肩与直腿版本。两版提示词与路径均保留，selection.json明确获选返修版。
- 全部24件按大图和32px物品栏缩略预览实际检查。青龙/朱雀/玄武/白虎/天罡使用不同色材与大甲片，避免细密雕纹；透明底没有白框。预览见after.png及inventory-32px.png，不是实机截图。
- 玄武靴原稿最大alpha为254，背景为0；保留原稿alpha，不强行改色或改透明度。完整原稿均未降采样或量化，运行PNG仅做透明裁边和2px留边。
- preservation-check.json实际确认56张穿戴贴图、22张获保护图标哈希不变，混元四个模型文件不变，其余20个库存图标迁移到现有原稿加载器。
- native.log：24张PNG、30955个原生挤出面及UV范围、图集codec通过。全体444件获选原稿的RGBA及889个JAR资源条目核对通过；历史22个范围外图标差异仅记录，不覆盖。

本轮仅库存图标；穿戴UV没有重做。没有启动图形客户端，游戏内画面仍待实际加载观察。不删除包含尚未实机验收要求的原提示词段落。
