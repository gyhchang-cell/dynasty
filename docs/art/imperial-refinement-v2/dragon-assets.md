## 1. 首选外形：Zhao Haiyang — ChineseDragon（TurboSquid 2200492）

- [作者商品页](https://www.turbosquid.com/FullPreview/2200492)
- [作者公开预览图](https://p.turbosquid.com/ts-thumb/do/fbCtOs/hb/z009_2/jpg/1709819269/1920x1080/fit_q87/61b63b70589812f8707b95a551409a5618f0ccc9/z009_2.jpg)
- 页面当前报价 **US$200**，税费及最终价格以购买时页面为准。没有付款。
- 作者列出 Maya 2018 / FBX、160,962 polygons、身体 4K / 毛发 1K 纹理、绑定和路径控制器；FBX 不含 Maya 的全部绑定控制功能。
- 已通过浏览器实际查看公开渲染图：长曲躯干、明确龙颅、鹿角、向后流动的大片鬃毛和四爪，三个候选中最接近用户的电影中国龙方向。展示为碧玉绿色，不意味着原样材质就是用户希望的真实皮肤；游戏画面也不能等同作者离线渲染。
- 商品标注 Standard License。[TurboSquid 官方许可说明](https://blog.turbosquid.com/royalty-free-license/)允许符合条件的 game mods，但要求防止最终用户直接取得模型，不能直接把开放模型文件再分发。**公开仓库里的 FBX/OBJ/GLB 或简单 JAR 打包不是已经获确认的合规方案。** 应先让卖家/平台书面确认具体 Minecraft 发布方式，或取得额外许可，再购买。
- 还需制作适合实时游戏的 LOD、转换绑定/鬃毛动画、重做金龙/青龙材质，不能把 Maya 场景直接塞进现有渲染器。
