# 幽冥古舰最终像素图集交接

范围仅 `textures/entity/scenic/ghost_ship.png` 与本texture目录。读取用户《建模要求.txt》19/20、assets规范、固定UV交接、模型预览和已有参考说明。实际查看模型overview、参考viewed-1联系表；模型对话已有100图/16项目研究，不冒称本作者全看过。

采用交接明确允许的原生逐岛像素绘制流程：author_atlas.py 是可编辑画稿，保存明确调色板、板缝/稀疏木纹/方形端纹/铁件磨损/竹节/帆面修补与缝线笔触规则；非随机噪点、临时色块或AI光滑插画。直接在512网格绘制，31种实际纯色。ghost_ship.png是实际源PNG，与运行PNG完整字节相同，不做降采样/减色。没有挪动或增减UV岛。

750面岛使用交接原始rect、face_axes和long_axis；木纹顺构件轴，木端面单独绘制，帆面缝线/大折痕按物理坐标而非每岛重置。跨五段的16处正反面相位检查通过。seal材质虽有声明但无专用面岛，少量旧封印只画在主桅现有木面，未增UV或几何。窄至1px的薄边保留简单材质，不伪造细节。

最终PNG回贴五视图、灰/黑剪影/原色/弱光、三档LOD、36/64/112米同FOV和5帧原有循环；见overview.png、comparison.png、各距离图及idle.webp。仅为Python软件逐面最近邻采样，不是游戏截图，也不是原生Forge验证；渲染器内部面UV钳制不能替代实机采样验收。距离参数已核对为米，由渲染函数内部换算模型单位。

validation.json记录非重叠/一像素边缘外扩/有限色板/1674个LOD面及跨帆相位。source-snapshot.json记录模型/动画/UV交接哈希，本轮均未更改。TEXTURE_READY.json为具体交接，accepted只针对贴图范围。主对话仍须同步bbmodel内嵌PNG、冻结最终构建并做实机水面/雾夜/LOD/动画验收。
