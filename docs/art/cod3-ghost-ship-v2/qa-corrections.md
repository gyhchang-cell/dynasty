# 本地验收修正

专用服首轮液面夹具放在测试结构相对y80，实际世界地形高于夹具，严格高度图净空检查正确拒绝。将QA夹具放到相对y200的露天空域，生产航线检查未放宽；仍检查整条56×12米航线每格源液体、两格深度及全部上方净空。

加入幽舰测试的回归批次中，旧火树测试全世界UUID断言偶发捕获与模板无关的地形生成生物。build-v2.log明确记录新增牛位于(227,121,146)，模板边界为x220..266/y-36..6/z160..206，明显在边界之外。将断言限定实际火树模板包围盒，仍检查模板NBT无实体/方块实体且模板内没有新增UUID；没有改火树资源和生产逻辑。相关失败日志保留。

原生v1成功真实渲染首张船体，但动画数值期望漏加主帆初始-18度张帆偏角，误以为动态关键帧应从0度开始。geo已有rest rotation[0,-18,0]，软件预览和模型导出一致。修正QA期望为初始姿态加8秒关键帧；保留实际角和期望角诊断，未放宽容差，未改动画来配合测试。

原生测试使用一次性受控深水世界和实际阴司维度中的临时水池，验证实际液体、水线、帆/纹理、维度雾色和清理；不声称这两个测试液面是自然生成的大江，也不操作用户存档。阴司配置default_fluid为熔岩但sea_level=-64，不能凭default_fluid配置推断存在连续天然忘川熔岩河；生产只在真实加载且满足航线条件的液面上显示，不制造河流。

原生v2全部20场景通过后，主对话继续核对本机实际4.8.4库字节码（GeoObjectRenderer.javap.txt），发现其preRender默认平移(0.5,0.51,0.5)。这会让以自身液面原点制作的船抬高半格。仅在ghost_ship渲染器中抵消这个默认平移，不改变其他景观物件。原生v3增加对真实preRender矩阵的零平移断言，并重新检查全部20场景。此为生产水线修正，不是放松验收。
