# 建筑重制 v3：宫殿、帝陵、观星台

打开 `gallery.html` 查看实际方块渲染与三件物品前后对比。本轮主力是建筑，科举优化仅整理为独立 DeepSeek 任务单，没有声称已执行。

## 内容

- 宫殿新起点从 48×48 扩至 64×64。中轴正门、两座池桥、西侧档案与制图殿、东侧锻造工坊、四亭、绿瓦墙檐、铺地线条和庭树。主殿 NORTH 子部件锚点按真实局部坐标转换，不再凭世界 Z 偏移摆放。四个庭院箱和两个主殿箱，未新增掉落档位。
- 帝陵保留 40×40×16 边界，重做墓道、四间主题侧室、两条环路、高柱藻井及棺椁台；原四箱与原掉落表不变。
- 观星台保留 26×26×20 边界，新增下层回廊、四向可走楼梯、上层嵌地星图与三轴浑天仪；原两箱不变。
- 探索者罗盘补齐真正读取的六项 `structure.dynasty.*` 中文名称，10 群系及4维度一并校验。不是通过更改注册 ID 来改名。
- 三张独立 imagegen 物品贴图：科举试卷、徽墨、竹简；128×128、主体最长边120像素。见 `items/prompts.md` 和源稿，旧图已保留。

## 存档与部署原则

已生成建筑不会自动翻修，不删除区块或存档。48 格宫殿根据保存边界保留旧路线；帝陵、观星台增加持久化布局版本，旧起点继续旧算法，避免已保存结构跨区块变成两种设计。新版应在新区域或独立测试世界检查。

只替换项目和已核实实例的 Dynasty JAR；不会更新其他模组版本，不调用会广泛同步目录的 exportModpack。实例替换前保存备份，运行中旧文件句柄不原地覆盖，重启后加载新包。

## 验证范围

独立 Forge GameTest 捕获生产建筑放置调用，检查边界、宝箱、合并主殿后的路线、旧宫殿 NBT 和四向楼梯；共26项。首轮庭树装饰阻挡指定通行点的失败已通过调整花丛位置修复，没有放宽断言。

Minecraft 独立客户端读取真实生产结构和物品模型并渲染到离屏缓冲，检查非空帧、GL错误及已有资源重载回归。不打开用户世界。预览不是游戏内行走截图；剖面有意隐藏高墙屋顶，预览未渲染水面、部分方块实体和周围地形。不能把这项检查当作全整合包地形适配、帧率、光影或战斗验收。

世界生成引用、特征顺序、战利品引用、5项罗盘汉化回归、18项任务回归另行核验。全库语言检查仍报告既有后羿弓拉弓模型和 puzzle_star_dial 缺少语言条目；GameTest 日志有既有 Curios 旧标签引用警告，这轮没有改动它们。

最终测试日志与渲染报告保存在本目录的 `gametest.log` 和 `render-check.txt`。构建及部署摘要见 `deployment.md`。
