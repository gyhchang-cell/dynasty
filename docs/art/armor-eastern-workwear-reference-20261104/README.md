# D25：五套未读中式工作装与军甲参考

本批实际查看蓑衣、士卒、寒铁、烫金灵铜、玄黑灵铁五套的20张原始图标、5张穿戴图集，以及5张源模型静态组装分析页。正面、45度、侧面、背面和黑剪影均看过。原图保持原始RGBA与分辨率，不复制到Dynasty。

`verification.json`为`PASS_RESEARCH_EVIDENCE`。20条原生四槽链从注册bootstrap、具体物品工厂、客户端扩展、渲染器追到GeoModel资源和护甲骨根。读取5个geo共680个体块、5份动画声明；26份镜回原始class、2份固定GeckoLib4.8.4槽位上下文均有原始归档与entry哈希。只反汇编，不运行模组类或游戏。固定4.8.4上下文不代表外部整合包运行版本已验证。

主要观察：

- 蓑衣的交叉绑带、层叠短袖、裙片和侧挂件形成一组新保守学习记录。四槽、挂件、体块及五个视角不拆分设计。
- 士卒、寒铁与两套铜铁甲追加原有片甲族，零额外独立设计信用。虽体块不同，仍不凭材料名字或金/铁配色扩充计数。
- 袖口和甲裙必须按实际结构处理。长护裙、长外套不能用“L2统一清空”修复；八根节点存在也不能只看根自身无cube而判某槽缺件，需查后代。
- 士卒图集256×256、geo网格128×128是2倍纹素密度，不直接报错；其他密度记录在`geometry-study.json`。
- 原生图标多为高分辨率模型正面图，部分胸图带整块裙摆，靴图像矩形。只学材料组织与结构，不能直接当原版甲轮廓成稿。软件分析图不是实机，也不证明动画、槽位最终可见性和接缝。
