近/中132面，远处与MINIMAL只保留48面柱影；细纹在72～96格淡出，低于清单150预算。采样已加载的实际土/草/苔藓表面，符纹跟随地面，超过4格落差的面跳过；石屋顶、水面、缺失区块不生成阵纹，不请求新区块。

保持原来主世界平原、17000～19000tick晴夜、1200tick寿命条件；客户端同步检查时段和雨量。近裁面保守剔除、透明深度排序、离区/换维度/断线清理，无额外实体、流体或玩法改动。

本项新增原创六秒无词合成低吟OGG（22050Hz单声道），有可复现合成源generate_array_chant.py，无真人录音或外部音乐。仅48格内的当前场景播放；音量随时段、雨、寿命、距离变化，循环实例在离区/到期/换维度清除，资源重载后可重建。主音量为0时完全不创建音源。未试听、未调整系统声音，音频验收仅做格式/峰值/资源加载与代码边界检查。
