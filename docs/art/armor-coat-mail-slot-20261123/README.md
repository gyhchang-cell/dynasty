# 猎人外套与强化锁甲的槽位对照

接续 Botania 与 Tidesinger，补查两个不同作者的本地固定案例。核验四槽图标、声明和选定穿戴文件的来源指纹，实际查看八个库存图标及两套的八块穿戴裁片，另统计了猎人外套第一层胸片的透明度。

Vampirism 普通猎人外套按 Forge 默认路径选 64×32 的两层图集。胸甲第一层正面每行只有 4–6 个非透明像素，留出开襟；护腿第二层的正、背和侧面则从顶至底有连续像素。原图上看得到棕色衣料和开襟内衬用的竖排扣。与未改盔甲的统一满铺模板不同，这里能辨认出内衬和上衣正面的具体配合。只针对旧金属盔甲裁腰，不能把“护腿层的上方不透明”当成可套用到全部服装的自动删除规则。外套与护腿一起穿戴的真实遮挡待验。

Dungeons Gear 强化锁甲的胸护片是 `armorBody` 的 `chest` 子骨，腿甲挂在左右腿根，模型无独立腰带骨。右腿正面原生裁片 [60,20,64,32) 仅第六行有一条棕线，腰带视觉来自腿部横带。用于比较“腰部装饰跟随腿”与 Botania、Tidesinger 的“护腿槽开启独立躯干腰带”两种做法。已固定的 Libraries 源码确实转发槽位，但版本与模组要求不同，GeckoLib 的精确槽位开关及实机表现仍待验。这批只将几何和原图纳入对照。

两个案例此前已经有家族归属或待验记录。本轮的分层证据不会为同一参考重复计数。Tidesinger 的同根局部可见性仍与这两例不同，保持待全局去重和独立验收。五套 Dynasty 候选沿用已核定的 UV 范围，1000 门槛未通过。
