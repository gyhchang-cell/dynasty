# Dynasty × 灾变：三位既有Boss的力量精修 V12

在已认可的V11人形上连续八轮修正，未重做物种、骨架、剧情或战斗系统。九霄天将、东海龙王、龙帝的全部原骨骼/父子关系、原Cuboid、脚部、注册ID、六段动作名/时长/循环保留。通过肩胸厚度、头部与身份部件的接合、兵器方向、战备手势、逐面PNG和独立气场加强首领感。最终不是统一给三人装一副灾变盔甲。

## 真正看过的八只

作者实际展示：[灾变图库](https://www.curseforge.com/minecraft/mc-mods/lendercataclysm/gallery)，打开查看了Ignis和Harbinger画面。另使用本机已经安装的Cataclysm 3.27，在独立、静音、隐藏窗口、一次性Forge世界里拍摄全部八只原模组Boss的正面和45度图。NoAI待机，不能说已完整体验八场战斗；利维坦12m触肢裁切，因此补拍32m完整构造。

## 差距、实际修正与反复检查

原先压迫感弱，不只是配色浅：肩胸薄而平、头部信息没有支撑、长枪和戟斜到身后、须髯藏在领甲内、手部停在腰旁。金边和背饰比控制中心抢眼，像陈列服制而不是能运作的首领。

- 九霄天将：已有肩胸、前臂和掌部加厚；钢盔及颊护有重量，裸拳改钢护手/暗握面。胸甲取消重V描边，领甲减少金色抢眼。枪杆前置，原枪头阶梯尖端拉长，仍为原兵器；左臂抬为战备/出令侧。双令旗与短披挂保留。淡金青白背弧线宽/范围适度加强，稀疏粒子不遮身体。
- 东海龙王：原龙冠、人脸、白须、王袍和戟保留。肩披增厚、背鳍与披挂靠拢；须根/上须/下须重新分深度，避免被领口盖住或漂在脸前。袖体使用顺肢体的织纹/细鳞组织，肩金板读成叠层；三叉戟位于身前，另一臂掌控姿态。海青背弧与少量水尘仍独立。
- 龙帝：原帝冕、人脸、黑须、赤袍、左手玉印保留。厚肩胸、叠领与袖体强调主体，黑须重新接合下颌并遮过领层。左掌印抬到胸前，右臂带控制姿态；背屏和浮圭降低与面部的竞争。暗金断弧加宽，赤金尘低速上升。没有临时添剑、弱点或伤害机制。

八轮中的前七轮资源与主要视图保留在iterations/01～07：第一轮厚肩胸但眼影垂；第二轮脸干净但枪仍向后；第三轮握持转正，原生发现须髯遮挡；第四轮仅前移薄须片不足；第五轮须根接合后并排仍发现内聚瞳孔、短钝枪头、低手势、远处气场弱；第六轮纠正瞳孔、缩短脸下段保持盔接合、锐化原枪尖端、抬战备手，并加强背后独立断弧。第七轮进一步把枪/戟避开正面目光，斜肩甲分离承重面与罩边，皇家前臂袖体收束，避免抬手像盒端。第八轮在真实死亡帧发现旗/鳍/浮圭托高躯体，使用现有骨骼在原14tick内收折背饰、随身放倒枪戟，实体肩侧/巨臂承重接地；补充检查防止装饰成为唯一接地点。没有靠缩放对照图、扩大脚底或套用对方资产掩盖问题。

## 公平画面与判断

comparison-cataclysm-v12-on/off.png均来自真实游戏。双方相机12m、70度FOV、1.62m视高、45度、日间；同一个1700×950裁切，角色不单独放大。Cata自带的熔亮、翼效、烟粒和天空色保留，没有额外光影/资源包，所以不能把这些效果说成纯PNG。我们的on/off另有同机位12状态，身体的无特效检查与实际气场分开。八只参考总览中利维坦32m图明确标注，不能用来比较相对体型。

本轮自评重点是人形首领的本体与战备可读性：三者已有可识别的厚肩胸、目光、主控兵器/掌印及不同外围轮廓；体量仍按约3格设计，不能声称与巨兽、利维坦同尺寸。灾变完整战斗编排、专属机制/大面积异常材质是另一层差距，不能因静态图改善便宣称整个模组的演出已经相等。最终真实对照供直接检视，未虚构“已经超过灾变”的评分。

## 运行资源、生成与验证

生产资产为src/main/resources/assets/dynasty/{geo/boss_cuboid/*.geo.json,animations/boss_cuboid/*.animation.json,textures/entity/boss_cuboid/*.png}中的这三只。权威源tools/art/boss-human-v12/create.py默认导出第八轮，纹理为天将/龙帝256×256、龙王512×512（更多面分配实际UV面积），有实际重绘/UV分配；各面最近邻采样，不是平均色。所有权哈希阻止旧V10/V11生成器覆盖回旧图。bbmodel内嵌正式PNG、逐面UV和六段完整动作，非循环导出为once。

离线验证检查：已有骨骼/父子/部件保留、脚部尺寸、逐面UV不越界/不串岛、纹理尺寸匹配、循环首尾、每动作321次接地采样、已认可的其他27个美术资源及战斗源码未变。原生验收分别记录生产Renderer和已加载资源哈希，42状态为正/45/侧/背开关气场、移动、蓄势、接触、恢复、受击、死亡；另12个干净待机状态与灾变机位相同。18段软件动画只叫资源回放，绝不冒充游戏录像。具体PASS、生产JAR哈希与当前主目录构建见build-report.json。

自然遭遇、复杂地形、联机、真实额外装备交互和服务器技能→cast同步待验证；伤害/技能机制/碰撞/任务没有改动。已确认背景红色三轨来自独立环境事件scenic_21（power-own-round7逐帧包记录），不属于Boss气场。最终验收仅在一次性世界里设置该区域环境事件冷却、清理临时场景的环境队列；正式ScenicEvents与战斗代码不变。所有Java检查在隔离的静音隐藏客户端进行，没有改变系统声音/亮度、读写或关闭用户愚者世界。
