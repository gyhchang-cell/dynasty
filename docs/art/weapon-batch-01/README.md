# 武器贴图第一批（64×64）

本批只替换三个物品的贴图，不改物品数据、模型、配方或其他贴图。源画由内置图像生成工具逐件制作，导出到游戏时保留透明背景、硬边像素与 64×64 分辨率。

| 物品 | 识别点 | 文件 |
| --- | --- | --- |
| 龙渊剑 | 蓝银剑刃、青玉剑脊、龙形护手 | `longyuan_sword.png` |
| 后羿弓 | 反曲弓臂、太阳纹、红色握把和清楚的弓弦 | `houyi_bow.png` |
| 雷霆锤 | 厚重双面锤头、雷电纹、金属箍与短柄 | `leiting_hammer.png` |

- `before/`：替换前的原始 32×32 PNG，可逐件恢复。
- `sources/`：各件生成的高分辨率透明原画；生成提示词在 `prompts.json`。
- `comparison.png`：原图与新图的并排预览。
- `tools/art/export_weapon_batch_01.sh`：仅导出本批三件到 64×64；先裁剪透明边、再将内容采样为最多 60×60，置于 64×64 画布中央，最终限制为 48 色和二值透明度。

这样每件武器的主要轮廓接近占满物品格，同时留少量边缘空间，避免物品贴着格子边框。原始图和生成源都留在仓库，后续可以针对单件继续调整，不必整批重画。

后羿弓已在 `docs/art/houyi-bow-v2/` 重新设计并加入三张拉弓帧；上面的首批比较图仅作历史记录。`export_weapon_batch_01.sh` 现在会导出新版后羿弓，避免意外还原旧图。
