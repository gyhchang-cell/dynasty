# DropBear 倒挂身体动作链

本批完整读取固定版本的模型、实体（含两个内部AI）、Renderer及四个移动/目标辅助类，共7份模组源码；另完整读取原版RandomStrollGoal，并补看选定落地回调。下载的固定源码与现有缓存逐份一致。

## 身体与动作

14个节点、13条父子连接、15次长方体定义。较大的前躯承接头、下颌和前肢；后肢属于后躯，爪端接在前肢末端。四段动画长度分别为咬击9、左右挥击各15、跃起20，与声明一致。

倒挂由同步标志生产，模型用0～5权重翻转身体；实体同时切换地面/飞行移动控制器。下落冲击来自落地回调，不能把动画时长、状态标志和真实接触当成同一时钟。
