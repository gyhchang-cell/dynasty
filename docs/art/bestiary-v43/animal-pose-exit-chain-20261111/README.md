# 动物姿态退出链补查

本批把已定位的 Gorilla 坐姿/站姿、采叶与逼近，以及 Bison 冲锋退出，与模型复位和导航停止连起来核对。保留旧批次所有有效引用，不重复算新生物。

## 这次补齐的判断

- **坐姿不只一个开关。** Gorilla 自己的 SITTING、原版 orderedToSit、原版坐姿位彼此独立。自定义 travel 负责部分停移动作；原版坐下 Goal 的退出不会替它清 forcedSit。
- **冲锋取消不等于立刻回稳。** Bison 先更新姿态和速度，后取消冲锋标志。条件推演显示取消当次可仍保留原速度，下次才恢复；模型姿态还需继续回落。
- **Goal 停止不自动清一切。** 调度器调用各 Goal 自己的 stop；采叶和群体冲锋缺少的清理，调度器不会补做。逼近 Goal 内部调用 stop 也不直接关闭外层运行标志。
- **模型复位只处理模型变换。** Citadel 按保存的旋转和枢轴复位，再叠加动画和坐/立权重；不会同步清导航、状态、进食或计时器。

实际源码、固定版本、源码行锚点、选定依赖方法和条件顺序表均已保存。条件顺序表不是实机回放，也不代表 Dynasty 有同样故障。
