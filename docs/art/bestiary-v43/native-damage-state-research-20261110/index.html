受击染红 ≠ 受伤骨骼动作 ≠ 死亡倒伏

固定本地 Minecraft 1.20.1 / Forge 47.4.10 源码研究。一个完整基础机制，不新增生物参考信用。

server hurt

LivingEntity.hurt initializes hurtDuration/hurtTime to10 in ordinary accepted-hit path. Cooldown branch can reject or apply only extra damage without restarting this timer; do not say every hit restarts it.

server event to client

Unblocked ordinary-hit branch calls broadcastDamageEvent. ServerLevel sends ClientboundDamageEventPacket. ClientPacketListener resolves entity and calls handleDamageEvent. Base LivingEntity sets walkAnimation speed1.5, invulnerableTime20 and hurtTime10; it does not rotate model bones.

separate hurt-animation packet

ClientboundHurtAnimationPacket -> ClientPacketListener -> animateHurt(yaw). Base LivingEntity method sets timers only and ignores yaw. This does not establish behavior of subclass overrides such as players.

timer decay

base tick decrements positive hurtTime; a presentation timer distinct from invulnerability/collision and custom synced AI state.

rendering overlay

LivingEntityRenderer.getOverlayCoords uses hurtTime>0 OR deathTime>0 to select overlay row3; otherwise row10. Default white overlay progress=0. Model rendered with RGBA multiplier1 except invisibility alpha.

shader consumption

Default EntityModel uses entityCutoutNoCull. Vertex shader fetches packed overlay UV; fragment shader mixes overlay.rgb with textured vertex color using overlay.a before lightmap/fog. Overlay row3 is ABGR0xb20000ff (redRGB255,0,0 alpha178). Thus standard hurt tint keeps178/255 of pre-lightmap base RGB and mixes77/255 red. It is not a changed PNG or bone animation.

body animation

Complete HumanoidModel.setupAnim uses locomotion/head/swim/riding/arm-use/attack/crouch/bob. No hurtTime/deathTime branch authors an injury pose. setupAttackAnimation consumes attacker attackTime; cannot label it defender hurt recoil. Hurt handling can change locomotion speed and entity knockback, so do not claim the visible body is absolutely motionless.

death synchronization

Server die sends entity event3; client base handleEntityEvent for non-player sets health0 and dies. tickDeath increments deathTime and removes server entity at>=20 absent overrides/hooks.

death transform

LivingEntityRenderer.setupRotations uses sqrt((deathTime+partialTick-1)/20*1.6), capped1, multiplied by default getFlipDegrees90 around Z on PoseStack before model scale/translation. It rotates whole rendered model, not individual leg/torso bones. Dead entities get zero locomotion inputs but setupAnim still executes; not a promise all pose channels reset.

reference applicability

Human Companions CompanionRenderer inherits wide PlayerModel chain without overriding setupRotations/hurt overlay. Its custom armor/item layers are not claimed to use identical overlay handling; custom Forge events, shaders and subclass overrides may change this.
