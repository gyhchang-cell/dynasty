# Citadel 5633260 动画生命周期补查

只读研究，未制作或覆盖任何运行资源。发行页对应 Citadel 2.6.0、Minecraft 1.20.1；下载包仅保存在本研究目录，未安装、未运行。

## 实际读到的差别

- 服务端发送动画的函数没有自行归零 tick；客户端收到包后会归零。必须结合各实体 setter 与调用顺序判断，不能把重复请求动画等同于重播。
- 播放完成按 tick 等于 duration 恢复；tick 已超过 duration 没有自己的恢复分支。Start 事件取消只阻止发送分支，不自动停止后续推进。
- 模型 resetKeyframe 把附加变换混回默认基线，不负责清坐姿、冲锋、导航、配对参与者或持久化状态。
- 混合使用正弦缓入，静态段保持前一段变换；Minecraft 1.20.1 映射已核对暂停判断、帧时间和 sin，不凭方法名猜测。

完整证据见 study.json、三份反汇编 JSON 和 mapping-evidence.json。十个完整类与两个额外选定方法仅算共享辅助实现补查，不算十二只生物。
