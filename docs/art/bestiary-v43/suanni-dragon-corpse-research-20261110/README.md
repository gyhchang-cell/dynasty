# 龙类尸体姿态：限定范围研究

固定 Ice and Fire 提交 `02b2922003cbce3c67dad55dfea79acf1721e0db`。实际阅读身体姿态、死亡进度、尸体生命周期、父链、渲染与地形支撑的选定流程，原始下载与哈希见 `source-verification.json`。

发现：火龙的身体下沉、颈链偏转、四肢松落共同组成尸体；冰龙源码另有 BodyUpper 下沉补偿。死亡后腿部地形采样不再沿客户端活体路径更新，模型仍可能使用残留支撑高度。保存读取末尾的 customPose 设置还会把死亡进度改为20，不能把 DeadProg 的存盘字段当作精确恢复证明。

这是尚未完成运行闭合的相关源码研究，不是新模型交付。实际注册点、Citadel转换与冰龙终姿资源仍有缺口；不记独立验收信用，不把三种龙、骨骼或姿态数凑成多个参考。历史认可与有效参考保持。

没有修改生产模型、贴图、动画、技能、总清单或任务文本；没有运行Java或游戏。下载资产只在本研究目录作阅读，未接入Dynasty运行资源。
