本次实际读了三条不同流程：

- **灾变下界合金巨兽**：死亡state5、停止其他状态、50tick死亡动画与60tick实体移除。根部沉降、屈腿、躯干回弹及头颚下垂分别驱动。完整DEATH混用线性和Catmull-Rom；模型还有注视/步态/睡眠叠加。五份本地选定源码与固定提交字节一致，另补齐固定提交的完整动画源码。
- **Mowzie霜冻巨兽**：致命受伤触发死亡，94tick动画常量与74tick移除。选定关键帧累加95tick，但不能据此声称全段可见；48–55tick侧倒，53tick为落地声条件。另读了默认姿态、插值器、地形四足解算、活动/待机层、出生同步与保存范围。八份选定源码与固定提交字节一致；两份腿解算源码仅记录本地SHA。没有播放声音或运行游戏。
- **Mowzie钢铁守卫**：130tick死亡常量、110tick移除；关键帧累计128tick。解除腹颈颤动后先沉降屈腿，再根部前翻并用不对称双臂/小腿承接；默认注视层仍参与，步态计时会衰减。复用并去重同仓库父类/插值器，不再把共享机制计数；不制作其武器。

这些策略用于学习“失去支撑→身体/头颚协调→落定→实体移除”的方法，不复制模型、动画或数值。相关方法不等于头颚已严格接地证明。Frostmaw的地形腿高解算也不是头部接地约束。

旧whole记录按原选定范围去重：Tiger爪击/跳扑、Gorilla砸击、人形恢复、弩手状态、通用控制器/受伤死亡框架均保留，不直接改计为铜兽接地死亡。当前Dynasty实体本身的检查也不是外部参考信用。没有重跑481/103/165采样，没有动已认可形体、贴图、物件、共享Jar、用户存档或主清单。
