  7. GeoEntityRenderer.actuallyRender applies pose-stack rotations before adding AnimationState model data and invoking currentModel.handleAnimations. It continues handling model animation for a dead actor while passing zero locomotion values; it does not automatically select a death clip.
  8. GeoEntityRenderer.applyRotations uses deathTime and the sqrt/cap formula with default getDeathMaxRotation90. This is whole-model Z rotation. Existing root/keyframe transforms occur inside that model transform; adding another collapse can compose with it and needs a deliberate review, not automatic double-fall accusations.
  9. SecondaryMob.animation maps STATE into idle/wander/hunt/flee/attack/special/evade and named skills. The single body controller has transition4 and thenLoop(animation()). Neither native hurtTime nor deathTime directly chooses another clip here.
  10. Server aiStep returns after super.aiStep when dead, before the custom STATE clock/update. Thus death does not author a new custom STATE through this method. Current animation dictionaries have19 clips each, none named hurt/death; presence of arbitrary other channels was not revalidated this turn.
  11. SecondaryMob.hurt can select evade/flee, then swindler sets deceptionStage3 and STATEflee for200. Until exposed, swindler aiStep requests special repeatedly. These are gameplay state producers separate from native hurt tint; no gameplay timing edited.
  12. GeckoLib4.8.4 source read closes the rendering state mechanism only. It does not satisfy per-creature art acceptance or a100/1000 semantic reference requirement and adds zero distinct creatures.
