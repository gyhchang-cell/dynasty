# 枯木树精：伪装退出的生命周期反例

dynasty:kumu_shujing。固定本地源码研究，非模型成品或游戏验收。

与已读Mungus的注视/膨胀不同：这次检查伪装载体与原实体是否连续，明确排除discard/new-spawn方案。它不能作为新的树精造型凭据。

现有TreeSpirit内类醒来时setTreeAwake并启动TREE_WAKE，不更换实体。休眠停止导航，每10tick扫描5格内有视线玩家；接受来自活物伤害也唤醒。既有同实体方案必须保留。

rootPoint在技能开始锁定，28tick前预告；根笼生成保留已加载、无水、稳固地面、视线、无碰撞与附近数量限制。根笼物件交物件专岗，不在本批重制。

树精六根根足受力、树心裂口开合和三段崩塌并未由蠹虫覆盖。
