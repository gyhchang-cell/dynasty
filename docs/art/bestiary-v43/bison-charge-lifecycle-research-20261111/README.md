# 野牛：身体、冲撞与恢复的完整源码研究

实际完整阅读Alex’s Mobs固定提交的ModelBison、EntityBison（含全部内部Goal）、RenderBison（含SnowLayer）、ModelBisonBaby，共4文件。查看原始图集/灰模卡。旧静态参考仍归原记录；不把幼体、冲撞分支、覆雪及剪毛变体增加计数。

主要学习：高前胸与低头成为一个前向体量，前腿属于前胸，后腿属于后躯；冲撞姿态渐变、关键帧和伤害窗口分别追踪。五步头部恢复不等于五步步态混合，Goal结束也不自动代表chargePartner清理。具体条件和未封闭边界见bison-whole-study.json。
