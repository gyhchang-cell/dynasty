# 狻猊：四足低姿态与头部坍塌续读

本批实际查看鳄、科莫多巨蜥和象的既有灰模绑定姿态图，读取模型低姿态、实体状态进度、保存范围及固定提交Renderer，并核对声明继承链。灰模图没有贴图和动画，不当作实机或材质研究完成证据。

三者均未在所查声明链定义专用死亡接地动作，沿用原版20tick移除与默认90度渲染侧翻，不能按三个物种新增三种死亡机制：

- **鳄**：晒背使身体下降，同时四肢局部反向平移并外展，手足反旋；头颚最终角度还受末尾覆盖影响。`DEATHROLL`是活体水中抓住目标后的攻击，不是死亡。无头颚求地面约束。
- **巨蜥**：坐姿有身体/前后肢/头部协同，角力另有叠加；无独立下颚骨骼，不能作为头颚接地直接实现。
- **象**：坐下时整体下降、四腿分向折叠，头和象鼻作局部补偿；坐与立由实体互斥。没有独立下颚，也没有专用死亡坍塌动画。

继续补读了**Mowzie食人花**的完整选定死亡流程：根部保留、头茎链失重、两步回弹、停止活体摆动；50tick动画在父类30tick移除。模型还按激活进度独立缩放/平移头茎，不能只看局部关键帧。它提供不同的相关头部控制策略，但没有证明狻猊所需的严格地面接触。

已有静态1000、原目标100条和前四项死亡策略研究均保留。累计相关专用死亡策略研究候选五项；本批三条活体低姿态另记，既不算三条死亡机制，也不升级为接地验收信用。当前限定修复的已映射验收登记仍为0；登记缺口1000，全历史可复用总量及最终缺口仍待核，不代表旧参考清零。
