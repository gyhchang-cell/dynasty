## 参考与造型

制作前查看 100 张不同的 [Skyrim 黄昏天气游戏截图](https://stepmodifications.org/wiki/SkyrimSE:Weather_Compares)。001–020 比较树林及落日下的暖色，021–040 比较山谷背景与前景留白，041–060 检查深色枝叶前的明度，061–080 比较金色树林与雪地，081–100 检查浓雾和荒野下的辨识度。它们是同一游戏的不同天气捕获，不是 100 款游戏，也没有冒称查看动画视频。

还阅读了 Minecraft 官方[樱花林介绍](https://www.minecraft.net/en-us/article/around-block--cherry-grove)中树冠下落瓣的说明，作为环境粒子与树林关联的参考；网页图像未成功加载，故不计入已查看的 100 张画面。未复制其他游戏的模型、纹理或动画。

100 个不同哈希、来源与尺寸在 `references.json`；原图与五张联系表只保存在本地 `build/cod3-golden-leaves-20261018/references`。参考的是黄昏色彩、疏密和轮廓，正式叶形由本项目五个硬边平面构成，没有运行纹理贴图或平滑渐变。

按照用户“参考过了再参考100个”的要求，新增查看100张不同画面，与之前所有 cod3 参考清单的图片 URL 和 SHA-256 均无重复。本项累计200张。追加画面来自同一 Skyrim 天气比较页：71张此前未查看的黄昏图、29张此前未查看的白天图；并非新增100款游戏，也不作为动画动作参考。

五组画面分别检查暗林/金色树冠、阴雨林谷、雪粒与过强橙红光、灰烬与黄叶对比、冷灰山地与金冠轮廓。新观察用于收窄阶梯叶尖（0.20→0.14格）和压低浅色面（`f0d084`→`e7c978`），保留赭金、硬边与深叶柄。落点中心从0.30提高到0.60格是另行发现的几何修正，保证最大尺寸叶柄也不穿地。

来源、100个新哈希、联系表哈希、逐组观察和实际修改对应关系见 `references-round2.json`；图片只在本地 `build/cod3-golden-leaves-second-study`，不进入模组。

## 接入和联动

`ScenicEventDefinition.of(19)` → `ScenicEvents` 保存/同步 → `Cod3VfxRenderer` → `ScenicLeafRenderer` → `ScenicGoldenLeaves.mesh`。

沿用真实森林标签、晴天、11000–13000 tick 黄昏触发与 1200 tick 寿命，保留既有编号、区域、种子及开始时钟。没有新增季节、任务、战斗或奖励系统。预览分支也使用正式渲染器。

客户端只读取已加载区块的 `MOTION_BLOCKING` 高度图，确认顶部带 `LEAVES` 标签，再向下检查实际方块得到落点。扫描最多 96 格，同一绘制批次缓存重复列；找不到落点便跳过。没有树冠的空地、裸露屋顶和山石不生成叶片；树冠下有屋顶时停在屋顶上方。不请求新区块、不摆放落叶方块、不生成实体或掉落物。

复查原生截图时发现一片暗叶进入屋顶下，原来的高亮像素阈值漏检。源码核实 `MOTION_BLOCKING_NO_LEAVES` 属于 `LIVE_WORLD`，不会随区块包完整同步，不能作为客户端落点依据。已改为上述实际方块检查，并为屋顶加入暗色像素检测和落点断言；证据见 `client-heightmap-fix.json`。

近/中/远保留 96/56/24 片叶子，最多 480/280/48 个面，低于清单的 500 粒子预算。远处与 MINIMAL 用小金点，共同叶片不换随机位置或重启时间；额外叶片在 LOD 边界前淡出。正式渲染使用世界深度、本地光照和近镜头淡出，叶子不会保持夜间满亮。

与已有天象共用寿命/区域衰减和原来的包清理链；黄昏与雨天可见性独立定义。低音量草叶沙沙声仅在区域锚点 16 格内、有效黄昏且晴天时每 120 tick 播一次，使用原版草叶声、AMBIENT 分类及原有客户端主音量；测试客户端始终静音。
