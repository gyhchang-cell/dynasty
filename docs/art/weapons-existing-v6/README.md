# 现有武器第六轮审稿

交付5种不同剑形、5把加强外饰的剑、5把弓。全部15个ID已有模型和中文名称，不新增注册。30张32×32透明PNG，五弓各有待机和三段拉弓。可编辑像素源：tools/art/weapons-existing-v6/create.py。

这批是用户要求先看思路的审稿，未覆盖运行资源或精修原图，没有游戏验证。天子剑未选中。神臂弓的草案使用已接受的原版猎弓骨架，未修改原128px神臂弓。

## 参考

references.json列出1000份按RGBA去重的剑类贴图，349份来自本机登神者：天阶咏叹v1.5。包含同剑的材质、状态和物品栏版本，不宣称1000种独立造型或1000个模组。十页参考图已视觉检查，剔除发现的升级图标、材料、UV展开图和零件；来源和排除记录均保留。参考仅用于比例与形状研究，没有把模组参考贴图写进交付PNG。

观察：登神中的短匕首靠短宽叶身区分，重剑靠宽厚刃面；细刺剑需要明确护手；高级款的辨识点应集中在剑格和弓臂外侧，避免全身花纹。本轮分别尝试鱼肠短宽叶、巨阙宽重、龙渊修长、流云弧刃、桃木平肩符刃；高级剑保留上一版主体轮廓，加银翼、玉叶、回钩、紫银展翼和仪仗金格。弓用原版骨架，按名称增加骨角、雁羽、狼牙、日轮和火羽。

## 检查与修订

实际查看三组审稿与全部20张弓阶段；修正流云剑尖高光与暗轮廓脱节，神臂弓加强外侧铜箍。十把剑8邻域轮廓均单连通。全部PNG为硬边透明像素；高级剑的底稿轮廓保留，弓底稿所有非透明像素逐像素保留。已有运行物品PNG在生成前后哈希相同。第一次全目录哈希检查曾遇并行修改，没有回滚或覆盖；重新记录当前快照检查通过。

检查是离线像素和资源身份检查，不代表模型手持或游戏加载验收。预览打开index.html，原PNG和生成源打包在existing-weapons-review.zip。
