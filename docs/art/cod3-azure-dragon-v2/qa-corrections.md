# 验收记录

首次构建的release打包完成，专用服6项中洞穴放置检查失败：放置前后全世界实体总数不等。该检查属于前批洞穴回归，不是青苍龙影建模。原日志保留于 `build/cod3-azure-dragon-20261020/build-v1.log`，不能用后续成功覆盖首次失败。

追加新实体类型/位置诊断后，复跑6项通过（`server-diagnostic.log`），未修改任何生产洞穴资源。首次日志只有数量判定，没有实体差异，不能确定首次变化的具体实体。

检查原实现发现放置过程会加载模板覆盖的新区块，加载其已有实体也可能改变全世界计数。因此验收脚本在计数前先加载完整模板区域，并同时断言NBT的entities列表为空、放置后没有新增UUID；失败会输出新增实体类型和位置。该修正仅在隔离测试源内，不进入release，也不删除或屏蔽实体。使用另一份全新临时服务器目录复查，最终结果以 `server-final.log` 为准。

客户端使用最终geo、animation、PNG和独立冻结运行目录，master=0且隐藏自己的窗口；用户现有客户端及存档未作操作。音效只核对增益与距离契约，不声称静音运行实际听过龙吟。

原生v1完成前12场景，在雨天配对像素检查失败。实际打开雨天截图后没有龙：旧分类器把雨中变化的绿色草地也计为龙。修正分类为实际青色图集的B>R条件，保持差值和像素数量阈值不变；另外增加雨天/夜晚/黄昏结束时ACTORS为空的独立断言，确认渲染器没有创建可绘制模型。原生v1失败记录保留，不能当作通过；最终以完整重跑v2为准。

v2在同一雨景仍有1301个分类像素：蓝色雨幕叠加草地也会形成青色，跨时刻图像差分无法可靠区分。v3对雨天单独使用原生生产ACTORS为空且共享可见性为0的断言，保留雨天成对截图人工检查。其他16场景保持像素数量/差值检查，未提高允许阈值。模型、贴图与生产代码在这三次间没有更改。最终完整验收以v3为准。
