# Mythic Metals 青铜甲与 Hallowed 穿戴研究

两套此前均未列入当前账本。来源是官方 Mythic Metals 的 Minecraft 1.20.1 固定提交 `2118186af2d5d418d2d41b91a4583ade6a1c39f6`。只保存定点源码和纹理，逐项比对 Git blob 指纹与本地 SHA-256。离线查看了两套四槽的原始库存图及实际使用的头盔、护腿纹理裁片。

青铜四槽通过 `ArmorSet` 创建标准 ArmorItem。材质名为 `bronze`，使用原版双层路径。头的主层从第四行开始打开，外帽面全透明。护腿前片最后五行有像素，最上行在中间留两格缺口，余下四行连续，前后和两侧有所区别。这是一套直接适用于 Dynasty 青铜候选的材料及腰带观察。标准双层机制与已收录铁木等例子近似，尚不能把它算成独立设计。

Hallowed 套装只有头盔创建 `HallowedArmor`。Fabric 注册的专用渲染器选用 `hallowed_model.png`，通过头部根绘制倾斜面甲和两侧翼，其余三槽继续用标准 ArmorItem。护腿仅在躯干底部四行保留腰带，前面上沿中间六格着色。额饰与常规甲身分走两条路径，可用于比较天将和玄天的装饰安排。它不能作为 Dynasty 直接移植几何的依据。裁片只说明主壳与面甲各自的透明区，面甲带旋转和不同面尺寸，实际脸部遮挡需要结合运行模型判断。

和账本中同时为多个槽位替换模型的 Electrum 比较，Hallowed 的替换范围仅限头盔，腰带仍留在原版护腿 UV 中。和 Tyr、Draco 对照，Hallowed 的面甲有独立几何及转角，属于不同实现。将此例作为新增整套候选提交语义去重及验收，当前新增正式计数为零。旧账本中已核实参考继续有效，制作门槛仍未通过。
