# 王朝资源风格约定（2026-09-25）

- 新饰品沿用用户认可的 journey-polish-v4 三件像素饰品风格：明确像素簇、清楚轮廓、少量硬边阴影；不要重新改已验收的饰品。
- 武器保持原有精细风格，不批量降为低分辨率像素图。
- 盔甲保持精细材质，但物品栏必须一眼认出头盔、胸甲、两条裤腿和一双靴子。不可用长袍或人物肖像代替。
- 所有新手持图都须运行 generate_handheld_edges.cjs；弓还须运行 generate_bow_models.cjs。保留整张正反面图，只为真实不透明轮廓生成侧面，避免半透明边缘噪声长出梳齿。
- 图标预览不是穿戴模型、第一人称或实机验收，交付时分别注明。
- 建筑优先保证入口、楼梯、照明、书架与操作空间；不靠巨大实心台基填体积。玩家搭建变更先只读快照和差异审查，再写回模板，不直接覆盖运行中的世界。
