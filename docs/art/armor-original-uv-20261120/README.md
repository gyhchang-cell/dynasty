# 五套旧盔甲穿戴图的来源与范围

青铜甲、将军铠、玉甲、天将云铠、玄天真龙甲的 10 张穿戴图，均与各自能在本地 Git 找到的最早版本逐字节一致。用提交 d00079658 中保留的原生成器和配色在内存中复现，10 张也都逐 RGBA 像素吻合。将军铠与玉甲来自 `gen_armor_layers.py`，玄天来自 `gen_dynasty3.py`，青铜是将军铠原图乘色，天将是玄天原图乘色。这个结果把范围从「履历不足」缩小到「现有图仍是可复现的原模板」。本地 Git 之前没有留存的历史无法复核。

五套皆列为仅限穿戴 UV 的修复候选。原稿对照页显示，库存头盔都留有下方开脸轮廓，但当前第一层的头部和外帽前脸分别是 64/64 不透明像素，在实际被头槽绘制的区域盖住眼鼻面。第二层护腿会绘制身体和双腿，五套的躯干四个侧面均填满十二行，前片还画有胸纹。这样只穿裤子也会显示完整的内层胸片。第一层候选只涉及开脸和保留材质的衔接，第二层只涉及将躯干覆盖归回腰部。图标自身的精致旧稿保持原样。

这批只核对项目内历史与已固定的 Forge 模型 UV。对照页使用当前原图裁片，不代表游戏画面。五套候选须等适用参考门槛通过后再进入制作，完成后还需实机验收。
