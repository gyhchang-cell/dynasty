# 后羿弓动态与神兵特效样板

这批按照原版弓的轮廓和拉弓模型切换方式，重做后羿弓；没有复制原版贴图。龙渊剑沿用上一批已经认可的 64×64 外观，新增持握与命中的粒子效果。

## 后羿弓

- `houyi_bow.png` 是静止状态，`houyi_bow_pulling_0/1/2.png` 是起拉、蓄力、满弓三个阶段，全部为独立 64×64 透明像素画。
- 客户端注册 `dynasty:pulling` 与 `dynasty:pull` 属性，按原版弓一样的 0.65 / 0.90 阈值切换模型。
- 模型不是单纯的平面图：`generate_houyi_voxel_models.cjs` 根据每帧透明像素生成有厚度的方块体，GUI 使用轻微侧转角；这是“立体 + 随时间拉弓变化”的试玩样板，并非真正的四维渲染。
- 蓄力时玩家前方出现金色粒子法环；松弦时法环爆发；射出的后羿箭有短粒子尾迹，命中时再出现小法环。仅为视觉特效，不改箭矢伤害。

### 搭弦方向修正

上一版三张拉弓图把箭头画在右侧、箭尾放在握把旁，方向反了。现在木质弓背在左、弓弦和射手在右；**箭头朝左，右侧的白色羽尾扣在弓弦中央拉点**。起拉、蓄力、满弓的拉点逐渐向右，箭和弦保持连接。只改三张拉弓帧，不动已定稿的静止贴图、剑、战斗数值或粒子逻辑。

## 龙渊剑

- 持握时在人物手边有蓝色法环与微粒；刚拿出有一圈加强效果；直接近战命中时目标周围有蓝色法环和电火花。
- 两件物品在物品栏都带动态附魔光泽。其他武器、盔甲、官阶／天子法阵暂未改动，待风格确认再推广。

## 复现与检查

- `before/` 保存上一版弓的 PNG 和模型；`before/reversed_game/` 与 `before/reversed_sources/` 保存这次修正前搭弦方向错误的拉弓帧，方便比较和回退。
- `sources/` 是当前四张高分辨率透明原画。最初提示词见 `prompts.json`，三帧方向修正及满弓细调的最终提示词见 `correction-prompts.json`；均使用内置图像生成工具逐帧编辑。
- `sh tools/art/export_houyi_bow_v2.sh` 导出四张 64×64 游戏 PNG；`node tools/art/generate_houyi_voxel_models.cjs` 重新生成四个立体物品模型。
- `four-stages.png` 是修正后的四阶段放大预览；`comparison.png` 直接对比错误箭向与正确搭弦；`pull-preview.gif` 播放四帧。它们是贴图预览，不是游戏实机截图。修正前的整组预览在 `before/reversed_preview.png`。
- `node tools/art/verify_houyi_bow_v2.cjs` 验证四帧尺寸、透明度、模型体素轮廓与贴图一致。离线构建通过；开发客户端已进入主菜单，资源加载日志没有出现本批模型错误。但尚未进入世界检验实际粒子、第一人称手持角度和整合包中其他模组的兼容性。
