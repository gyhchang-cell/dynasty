# D104 twilightforest:arctic 整套参考补证

北极毛皮甲已有D86整套源码研究：同一arctic_fur_leather家族，不能重复算作新设计。本轮14张本地Jar原图均查看，其中12张与D86固定源码PNG逐字节相同；另2张无后缀合成图不被已读getArmorTexture返回。

实读本地4.3.2508的TFItems四个注册bootstrap114–117及factory95–98，均创建ArcticArmorItem、ARMOR_ARCTIC及对应四Type。getArmorTexture在LEGS选择2、其余1；第四参数null用_dyed，非null用_overlay。客户端扩展实际选择ARCTIC_ARMOR_INNER/OUTER后创建TFArmorModel；层定义到ArcticArmorModel.addPieces及64×32已读。
