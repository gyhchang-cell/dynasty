# Tidesinger 入账复核与 Botania 跨槽腰片对照

本次筛过历史账本的 215 个学习组记录，标出 35 个提及腰带、披片或裙部的组作去重线索。进一步对照 Mythic Metals Tidesinger、Oreganized Electrum 和 Botania 固定源码。筛选覆盖的是已有组的文字记录，不能代替逐套去重和验收。

**Tidesinger 保留候选，暂不正式入账。** Botania 已实现单穿护腿显示腰带，同时不显示胸片，所以仅凭腰带归护腿不能判定 Tidesinger 独立。Tidesinger 的差别是用同一躯干根切换胸片、腰带和腰扣的子件可见性。Botania 则按槽选不同网格。Tidesinger 的额冠、鳍和护腿腰扣也有自己的造型。还需与其它分段甲和海洋甲候选逐套对照，取得独立验收。

本批用 Botania 固定提交 `0c06dcf7ae9555d52885f913ecd769ceb94fa823` 补查魔力钢、泰拉钢和魔力布。固定 35 份源码与资源哈希，实际查看三套各四张图标和一张原生穿戴图集，共 15 张 PNG。独立看了腰部正片及相邻裁片。其护腿槽选择内层网格，并显示躯干和左右腿。魔力钢的内层腰带高三像素，泰拉钢高五像素，胸部主体由外层网格绘制。魔力布的内层没有躯干甲片，两块裙片挂在左右腿下，外层短下摆随胸部主体显示。三套均有既有组归属，这轮不重复计数。

对青铜、将军、玉、天将和玄天，保留「护腿只在腰部有覆盖、胸片留给胸槽」作为验收条件。真实披片如果随腿动，则应区别于错误填满第二层的胸片。当前五套修复仍限已有原版 UV 范围。裁片无法验证服装随动作的遮挡，实机留待验收。1000 个独立参考门槛尚未通过。
