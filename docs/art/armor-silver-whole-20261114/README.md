已查看4张16×16原图标、两张64×32原生穿戴图，以及最近邻原图页和全部60个原始UV矩形。PNG保留原字节；分析页非成稿、非游戏。银灰白主面、蓝紫灰阴影、深蓝灰轮廓清楚分档，无外挑冠角；短宽胸甲有肩部负空间与腹部横亮带，直裤腰带横贯，两只长筒靴分开、脚尖小阶梯外伸。头盔为封闭横缝面甲，不满足所有普通甲应有的倒U脸口，作为不能直接照搬的反例。亮点较碎，不能把全图小金属斑复制到项目，宜只学主面、暗侧和关节分区。

逐面裁片：头部侧面和正面沿帽下半留空，背面保留银壳；hat六面全透明。胸前、背后均以大块亮灰蓝面配深色分隔，顶部/底部大量透明；左右袖根用相同UV而保留镜像标记。腿槽腰壳与腿壳分区，腿甲图下部逐渐留空；足槽下端有靴面，顶端留空，不能将其视作整条银腿或遗漏。图集透明区与槽位几何必须一并判断。
