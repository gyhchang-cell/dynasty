## 玄天头盔光效专项

当前框架为标准 Forge 1.20.1 盔甲几何，玄天装备还通过独立的玩家渲染层按装备槽绘制青色菱形。源码与旧发布说明都表明，这个光效不会重写穿戴 PNG。

在默认头部局部正视投影中，主头面 Z 为 −0.3125，光效为 −0.319，外帽面为 −0.34375。光效在主头之外、外帽之内。光效投影在外帽 UV 的保守包围区 [43,9,45,12)，该区目前完全不透明。后续开脸若切入该区，可能露出现有青光，影响眉心与眼鼻留白。首先核对这一处的纹理与既有光效是否重叠，再看头部抬低、45°和全套穿戴。胸、腿和靴的固定光效位置也已按各自槽保存。这里是同枢轴正视的静态推断。真实深度顺序、头部姿态和资源覆盖仍须实机观察。

1000 个适用独立参考门槛未核定通过。本轮只核收 Dynasty 既有发布与穿戴来源，新增正式参考计数为 0。六项已修正旧测试沿用主协调结果。未改运行资源、测试或任务清单，未启动游戏。
