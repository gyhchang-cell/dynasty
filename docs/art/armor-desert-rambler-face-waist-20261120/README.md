# 沙漠铁甲和漫游者皮甲的完整穿戴对照

这轮补读两个尚未计为独立设计的四槽参考，核对 18 张原生图层。Atum 沙漠铁甲有四件双层物品图标与两组双层穿戴图。Jerotes 漫游者皮甲有四张物品图标和两张穿戴图。对照页按声明叠放 Atum 原图层，保留两层各自的透明掩码记录。颜色预览没有模拟染色、照明或游戏穿戴。

Atum 四槽注册把对应装备类型交给 `WandererDyeableArmor`。它继承的 `TexturedArmorItem` 把腿槽指向第 2 层，其余指向第 1 层，并按基础或覆盖分支选择普通图与 `_overlay`。两个实际源层叠合后，头面有三行完整额带和两侧竖垂片，中间六像素宽的脸区连通到下缘，外帽正面留空。护腿躯干四面只覆盖 V=27–31，两盖面透明。可供青铜与玉甲参考开口和护颊如何衔接。沙漠铁、金、钻石属于已归档的沙漠材质家族，此处只固定铁甲默认结构，不把叠层或染色拆计。

Jerotes 的四个构造器分别绑定头、胸、腿、足，已复核固定的 `getArmorTexture` 反编译记录，只有腿槽返回第 2 层。主头面保留较厚的皮盔边，外帽正面在前六行有少量像素。主头面与外帽合看后，眼鼻区仍有留白。这个实现可供天将和玄天参考额饰少量覆盖的处理。腰带在同样的最后五行，前背色块与侧面接续，上下端盖透明。旧账本已将它收录到 Jerotes 棕色猎人皮甲家族，本轮不增独立计数。

本轮新证据支持五套候选的开脸遮挡和护腿腰部复核。适用 1,000 个独立参考的制作门槛仍未通过，原修复坐标与保护范围继续沿用。
