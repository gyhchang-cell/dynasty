# 盔甲参考续作：施法、板甲与穿戴材料

本批实际逐页查看45个新名称族的144张原始物品图标、101张穿戴图集，并读取两份原生96×96几何文件的相关骨骼及逐面UV。归并为34个保守设计学习组；复用前批23组，合计57组。部件、变色、叠加层和版本均不增加独立设计数，尚未达到1000个真实独立相关参考要求，不据此开始制作。

来源是既有固定本地JAR及研究索引；`provenance.json`记录归档、条目、SHA256和原尺寸，`semantic-review.json`记录逐组观察及实际查看的7页图标、17页图集。原生几何读取见`native-geometry-study.json`，命名关联不代表已经证明运行时渲染绑定，也不是游戏内验收。

`application-principles.json`将观察落实到三个既有问题：短袖孤立腕底面的去留必须符合袖长意图；旧款整片躯干要区分长袍、板甲及有意封闭的面甲；鸿蒙、朱砂和织锦穿戴材料应服从已认可图标的白金、红白、紫白身份。这里只保存处理原则，没有改变生产贴图。
