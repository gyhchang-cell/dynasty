本轮 293 张样本 RGB 色数中位数 **8 色**，前 8 色占比中位数 **100%**；这是原生 16×16、建筑/自然表面优先选样的结果，不是全部模组贴图的统计推断。部分图来自功能模型的共用材质/粒子代表面；用来观察木材、石材、金属的调色与颗粒，不当作完整方块模型。

扩大后仍支持初步结论：MC 风格不等于“把高清图缩到 16×16”，而是直接为网格设计明确图案与色簇。Chipped/Quark 的砖面、Twigs 的柱纹、Macaw 的建筑面、多种生态模组的木板都把结构放在明暗之前。高饱和幻想材质仍可成立，但普通砌墙材质需要安静、可重复，不应满墙都是中心宝石与强高光。

## 真正影响风格的差别

160 张样本的 RGB 颜色数中位数为 **10**；出现频率最高的 8 色覆盖像素比例中位数为 **96.09%**。相邻像素完全同色比例中位数为 **26.25%**，相邻亮度绝对差中位数为 **14.445/255**。这里的亮度采用 `0.2126R + 0.7152G + 0.0722B`，只是一种可复核描述，不能单独代表美术质量。

对照当前 V7 源资源（只读）：

| Dynasty 贴图 | 尺寸 | RGB 色数 | 前 8 色占比 |
|---|---|---:|---:|
| palace_bricks | 32×32 | 374 | 11.4% |
| jade_block | 32×32 | 522 | 7.7% |
| marble_block | 32×32 | 252 | 15.9% |
| cloud_stone | 32×32 | 391 | 21.1% |
| jade_soil | 32×32 | 370 | 18.5% |
| marrow_vat | 32×32 | 788 | 3.7% |
| vitality_shrine | 32×32 | 643 | 6.2% |

因此问题不只是 32×32：高分辨率生成稿缩小后仍有大量近似色、细密明暗和逐像素渐变。它会看起来像被像素化的插画，而不是先按 16×16 网格设计的游戏材质。

## 逐类观察

- **暮色森林**：砖缝和结构优先，石砖中部是大片同一明度的灰绿，裂纹不平均铺满所有砖。铁木、骑士金属依靠规则轮廓和有限亮点表现材质。部分旧石材确有很多近似颜色，因此不能把“少于 12 色”说成暮色的统一规范。
- **Biomancy**：肉质依然能是 Minecraft 风格，靠 2–4 像素色簇、有限粉红/暗红、少量点状器官来表达，不靠摄影式湿润反光。功能面由边框、孔洞、中心区组成，远看能读出用途。
- **Create**：铜片和黄铜的形状非常清楚，铆钉/边框只占少量像素；视觉逻辑是工业结构，不是满图随机金属噪声。
- **农夫乐事 / Decorative Blocks / Vinery**：继承木种色域，横木和竖木按木纹方向区分；把手与面板分区清楚，不需要模拟真实木板照片。
- **Deeper and Darker**：暗砖用 6 色就能表达四块砖和接缝；发光色只是矿簇或少量功能亮点，不把整个背景变成发光油画。
- **灾变 / Aether / Goety**：允许更鲜明的幻想配色与雕刻，但首先保留大轮廓、对称结构与 1 像素线，不意味着每块普通砖都要带宝石、徽章或重度反光。

## 单张原创样稿建议：灰绿宫砖

先只做一张普通砌筑面，不做高级纹章面，不批量替换：

1. 原生逻辑网格 **16×16**，不使用平滑缩放、模糊、抗锯齿、镜面光斑。
2. 两行错缝砖，横缝位于 `y=0、8`。上行竖缝 `x=0、8`，下行 `x=4、12`；边界连续，必须看 3×3 平铺，不仅看放大单张。
3. 约 **8 色**原创灰绿调色板：`#424c49 #515e58 #62726a #728278 #839187 #94a095 #a1aca0 #b3bbae`。不能以降色替代构图，但降色可以去掉生成器残留的细碎近似色。
4. 砖缝主要 1 像素；砖面 2–4 像素色簇，不在每个像素加入随机噪声。最深色集中于接缝，最亮色仅少量断续磨损。
5. 不画每块砖完整的亮边，不做浮雕圆角，不画中心宝石、金边、发光图腾，不让砖块像巧克力块或皮革软垫。
6. 原尺寸可读、3×3 平铺不过密、放到原版石砖/安山岩/深板岩旁不跳风格，再给用户看样稿。只展示，不部署；用户明确选定后再扩大范围。

这些约束来自视觉观察后的设计建议，参考图像素和图案不复制到原创纹理。
