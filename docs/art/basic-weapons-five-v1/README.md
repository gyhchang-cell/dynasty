# 五件基础武器风格样稿

用户要求先看五件，重点考虑手柄粗细，保护精修武器。采用内置image_gen分别生成，提示词见prompts.json，实际尺寸与颜色统计见review.json。

- 木矛：木质削尖端，长细杆，区别金属枪。
- 石戈：横向石刃与绑缚连接，细长杆；当前轮廓仍有石斧观感，需要用户审阅。
- 铁剑：对称直刃、小护手，短柄窄于剑身。
- 猎弓：紧凑弓身、局部握把、两端相连的直弦；当前弦显得偏粗，正式像素化时需控制。
- 环首刀：单侧亮刃、短细握柄、带孔环首，与双刃铁剑区别。

已实际查看五件旧图及长弓、长枪。长弓现有细节较多，本次避开。所有图稿在本目录独立保存，未替换任何正式物品、模型或士兵内嵌武器资源；天子剑等精修内容未动。未启动Java。
