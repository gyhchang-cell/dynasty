等级几何与身份要求性能边界
普通人形弓兵修长轻装，叛军单肩杂甲；必须有真实腰、肘、膝、腕、脚，不能只换皮肤。目标不超过 180 个实体几何块；本轮弓兵 117、叛军 108（包含隐藏变体）。
精英 / 叛将精英刀兵下沉重心、多层胸肩甲；叛将独立冠盔、护心镜、肩甲、长甲裙、披风及重刃。将领不直接等比放大普通叛军。精英目标不超过 240 块，将领不超过 320 块；本轮刀兵 150、叛将 159。
最终 Boss保留已确认的最高规格。每个 Boss 独立主题、剪影、身体比例、武器及动作语言，不套杂兵模型。后续修改前先做身份设计与剪影验收。沿用各 Boss 已有独立预算；不能为统一模板降低现有质量。本轮不重制。

关节链：pelvis → waist → abdomen → chest → neck → head；shoulder → upper_arm → elbow → forearm → wrist → hand；thigh → knee → shin → ankle → foot。衣摆、披风、甲片依附相应部位，不以贴图替代所有体积。

动作：胸肩参与射手瞄准，双臂使用两段逆运动学，弓弦端点与手跟随骨骼；近战用腰胸、肩、肘、腕依次发力。叛军挥击 14 Tick、刀兵 18 Tick、叛将 24 Tick，实际命中位于中段关键帧；前摇期间没有提前扣血。伤害和攻击目标由服务端决定，只同步每次挥击的起始时间。

个体：三套受控装束组合，由保存并同步的实体 UUID 稳定选择；脸宽、胡须、束发、头巾垂带、半肩披布、额脊、腰包按职业组合。不用每次渲染随机抽取，重进世界不会变脸。暂不新增实体 ID，不改掉落和基础属性。

原创与材质：人体、服装、甲胄、武器几何及配色由本项目代码构建，未移植其他整合包资产。使用 Minecraft 原有中性像素材质作为细微表面颗粒，通过材质色区表现布、皮、甲和金属；不是写实皮肤或高清噪点。共用一个纹理通道，不为每件甲片增加单独纹理。

验收门槛：正面、左右 90°、背面、前后 45°，加纯黑剪影。检查头身、胸腰骨盆侧面体积、衣甲层次、武器握持、运动时接缝与遮挡；剪影不分职业就返回几何阶段，不能靠重涂颜色交差。

测试与进入游戏

主要移动 Bug 是战场内部范围 deflate(.4) 把合法的 Y=65 落脚高度排除，服务端每 10 Tick 重传送、清速度并重设视角。现已删除该周期定位路径、献祭末段牵引和客户端输入清零。首次进入仍安全落地一次，重进同场地不再次锚定。

保留竞技场防拆与防越维度逃逸，不限制正常 WASD、跳跃、冲刺、潜行、视角、战斗和弓/食物使用；准星指向场地墙面不再吞掉普通物品右键。

客户端逐项记录 · Boss 维度实测画面。服务端回归包含两人不同站位、地面与空中、登场各阶段、阶段保存恢复、献祭末段自由移动，以及挥击关键帧只命中一次。
