# 第二批：鬼面蝠、穴居盲骨鱼、浮溺鬼

2026-10-11 凌晨。首批三个已通过 solo3；本批独立制作与验收，不能沿用上一批 PASS 当作证据。先核对原模型与保存基线完全相同；没有本聊天的游戏验证在运行。

## 制作前的体块与动作计划

- **幽灯鬼面蝠**：压低蝙蝠躯干，8×7×6 的胸腹、10×6×7 的鬼面头，粗阶梯耳朵；灯笼在双爪下方，保留火焰独立骨。双翼用肩翼骨与四条分叉翼指，硬边薄长方体组成阶梯翼膜，展开约 40 像素宽、全高约 23 像素。层级 `root → body → head/face/left_wing/right_wing/left_claw/right_claw/lantern → flame`；翼指仍归左右翼。待机轻拍，巡航大幅同步拍翼，俯冲收翼后展开，炫目时提灯，死亡折翼伏倒。不是带翅膀的人。
- **穴居盲骨鱼**（原资源 ID `xueju_mangguyu` 保留）：厚重无眼鱼颅、可张开的方颚，头部 12×9×10；八节躯干从 11 像素逐步收至 3 像素，鱼尾分上下叶、左右有宽而短的胸鳍，背侧粗红色骨棘。最初预计总长约 43 像素，实际导出鼻端至尾端约 54 像素、高约 19 像素。层级 `root → spine_0 → spine_1 … spine_7 → tail_fin → tail_tip`，颚在首节、胸鳍在第二节，背棘与血带保留原发光骨名称。待机缓慢摆尾，游动依次传波，扫尾在第 16 tick 达到摆幅，骨鸣在第 30 tick 张颚扬背棘，死亡折弯成沉静骨架。保持漂浮鱼类的专用骨架。
- **煞水浮溺鬼**：具有独立骨盆、细腰、前倾胸、鬼头，身下为三级阶梯水裙与水花基座，不用人形双腿。下部宽约 16 像素、窄腰约 6、胸约 10，头约 8；高度约 30 像素（约 1.9 格）。层级 `root → body（必须在地面原点） → pelvis → waist → wave_1（胸） → wave_2（头） → hair_*`，双臂各三节水鞭与三条水指。头发以粗方块垂发遮额、不遮住口鼻，旧骨名保持。步态是水裙波动；挥鞭有收肘预备与第 14 tick 的甩击，水池沿用现有渲染器缩放地面 `body`，死亡下融成水，不能新增玩法逻辑。

三者都使用实际 16×16 白底、一像素留边、2×2 色块的正面肖像小图集，四种纯色含白底，UV 复用其中的纯色岛。骨鱼用骨白、深色、血红；蝠用深墨、灰骨、幽绿；水鬼用亮灰水色、深青、浅绿，考虑现有透明着色器。所有新资产为原创 Cuboid，保留已有 clip 名称和持续时间，动作触点按现有服务端时间制作。离线五视图和真实客户端动作需逐项验证后填写结果。

## 验收状态

已经通过 `validation-floaters.json`：3 个模型共 21 个原 clip，旧骨名称全部保留，16×16 四色/白边/2×2 色区、有效 UV、父子层级、bbmodel 坐标及每 0.25 tick 的地面检查通过。蝠 18 骨/59 Cuboid；鱼 28 骨/58 Cuboid；水鬼 26 骨/42 Cuboid。首批九项资源哈希未变。

灯笼双爪归到提灯骨，提灯/摆动时仍扣住把手；浮溺鬼挥鞭的第二节在 14 tick 沿长轴延伸至 2.2 倍，再收回，侧面检查见 `shashui_funigui-whip-side.png`。没有改变命中范围或技能时间。

Java 17 离线构建已通过；`jar-validation-floaters.json` 确认生产 JAR 含本批九项实际资源，SHA-256 与验证数据一致，独立 QA 不进入 JAR。`generator-protection-floaters.json` 在隔离目录实际运行旧生成器 `--bat`/`--fish`/`--drowner`，确认不会覆盖本批已制作资源。

`native/floaters1` 失败原因是 QA 把普通未施法的 `start=-1` 误当作等待入水的动作；已修正夹具分支，未修改生产逻辑。`native/floaters2` 已通过 37 个真实渲染姿势及资源重载，服务端正常启动的动作与客户端 clip/epoch 同步、当前资源与实际快照 SHA 一致。浮溺鬼使用真实三格深池，入水标志由正常实体 tick 得到，特殊动作目标在 1.4 格内；蝠俯冲从高于目标 1.8 格的位置真实启动。

查看实机截图时发现蝠死亡后实际下落至地面，原固定高位相机裁掉部分尸体，水池形态则被水面遮住；因此再进行 `floaters3`，仅修正独立 QA 相机跟随尸体和下水查看水池形态，资源不变。最终该轮 **PASS**，37 个实机姿势与资源重载通过；逐个核对四个实机方向、触点、死亡，蝠尸体完整入镜，水下可见水鬼展开的扁平水池和死亡融化形态。快照与当前九项资源及 JAR 哈希相符。最终构建日志为 `build-floaters-final.log`，原失败记录保留。

水鬼沿用已有蓝绿色透明渲染，低于水面的水裙和死亡/水池形态会受水面遮挡；整模形体另有五视图检查。骨鱼沿用已有 0.72 透明度与发光背棘，死亡逐渐消散。美术加载/动作验收不代表 Cod2 完整生态、地牢或战斗条目已经完成；本批不删除对应玩法提示词。
