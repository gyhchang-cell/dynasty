# 百草化萤·大地绿脉

cod3 奇观 #7。原先与其他光点共用的简单上下浮动网格，改为低处草木绿脉和独立升起的萤点。实际源为 `ScenicFireflies.java` 与 `ScenicFireflyRenderer.java`，实际入口 `Cod3VfxRenderer` 的 `scenic_07` 分支；预览分支同样调用正式渲染器。

## 新增100张参考

本次新选100张《Ori and the Blind Forest》[Steam游戏截图](https://steamcommunity.com/app/261570/screenshots/?p=1&browsefilter=mostrecent)，包括游戏过程与过场，不是100款游戏或动画视频。先筛掉近似图，再实际查看156张候选联系表，剔除56张标题、设置、技能菜单、非游戏插图和相近构图，最终保留100个不同SHA-256文件。来源、作者和单图页面在 `references.json`；审阅过程与选用/不选用依据在 `reference-review.json`。参考原图仅保存在本地build，不作为模组资源。

主要借鉴林下低处密集亮点与高处稀疏光点的关系、暗部留白、光点与植物位置的联系。没有复制角色、树形或纹理；大面积爆光和柔光只作不采用的对照。正式表现使用四种纯色、硬边小平面和块状折线，不改变全局天空、雾或世界光照。

## 实际表现与联动

- 近景96只，每只两个交叉萤核和两片暗翅；中景56只、远景与MINIMAL为24个交叉小绿点。
- 八簇地面分叉绿脉，每簇12个方块对齐的小平面，中距离渐隐，远处完全省略。合计近/中/远480/208/48面，低于清单600预算。
- 各只萤点依据服务器seed、start和绝对年龄独立升起、漂移、闪烁与振翅。共享个体切换LOD保持轨迹，新增个体与翅片在边界前淡出；迟到观察者不重启动画。
- 复用金叶已验证的已加载区块采样：从同步树冠高度向下检查实际方块，最多96格。只有土/草标签与苔藓表面发光，裸岩、屋顶、液体、缺失区块跳过。不使用未同步的NO_LEAVES客户端高度图，不请求区块。
- 继续使用原定义中的主世界森林、满月、夜雨、1800tick寿命。清单10.3.1已明确以满月夜雨替代不存在的春季系统。客户端同样检查夜晚、雨量与月相；白昼、放晴和非满月不残留绿光。
- 沿用原世界区域与客户端退出清理、显示总预算和透明深度绘制；不生成服务器实体、碰撞、伤害、掉落或声音，不修改其他开发者的战斗与任务逻辑。

## 验证

`FireflyGeometryQa.java`直接检查正式几何4,525组种子/年龄/距离组合，涵盖预算、地表高度、无效地表、绝对时钟、寿命、天气/月相与LOD共享路径。软件预览来自相同几何，包括四个方向、局部和黑色剪影；动图为加速采样，不是游戏录像。
