# 关羽与神龙模型重制

本轮只重制关羽、青龙、金龙及相应材质和渲染，不重复改动其他物品、任务系统或武器数值。所有模型都是真正的三维表面，不是把参考照片贴在一张平面上。

## 关羽

- 保留约 9 格高的守护像，重做连续面部、鼻梁、眉眼、耳朵、长髯、手指、衣袍和披风。
- 增加胸甲龙面浮雕、肩部甲叶、护胫、冠饰，以及青绿金纹织锦。
- 刀杆沿握持手布置在身体外侧；刀刃、刀杆、刀穗与非握持身体的面片交叉检查为 0。刀杆与护腕装饰的最小检查间隙约 0.13 格。
- 70,788 个四边面。面数只用于性能和完整性核对，不等同于美术质量。

## 青龙与金龙

- 重做颅骨、上下颌、獠牙、眼睑、分叉鹿角、长须、鬃束、四肢、对生爪和尾部。
- 43,272 个四边面/条；金龙与青龙使用不同材质配色，双金龙镜像朝内。
- 修复邻接鳞片互相切穿的问题，并重新检查鳞片与躯干间距。
- 天降龙按真实鼻尖而非模型原点对准目标，避免落点偏离；原来的延迟伤害结算没有改变。

## 材质和性能

- 为关羽、龙增加独立的实体材质着色：平滑法线、金属高光、补光和深度遮挡。后羿原有半透明效果不改动。
- 织锦仅作用于指定青绿衣料，不会印到脸、胡须和金属上；纹样随模型移动而非随屏幕滑动。
- 完全显形的关羽和青、金龙使用缓存模型，避免每帧重新处理大量顶点。显形过程保留由下至上的裁切。
- 实体在透明方块/粒子之前绘制，法阵辉光仍在粒子阶段之后绘制；异常、跨帧和资源重载时释放未使用的辉光数据。
- 保留整模型数量预算，优先显示附近正在攻击的龙，不截断成半条龙。繁忙场景中装饰性双龙可能暂时让位于攻击效果。

## 检查与图像说明

源代码验证、16 项 Forge 功能测试已通过，包括四个朝向的遮挡清除、每次最多 64 块的限制，以及容器、液体、基岩、受保护方块和支撑地面的保留。

模型检查覆盖有限坐标、面片退化、边界、法线、武器净空、鳞片交叉、鼻尖命中位置和 242 个特效动画采样。详细记录见 [几何验证记录](geometry-verification.md) 与 [龙表面检查](dragon-surface-qa.md)。

- `before/`：旧网格使用同一离线检查器生成的几何对照，不是以前游戏画面的截图。
- `after/`：新网格的多视角几何/材质预览，其中离线图不包含织锦贴图。
- `runtime/`：实际开发版 Minecraft 客户端调用生产渲染器生成的离屏图，不是在游戏世界中拍摄的截图。最终 14 帧通过材质加载、透明前后景深度混合和异步资源重载检查，详见 [运行时记录](runtime/README.md)。
- 编译、离屏渲染及几何测试不能替代整合包实际游玩的视觉与帧率验收；具体测试结果及未运行项以验证记录为准。

## 尚未达到的目标

当前结果是经过多轮修正的风格化三维游戏模型，**还没有达到参考照片的电影级写实程度**。面部雕刻、真实皮毛、精密甲胄雕花和自然动画仍有差距，不能用增加面数或一张生成效果图宣称已完成这些要求。

织锦是本轮通过内置图像生成工具制作并实际应用的位图资产。提示词和原图保存在 [image-prompts.md](image-prompts.md) 及 `sources/`；没有下载来源不明的第三方模型，也没有把用户的参考照片作为游戏里的平面替身。

复现几何检查与真实客户端渲染检查的方法分别见 [模型工具说明](../../../tools/art/IMPERIAL_MESH_PREVIEW.md) 和 [客户端检查工具说明](../../../tools/art/runtime-qa/README.md)。
