# Dynasty 已注册盔甲的资源与改稿履历

本次从 `DynastyGear` 的七套显式注册与二十一套表格注册出发，确认 `DynastyContent` 接入模组事件总线。共 28 套、112 个物品 ID，比上一轮扩大 84 件。逐件解析物品模型中的 PNG 引用，并根据 `DynastyArmorMaterials` 的材质名及本地 Forge 1.20.1 / 47.4.10 渲染源码确定穿戴层。护腿读第二层，头、胸、靴读第一层。绑定结果覆盖 112 个物品模型、112 张图标和 56 张穿戴图。

- 图标有 100 件可确认曾重画。52 件匹配后来获选原稿的接入记录，40 件匹配 v15 安装前后收据，青铜、玄天共 8 件匹配 v7 交付。另外 12 件属于玉甲、将军铠、天将云铠，有精致旧稿保护记录，重画履历证据不足。
- 穿戴图有 46 张可确认是 v15 重画后接入的版本，覆盖 23 套。青铜、玄天、玉甲、将军铠、天将云铠的 10 张穿戴图未找到重画收据。逐文件可查到的 Git 历史各只有一次记录，无法据此确认它们就是首稿。v7 记录也明确区分了玄天图标、光效和穿戴 UV。
- 本地待办 `cod3.txt` 第 6.5 节涵盖盔甲的触发式视觉效果，不能作为基底贴图重画的具体记录。按用户本轮“未改且需要重做”的筛选条件，目前没有足够证据可确认的生产目标。

详细 JSON 按套保留注册位置、物品模型、纹理路径和哈希，以及缺少履历的图集。护甲真实运行效果和资源包覆盖仍待核实。有效参考门槛未通过，本轮仅做离线核查。
