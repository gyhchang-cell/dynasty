# 未完成饰品与器物候选

本子批只处理 `allowed.json` 指定的 138 个旧占位或未精修 ID；全部文件留在 `candidate`，尚未接入源资源。逐项中文用途和设计说明见 `all-items.json`，真实原图、原路径与 SHA-256 见 `baseline.json` 及 `before/`。

## 制作方法

沿用本轮已确认 v13 铜镜的原生 32×32 细节精度。生成器从透明的 32×32 画布开始，以整数坐标逐像素组绘制；PNG 生成阶段没有高分辨率母图、缩小、滤镜、随机噪点或第三方图片取样。放大只用于预览，采用最近邻。调色以连续大色簇和短高光表达铜、钢、玉、漆、布、骨材；透明度只有 0 与 255。

同族工艺可以相通，但按物件结构分别设计：铜钱方孔、银币菱面、玉币方框；印章有方环钮、圆环钮、双柱钮、龙钮、虎钮；妆匣具翻盖、铰片、锁口与底脚；马镫、司南、砚台、笔架、铃铛、贝珠、琴弦、绷带与战旗保留各自识别结构。每项具体设计记录在 manifest 中。

## 视觉复核

已实际查看全部 7 页 `previews/all-01.png` 至 `all-07.png`，每页最多 20 件，包含原图对比、候选 1× 和候选最近邻 4×。首 24 件另有 `first24-01.png`、`first24-02.png`。

复核后修正：避水珠贝壳原有过暗大面，改为清楚扇贝内缘与放射肋；蚀月珠扩大银月弧；符箓主符记增宽至 2 像素；妆匣取消袋口构造，改为宽翻盖；潜蛟印与龙宫印增设不同鳍脊、盘尾和印座；方官印与金印分别使用方环钮和圆环钮；玉带钩、玉辟邪补少量完整明暗组；官徽金鸟补齐长颈、翼和两足。

## 引用与验证

全部既有物品模型都是 `item/generated` 或 `minecraft:item/generated`，各自 `layer0` 为 `dynasty:item/<ID>`。候选保持同名资源路径，故这 138 件不需要改模型或公共注册代码。没有现存 `.mcmeta` 动画元数据冲突；本批也没有动画和发光功能。

`verification.json` 核验：精确 138 项范围、32×32 PNG、二值透明、至少 1 像素透明外边、每项备份匹配原 SHA-256、每项源图仍未变化、模型引用匹配、manifest 哈希一致、无完全重复 PNG。色数范围为 4–14。

本批未修改任何源 PNG、模型、Java、其他完成品、并行祭坛资源、实例或存档；没有启动游戏，尚未游戏内实测。
