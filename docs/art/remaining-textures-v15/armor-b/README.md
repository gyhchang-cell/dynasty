## 穿戴与引用

- `textures/item/<套装>_<部位>.png` 对应现有同名物品模型的 `layer0`；48 个 `item/generated` 模型均无需修改。
- `textures/models/armor/<套装>_layer_1.png` 使用标准 head、body、左右共用镜像 arm 和 boots UV。
- `textures/models/armor/<套装>_layer_2.png` 使用腰部及左右共用镜像腿部 UV；上身其余区域透明。
- 头盔中央面孔透明，靴层不占据大腿贴图区。所有不透明像素都在标准 UV 岛内。
- 120 个源 PNG/物品模型已逐个备份并记录 SHA-256；末轮检查源文件未变化。未改 general、jade、sky、bronze、xuantian 的 20 张保护图标。

## 预览与限制

`previews/armor-b-contact-1.png`、`armor-b-contact-2.png` 是总览。每套还有 `<套装>-overview.png`，包含旧图对比、原尺寸、最近邻放大、两张 atlas 及正面、背面、斜向穿戴预览。

穿戴预览使用已核对原版源码的 ModelPart UV 和镜像规则，在内存中读取 v14 渲染器并重组完整套装。它是离线正交像素预览，不是游戏截图。物品图标中的冠形、肩轮廓是图标表达；穿戴仍是原版方盒人体几何，没有新增角冠、肩部模型、碰撞或功能。没有新增动画或发光渲染，也未运行游戏。

生成脚本 `generate_armor_b.py` 只输出本目录；`verify_armor_b.py` 可复查尺寸、哈希、原图保护与 UV。模型、注册、存档、建筑和另一任务网页均未修改。
