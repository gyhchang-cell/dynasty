# 装备候选独立只读检查

检查范围：同轮 `items-equipment/candidate/assets/dynasty` 的 **45 张 32×32 PNG、28 个候选物品模型**，加上其余 17 个物品沿用的原版 generated 模型。检查未修改该组任何文件。

结论：**未发现引用或轮廓挤出不一致。**

- 45 张 PNG 的 alpha 只有 0/255，模型 `layer0` 与同名候选 PNG 对应；32×32 数量为 45。
- 28 个模型的 `dynasty:item/solid_handheld` 父级存在，纹理引用全部可解析。
- 从每张新 PNG 的非透明像素出发，检查上、下、左、右邻居；邻居透明或越界时，该边应出现一个侧边面。然后把 JSON 元素坐标反推到原生像素位置，与期望边集合逐项比较。
- 28 个模型共 **3,680 个实际侧边面**；缺失边 **0**，多余边 **0**，透明像素错误挤出 **0**，偏离原生像素网格的元素 **0**。
- 每个边的 UV 中心都采样对应的不透明源像素，无错位；正反平面为 0—16、厚度 7.75—8.25，north/south 面正确。
- 其余 17 项没有固化的 `elements`，沿用 `minecraft:item/generated`（包含合法省略命名空间的 `item/generated`），会根据新 PNG 的 alpha 生成轮廓。

这是静态资源与几何边界一致性检查，未进行游戏内测试。详细计数见 `equipment-independent-check.json`。
