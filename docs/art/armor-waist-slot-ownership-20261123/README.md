# 低腰片应归胸甲还是护腿

将此前固定的 Oreganized Electrum 与最新 Mythic Metals Tidesinger 对照，补查的是腰部装饰的槽位归属。核对源文件、活动图集、返回纹理路径和绘制分支后，实际检查了八块原生 UV 裁片。Electrum 的默认命名第 2 层会造成误判，当前物品回调明确返回 64×64 的实体图集。

Electrum 的 Body 里有一块三像素高的下摆，切片 [44,18,52,21)，随胸甲显示。护腿分支只绘制左右腿，没有下摆。Tidesinger 把三像素高的腰带四面和独立腰扣分到护腿分支。单穿护腿时仍有腰带和腰扣，胸甲片与胸饰继续隐藏。两例都应从绑定源码判断部位，单看图集中的低位图块或物品栏图标无法判断其归属。

青铜、将军、玉、天将、玄天已有原版两层坐标。这个对照直接支撑后续验收：需要看单穿胸甲、单穿护腿、整套分别哪些腰部细节可见。Dynasty 的腰带留在第 2 层，胸甲下缘若已有自身图案则仍归第 1 层。不要把第三方几何或图形挪入项目。本文只说明源代码和对应裁片，实际遮挡、转角和穿戴效果仍待实机。未新增独立设计计数，未生产贴图。
