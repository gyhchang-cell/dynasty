# 武器像素重做 v19

本轮只选仍沿用早期简图的三件现有武器：长枪 `chang_qiang`、雷霆枪 `thunder_spear`、分水三叉戟 `sea_trident`。最早精致的武器、上一轮状态图标及其他素材继续保留。没有新增注册 ID，也没有修改伤害、任务、配方、AI 或存档。

实际查看 `docs/art/guandao-photo-reference/reference.png` 的历史用户参考，借鉴刀刃与长杆的重量分配、刃与握柄的清楚分区，不把青龙偃月刀外形直接套给长枪。本轮重新核对了旧图：长枪与雷霆枪此前主要靠缨穗颜色区分，三叉戟叉头辨识度弱。新图分别使用红缨叶形刃、折角雷纹枪刃、三根分离叉齿；均保留斜向长杆和实用握柄。

三张源画由内置 imagegen 逐件生成，提示词和来源见 selection.json，完整源 PNG 保存在 sources/。运行贴图仅裁透明边、补 2px 透明边，未缩成 16px、未减色。生成提示以粗像素台阶轮廓、离散明暗、透明背景为约束。comparison.png 来自实际运行 PNG 的最近邻缩略，仅为资源预览，并非游戏截图。

接入统一 `tools/art/inventory-refresh/install.py` 原稿发布链；三件均使用已有 `original_item` 加载器，重新依据透明轮廓挤出侧边，不复用旧贴图的静态侧边几何。保持既有 solid_handheld 的左右手第一/第三人称变换。

检查：原稿与运行图 RGBA 逐像素一致，三张原生 PNG 解码、9574 个原生挤出面、UV 边界和图集 codec 通过。全部四种手持变换存在。最终本地 JAR/现有导出包仅替换 3 PNG、3 模型和图集过滤表，逐项校验其余载荷，备份在 deployment-before/。具体文件和哈希见 DELIVERY.json。

没有启动、重启或关闭客户端，未操作音量、亮度或存档。真实游戏持握、光影和缩放画面仍待实机检查，静态与无图形检查不冒充游戏验收。
