# 压缩铁甲与钢甲的开脸、护腿腰部对照

从两个固定 1.20.1 源码快照实际查看两套四槽装备的 8 张库存原图、4 张穿戴原图。逐项核验登记、物品 JSON 和基础图的 Git blob 及 SHA-256，再单独观察头部与躯干 UV。本轮补齐这两套在五套候选修复中的具体适用范围。

PneumaticCraft 压缩铁甲的四个物品直接把各自 `ArmorItem.Type` 传给 `CompressedIronArmorItem`。该类在腿槽选 `compressed_iron_2.png`，其他槽选 `compressed_iron_1.png`。主头面保留连续头顶及两侧颊片，中央是大块开口，外帽正面全部透明。护腿的前后左右躯干只在 V=29–31 的最后三行有材质，躯干上端盖透明，底端盖有色。这提供了一种比原版铁甲五行腰带更紧凑的方案。适合对照青铜及玉甲的轮廓与腰线，配色和边缘形状仍按 Dynasty 原设计。

Immersive Engineering 钢甲通过 `ArmorItem.Type.values()` 注册四件，`SteelArmorItem` 根据 `LEGS` 选择 `armor_steel_legs.png`，其他槽使用 `armor_steel.png`。头面是多条横向相间的栅栏，不适合作实心盔甲开脸的直接范例。护腿躯干的四面、上下端盖全部透明，体现了裤腿和胸甲完全分离的另一种实现。将军、天将和玄天如果已有清楚的腰带身份，应保留其自身腰带。该钢甲可用于对照「单穿裤子时不能出现胸片」的边界。

两套都已在历史账本的原版轮廓学习组里，新的逐面阅读可以复用，暂无独立设计验收可新增。原档对照页是整数放大和 UV 裁片，当前没有游戏内验收。五套候选的既定编辑和保护范围继续沿用，制作门槛维持未通过。
