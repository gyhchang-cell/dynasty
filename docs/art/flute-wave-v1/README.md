# 玉笛：真实范围减益后的音波

本轮接入 `FluteWave` 与独立客户端渲染器，将玉笛的通用近战冲击环替换为右键实际减益反馈。原 `FluteItem.use` 的扩8格包围盒、两次120tick虚弱II/缓慢II应用、目标计数、玩家160tick力量I、原冷却、消息、音效、挥手和返回值全部保留；没有新增伤害、硬直或效果。原实现只排除施法者，包含盟友与遮挡后的生物，本轮保留这项已有行为，不能报告成已过滤盟友/视线。普通近战仍保留原残影和会心提示。

每个原目标在应用前保存活动减益的存在、等级和时长值，应用后检查活动效果是否确实变为等级1、120tick，且原状态为空、等级较低或同级时长较短。只要虚弱/缓慢之一真实生效或刷新才计入视觉回执。Forge拒绝、已有更强/无限时长/同等时长、仅外观标志改变或新增隐藏的较弱效果不冒充活动减益触发；无目标也不播放范围命中波。原两次addEffect调用保持原样，不为了观察多调用一次。

自检补上施法开始时的只读Cast快照：原始玉笛来源、副手/主手、维度、tick、实际身高的胸部世界锚点及视向预先锁定。后续换手或转身不改变来源/锚点，死亡、跨维度、过期或异常超过8格位移的施法者拒绝归属。每玩家每tick最多一次，Cast在本次调用结束后释放，没有服务器常驻视觉实体/队列。它是明确胸部世界锚点，未声称等于客户端物品渲染矩阵中的笛口。
