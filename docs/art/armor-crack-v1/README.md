# 破军、玄天：实际士气减伤后的甲裂

本轮实现 cod4-3 `pojun_axe / xuantian_axe` 的真实破甲甲裂。现有破甲机制是目标士气减伤减半，不是扣减原版护甲属性。原 `DynastyCombatEvents` 的 `toughness *= .5`、伤害公式、玄天减速、唐刀上一轮回执和其他武器全部保留；只在已执行的减半位置加入视觉回执，并在同次最终正伤害事件消费。

回执记录原管线捕获的精确武器ID、同一 DamageSource 对象、攻击者/目标UUID、维度和服务器tick。目标实际士气必须大于0，传入前值必须对应当前真实目标类型，后值必须恰为减半；只接受直接玩家近战。最终伤害的来源、目标、归属、维度和tick均须一致。取消或零伤害不播放；其他斧、重弩、普通原版有护甲但无王朝士气的目标不能借用甲裂。回执不持久化、最多32条、每tick末和停服清空；每玩家每tick最多一次短视觉。没有按名称含axe或仅手持斧来猜触发。

生产源为 `cod3/ArmorCrack.java`、`client/ArmorCrackRenderer.java`。保持已有 `Cod3VisualPacket` 字段及32格广播；客户端专用cue、每目标一个实例、最多12个、10tick结束、换世界清空和64格绘制距离。独立渲染恢复GL状态，不修改其他聊天正在使用的公共 `Cod3VfxRenderer`，不增加伤害、硬直、状态、音效、相机变化、服务器实体或注册ID。

`plan.json` 是制作前方案。原创8×8硬边像素板裂缝，裂板随时间略分开，四小平面碎片短时飘落。破军铜色、玄天紫灰色，各配一种深裂缝色；生产函数直接绘制像素矩形，单实例70三角形，最大实测局部顶点距离0.8162格，缩放限制0.45–1.2。没有模糊PNG或复制模组图案。平面绑定受击者身前：高度55%、表面外移半身宽加0.025格，跟随真实插值位置；这是有意的表面 decal，90度边缘不可见，不是新生物纸片身体。实际透明度只有时间淡出。

实际Java `CrackCheck` 通过126690生产几何/锚点/位置检查，覆盖两武器、五方向、三缩放、每半tick、真实FriendlyByteBuf往返、有限包围、非退化像素、两色上限、目标平移跟随和非法cue拒绝。`actual-triangles.json` 来自生产函数。`software-views.png` 和 `software-timeline.png` 已实际查看正、45度、侧、背、纯黑、灰色及拆开/碎片/消失。**这些是同尺度不透明软件诊断，不是游戏截图；没有证明真实光照、透明重叠或人体表面遮挡。**
