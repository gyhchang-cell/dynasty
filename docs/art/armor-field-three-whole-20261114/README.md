## 实际观察、分部遮挡与反例

- **攀登装备**：米棕头罩、灰横扣、砖红下缘；暗绿胸底用浅米绳带与窄蓝横带辨识功能，裤为短裆片，米靴两只直筒。头罩8×9×8附10×2×1横条；臂腿存在不同UV/inflate的同尺寸两层盒，不能见空处就把整片填色。96×65图集，基础身体8×12×4、臂腿4×12×4。学材料分区，普通布甲不照抄大交叉绳带，普通裤甲也不照抄短裤轮廓。旧explorer_straps_iron_variant已有肩带原则，本批保留不同头罩/双层结构候选，独立性待验。
- **洞穴探索甲**：头具是棕边带与单根白烛；胸由深青蓝主面、棕金肩带及小腰扣组织，裤短、靴扁。头具不是完整盔壳：7个盒描述烛体、芯与头带；5个7×9×0火焰平面各自有骨。独立idle动画1.28秒循环，以0或0.4的XY缩放切换火焰，所有动画骨名在geo中存在；不等于已测时序/插值/渲染。104×64图集。只学工作用途由少数部件表达，不把烛台当普通防护头盔，也不把短裤/扁靴作为标准比例。旧采矿围裙只胸部，旧探索肩带已有相近构成，完整设计的语义区别仍待验。
- **雪甲**：浅蓝硬盔有深灰倒U边口、白鼻梁和两侧短片；胸主面灰蓝加局部青色中框、黑底，靴黑筒青口，裤仅小膝片。实图没有白毛皮；配置是heavy_plate，不能因名称误当白毛皮套。头5盒，胸主体另附8×4×1小片，双臂侧片不扩大躯干比例；96×65专用图集。学亮片/暗底大块分工，不把青色当发光已验、不照搬到普通布皮。与旧棕白皮毛和紫粉/蓝黄衣装观察对照后仍需同其他浅蓝金属甲做独立完整语义审查。

三套的12个generated物品JSON完整查看，layer0逐个解析到对应实际PNG。三份gearconfig完整读过；攀登为`dungeons_gear:pelt`，洞穴探索为字面`minecraft:light_plate`，雪甲为`dungeons_gear:heavy_plate`。洞穴探索material是否真正注册/解析尚未核实，不据此改代码或宣称其材质运行成立。

三份geo逐节点查看了尺寸/UV原点概要，完整原声明保存在`three-whole-bindings.json`。静态父级无缺失或环，图集声明和PNG尺寸一致，列表UV名义展开包围范围在图集内；13/20/15个盒是同三套的组成。这里不声称最终面朝向、镜像、穿戴遮挡、接缝、五视角、灰模/剪影或实机通过。

## 注册与不同消费者

实际读过ItemInit入口及三个构造helper：攀登调用普通ArmorGear/COLD；雪甲调用FreezingResistanceArmorGear/BASIC及默认动画；洞穴探索调用PetBatArmorGear/BASIC及独立spelunker动画。每个helper都显式构造四槽ID、geo、贴图路径。两个小子类完整阅读，构造均原样传递资源，额外抗冻/宠物接口不作为美术修改范围。CLIENT MOD AddLayers实际对两个子类注册ArmorGearRenderer。
