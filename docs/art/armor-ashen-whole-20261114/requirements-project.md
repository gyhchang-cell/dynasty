# 用户贴图长期要求

保存日期：2026-11-02（北京时间）。来源：本聊天中用户从2026-10-15起的返图反馈、盔甲返修反馈，以及2026-11-02要求长期保存、每批保存要求的直接指示。以后用户的新指示优先；不可把本文件当成冻结后不可修改的设计。

## 每批开始与保存

- 每次贴图任务先读本文件、当前目标的已有资源、历史获选版本及用户最新反馈。每个实际制作批次保存本文件全文副本、SHA-256、具体目标ID/路径及本批执行说明，不只说“记得”。使用 `tools/art/snapshot_texture_requirements.py` 保存。若要求后来改变，保留旧批次快照并另存新版本，不覆盖历史依据。
- 先区分：已重做且认可、原本就精致、仍旧且简陋、版本/接入待核。优先后两类中的确定缺口；已改好的、精致老原稿不动，不为统一风格重画。
- 新制作遵守该范围适用的1000个真实相关不同参考要求，固定来源、实际看图、语义去重并记录观察。不把颜色、同物件部件、动画帧、重复截图或下载文件拆成不同设计，不把1000件说成1000个模组/整合包。能复用已完成且适用的参考证据，不每次清零；未达标不宣称完成，不拿无关素材凑数。

## Minecraft感与物品身份

- 画面首先像MC游戏物品：清楚的阶梯轮廓、大像素簇、大块离散明暗、克制且可辨的材料分区，缩小后仍能认出用途和名字。
- 不用光滑插画、写实高光、噪点、细密雕花、柔光、渐变或密线装饰冒充精致。不靠事后缩到16px或强行减色来修复风格。
- 物品轮廓必须符合名称和用途：牙像牙、蹄像蹄、笔筒像笔筒。不要主体过小、长得像另一物品，或把同一模板随意换色命名。普通物品/饰品应有自己的身份，不全套照抄原版物品再换色。
- 物品栏背景透明，去除真正的白色画布/框底；白骨、牙齿、金属亮部、衣料等主体白色不能误删。早期白底、固定16×16、整图最多四色规定已被用户后续透明原稿要求覆盖，不再套用。

## 盔甲专用标准

- 以MC原版盔甲图标的比例、轮廓和像素组织为基础：紧凑盔顶与倒U面孔开口、短宽胸甲和适度方肩、腰部连接两条直腿、清楚分开的短靴；不是整套人台、展示插画或穿戴人物渲染。
- 保持部位比例：不任意缩短靴筒、画圆鼓鞋头，不做过度宽肩、外挑头冠或巨大装饰压住主体。双靴整体宽高约1.4可作原版比例参照，不作为所有设计的硬编码数值。
- 初期装备朴素，使用实际竹、布、皮、铜铁等材料身份；强力中后期盔甲可以创新、神圣、有独特冠饰和纹样，但必须长在MC盔甲基础轮廓上。鸿蒙/混元等不能变成圆环科幻躯干、巨大圆肩或华丽人台。
- 用户说“微调”时，只收敛比例/像素风格，保留已经认可的设计、颜色、材质和纹样；不要借机重新设计。
- 库存物品图标与穿戴layer_1/layer_2图集分开核验。图标改过不等于穿戴贴图改过，旧穿戴图也不能作为重画已认可图标的理由。不动身体几何/骨骼/动画；只按实际UV检查材质、接缝和朝向。

## 武器、饰品与配套物件

- 武器按真实伤害、配方及获取难度判断阶段，不为迎合美术改数值。前期参考已认可的原版武器基础改造方式，简单粗像素、材料清楚；强力中后期允许独特刃形、结构和材料身份。
- 饰品只改未做过且简陋/卡通或名图不符者，精致早稿保护。不要批量重复同一宝石、袋子、圆牌模板。
- 已获授权的手持物、挂件可制作其自身模型和贴图；人物/生物身体、骨骼、动画仍归建模专岗。先记录原生物品ID、握持姿态、持握骨/挂点接口和实际来源；接口不明时列待核，不猜骨名，不把基础ID当NBT变体。
- 新模型使用Cuboid、方块、平面和粗阶梯结构，按实际UV面积选图集，原创不复制其他模组资产。模型另读用户最新版《建模要求.txt》。

## 原稿、接入与返图

- 获选原稿保留原始分辨率与主体RGBA像素，不压成16px、不量化、不做有损压缩。仅允许裁去透明外边距并补必要透明边距；不能裁掉主体。
- 用户默认要求获选美术真正覆盖项目运行资源，无需每次再等提醒；同时遵守当前批次较新的并发、参考和接入边界。当前2026-11-02分工：只在项目内处理获授权资源，不开游戏，不碰用户实例原档，不覆盖共享Jar；由协调完成受控集成与验收。
- 保留源图、选图/裁剪记录、运行路径、模型声明、旧新哈希以及适用的UV适配证据。缺引用/接口不把“PNG存在”当接入完成。
- 做完自己检查，发现不足就改善：形状与名称、MC比例、像素簇、透明边距、小尺寸辨识度、材质区、左右/前后/UV接缝、实际源与运行文件对应。
- 按当轮用户要求返实际获选原稿或原稿来源的有名称总览/新旧对照。总览可以缩略，运行原稿不能跟着缩小；不混入未选稿或他人参考，不以预览图冒充游戏截图。不需要每次堆上所有历史批次。
- 未实机、未穿戴、未双人或未完成要求的项目如实标明，保留提示词。当前提示词由主协调按完整证据统一精确删除；本专岗不自行同写主清单。
- 全程不打开声音、不提高亮度、不唤醒屏幕、不关闭用户已有客户端/存档；仅本地，不擅自推送。
