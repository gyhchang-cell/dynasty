# D28：七种同模型法袍

从本地固定Wizards 1.4.1+1.20.1原包阅读七种此前未读名称：普通巫师、奥术、火、霜，以及后三者的下界合金版。其物品部件后缀是head/chest/legs/feet，旧的helmet/chestplate筛选未包含。新增的候选发现清单记录3069个按文件名去重的Jar范围，只是发现记录，零设计参考信用；四个tome部件名等并不能自动算盔甲。

实际查看28张原生16px图标、7张64px图集、7张正/45/侧/背/黑剪影软件组装，共21页。七套共用一个17体块geo；合并进入已有巫师帽袍学习族，新增独立设计信用0，新增学习组0。记录详见 `semantic-review.json`。

静态读取7个原类、两个补充verbose反汇编：材料名、共享WizardArmor、RenderProvider、渲染器、模型与textures/armor/{name}.png相符。七个factory分别创建四种不同中间命名ArmorType。当前包未闭合外部Spell Engine Armor$Set注册实现及中间命名类型映射，因此只记7个四物品factory/材料声明，不冒充28条实际槽位验收。

包内有armor_idle.json，但getAnimationResource返回null，registerControllers直接return，不能据文件存在声称动画已接入。来源为Fabric/AzureLib；只学习像素分区、领襟/袖口/袍摆与正背连续，不当成Dynasty Forge/GeckoLib可直接加载资源，也未复制运行资产。

普通蓝袍以大块明暗保持识别；元素版通过紫符、红橙中线、浅蓝肩/帽顶区分；下界版主要增加灰袖带/靴扣，未新增几何。目标仍以Dynasty原版甲比例与自身UV为准，不套宽尖帽或统一抹掉长袍L2。软件图包含BoxUV小数/镜像近似，只作结构观察，不能证明实际引擎采样、玩家动作、shader、槽显示或接缝。

核验通过来源字节、原生模型/材质声明、静态factory、图表哈希、要求快照、前序证据与289条保护路径。累计640名称族、626盔甲名称族、213学习组、14排除项；已验完整独立设计总数未知，1000门槛未达。213含局部/变体/反例，787仅是每组都合格时的最低缺口。

本轮没有新增贴图、生产覆盖、游戏启动、共享Jar修改或提示词删除。D2袖盖、旧L2和材质待修保留；下一步继续固定本地源未读有效完整设计，避免重算换色、旧版本同物或已有适用证据。
