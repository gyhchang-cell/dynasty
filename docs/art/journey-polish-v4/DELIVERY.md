# 2026-09-25 任务、淬炼与弓的体验更新

- 四条流派的 +1、+5、+15、+30 淬炼任务列出最后一步与逐级材料、经验等级消耗及累计材料；物品提示仅留淬炼等级。淬炼机制未改变。
- 八个主线章节各增加两条两节点支路：32 个新任务，主线章节合计 101 节点，全书 696 节点、35 章节。既有 488 条旧任务身份保留。
- 合成任务启用 FTB Quests 原生 JEI 跳转：点击任务详情中的物品任务图标；悬停 R 看配方、U 看用途。
- 六种弓统一模型生成规则，修正逐星弓拉弓朝向、背面 UV、透明边缘采样。保持原始贴图分辨率；所有拉弓阶段和左右手纳入回归检查。
- 接入 FTB Ultimine 2001.1.8，移除 Dynasty 内置连锁采矿类；原类备份在 build/backups/journey-polish-v4。按键可在游戏控制设置的 FTB Ultimine 分类调整。
- 接入 WorldEdit 7.2.15，供独立创造世界搭建与导出建筑；具体流程见同目录《建筑搭建交接》。没有修改或删除玩家世界。
- 万钧戒、灵文佩、金乌箭囊仅做 3 件图像生成像素风试样。默认资源不替换；启用 dynasty-three-pixel-samples 资源包试用，关闭恢复。

## 验证范围

- 离线 Gradle build 通过；部署包不含运行时截图测试类或旧连锁采矿类。
- 65 项服务端 GameTest 通过；另带 FTB Ultimine / WorldEdit 加载的隔离服务端测试也通过。
- 任务结构、配方引用、无循环前置、淬炼逐级成本和弓模型方向测试通过。
- Minecraft 客户端离屏渲染检查通过，共 193 帧，含六种弓左右手和拉弓阶段，无 GL 错误。
- 离屏图不是玩家世界实测；仍需在实际整合包中确认惯用 FOV、惯用手和其他动画模组共同作用下的手感，不以静态测试保证未来绝无回归。
