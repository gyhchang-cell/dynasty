# 你可以直接进游戏搭建筑

本次加入 WorldEdit 7.2.15（Forge 1.20.1）。完全退出游戏并装好更新后，新建一个**创造模式、允许作弊**的独立超平坦世界，命名「王朝建筑工坊」。不要在生存主档试验大范围编辑。

最省事：从空地直接搭你想要的王朝建筑，使用创造物品栏里的王朝方块。搭完告诉我**世界名称、建筑名称、你站在什么位置**，把建筑附近的地标截个图。把角色留在建筑旁并保存退出；我可以从这个存档提取，不要求你输入任何方块坐标。

如果想从现有建筑改起：在这个测试世界的空地输入 `/place structure dynasty:star_altar` 放九霄星坛。其他结构在 `/place structure dynasty:` 后按 Tab 看实际注册列表。给大型建筑留足空地，不要在自己作品旁边反复生成。

## 想自己导出也很简单

1. 输入 `//wand` 获取木斧。
2. 用木斧左键选建筑区域的一个最低角，右键选对面的最高角。必须把屋顶、地下室、装饰都包进去；临时放两块标记块会更好选。
3. 站在建筑入口，输入 `//copy`。入口位置会成为粘贴参考点。
4. 输入 `//schem save dynasty_my_build_v1`，保存后退出游戏。
5. 文件一般位于实例 `config/worldedit/schematics/`，以游戏提示的保存路径为准。把 `.schem` 文件交给我，并告诉我是替换星坛、宫殿还是新增建筑。

你只负责搭。接回整合包时由我检查旋转、楼梯朝向、生成边界、地基、战利品和怪物数量，再转换/接入世界生成；**保存 schematic 不会自动更新整合包**。

建筑生成变更只影响未生成区域，不直接覆盖旧存档已有建筑。不要为了测试删除你的生存存档。
