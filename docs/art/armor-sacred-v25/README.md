# 神圣鸿蒙与三套高阶盔甲物品图标

用户要求鸿蒙更神圣、更创新，并追加多做尚未重做的简陋图标。本轮16件：鸿蒙返修4，紫微、混元、北斗各4。只改物品栏贴图，保留麒麟v23、精致旧图、装备数值/配方/注册ID与穿戴UV。

## 实际依据与设计

已查看四套现有图标并核对DynastyArmorMaterials、DynastyGear、物品模型与中文名称。紫微对应帝星，混元是高阶毕业甲，北斗偏星石与移动，鸿蒙在混元之上；未为设计修改数值。

- 鸿蒙：白金阶梯光冠、青白星核、象牙白甲片与少量深靛关节。神圣感来自实体冠架与配色，不依赖粒子或柔光。
- 紫微：紫晶、深梅紫、银色折线星轨与帝星嵌片。
- 混元：青玉、墨绿、古铜扣合，以方阶玉环作为结构标记。
- 北斗：深蓝钢、银色阶梯包边、嵌入式斗星纹样。

沿用armor-imperial-v24实际审阅的1000张去重盔甲相关参考及神灵金四件，未声称本轮又新增研究1000套。来源和十页参考表保留在该目录research。全部为原创重绘，不复制模组像素。

使用内置imagegen逐件编辑；完整提示词及输出路径保留selection.json，获选完整PNG保留sources。紫微靴和混元靴首稿柔光不合格，采用干净边缘的新稿；北斗胸甲首稿六星返修为七星，七处嵌片已逐一目视确认。实际资源保留原稿主体RGBA，只裁透明外边距并补2px透明边，不缩16px、不量化。汇总缩略图仅便于观看。
