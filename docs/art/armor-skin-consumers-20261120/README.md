# WizardsReborn 盔甲皮肤绑定与去重

现存的 FluffyFur 固定源码提交 `76f32e28e1abbf13e22621be731df98c8ce89756` 标注版本 0.3，与 WizardsReborn 声明一致。核对了已保存的 `ArmorModel.java` 与来源哈希。它在头槽只绘制头部，胸槽绘制躯干和双臂，腿槽绘制双腿与骨盆，脚槽绘制双脚。灵魂猎手和皇家卫士沿用这套槽位逻辑。Magnificent Maid 继承头槽逻辑，但自行分配胸、腿、脚槽，左右裙摆从胸槽绘制并跟随腿姿态。普通臂和细臂属于同一设计。

WizardsReborn 的皮肤入口声明了物品类别检查、装备槽到图标模型的映射，以及所选穿戴模型。发明家法师与秘法堡垒装备均有自定义模型，装备渲染入口会读取物品上的皮肤后请求替换模型与贴图。此次在可读项目内档案中未定位到 FluffyFur 的 `ItemSkin` 或 `ArmorClassSkinEntry` 实现。皮肤如何从物品读取、如何查找条目、细臂判断与继承的贴图返回细节仍缺依赖源码。已保存版本声明与实际加载二进制的一致性未实测。

新看完 Capitalist 四槽图标及穿戴图集共五张。它的奶白大色块、暗红帽带和衣襟使小图标能看清，但与皇家卫士、默认发明家法师共用模型。同一组九个可见 RGBA 色值的一对一映射即可同时从一套还原另一套的四张图标和图集，所有可见轮廓与透明度相同。三者归入默认发明家法师这一个历史设计。Capitalist 的四槽回指和皮肤物品注册已查到，具体获取路径未核实。

灵魂猎手和 Magnificent Maid 在同一来源中有实际轮廓与穿戴部件差异。对其他现存盔甲原图的 2,774 张同尺寸图片没有找到逐像素复用。这个范围的像素比较无法排除异尺寸重绘或跨项目语义重复，两套继续待全局去重。有效参考新增计数为零，尚未满足 1,000 个门槛。
