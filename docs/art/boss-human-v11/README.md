## 验证边界

离线验证保留全部已有骨骼/父子关系/原部件、六段动画名称时长循环、逐面UV不越界/不重叠、完整动作321个采样点接地，已认可的其他27个美术资源与战斗源码保持。

独立静音隐藏的Forge原生测试使用一次性世界，实际生产Renderer/PNG/控制器。正/45/侧/背各自给出关闭和开启气场对照，再检查移动、攻击蓄势/出击/恢复、受击和死亡，共42个状态。on/off使用同相机、同光照与相同玩家比例；独立测试中关闭气场不改运行资源。粒子发射请求有记录，画面判断与计数分开。实际结果见native目录及build-report.json。

最终结果：隔离分支和当前主目录构建均通过；42组原生状态通过，12组同机位开关对照中关闭为0发射、开启均有真实粒子发射，场景无遗骸容器遮挡。交付主目录JAR中的9个实际资源及BossHumanAura/BossCuboidRenderer全部类字节与已验收的美术包一致。主目录包含其他开发者并行更新，整体JAR哈希与隔离美术测试包不同；本轮实机结论只覆盖这里的三只及其渲染资源。

复查中修正了玩家取景裁切、日光下符线过弱，以及测试世界上一只死亡后延迟生成的遗骸容器遮挡。正式掉落逻辑未改。所有最终原生截图仍保留2800×1800原始文件；总览仅使用三张相同裁切，不更改玩家/Boss相对尺度。bbmodel中的非循环动作同步为once，避免编辑器再次导出改变运行循环属性。

移动由测试夹具驱动，视觉出击不等于服务器伤害验收。自然寻路、复杂地形、联机、实际装备握持、服务器施法同步仍待验证。发布JAR不包含QA测试类，不调整系统声音或亮度，不读取、修改或关闭用户愚者存档。主目录其他并行改动是否构建通过单独记录，隔离分支包不冒充全部最新主目录构建。
