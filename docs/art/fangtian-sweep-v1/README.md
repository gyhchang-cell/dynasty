# 方天画戟：真实横扫后的360度月牙

本轮完成独立 `FangtianSweep` 与客户端渲染器，替换方天原通用约70度短弧。原横扫是主目标包围盒扩3格内、过滤盟友和攻击者视线遮挡的瞬时判定。本轮保留原范围、`mobAttack`副目标来源、60%副目标伤害、主目标按yaw的0.8水平/0.25上扬推力和SWEEP递归保护；不新增攻击、浮空、迟延伤害、音效或相机变化。战斗源仅传递只读原DamageSource，并在原循环前后加入观察回执；移除这几处纯视觉差异后，与本轮开始备份逐字节一致。流派战斗类、公共Cod3VfxRenderer及其他开发者编译阻塞类保持字节一致。原残影和会心反馈保留。

回执要求实际原生AttackEntityEvent的一次性凭据、原始武器与主目标，以及原DamageSource对象。真实横扫内部记录最终正伤害，待原hurt返回确认副目标确实损失生命；或在同源主目标最终正伤害后于tick末确认真实生命减少。两者之一成立才广播。主目标后续取消而副目标已经真实受伤，仍正确呈现原横扫；全取消、无敌、普通剑、没有原生攻击入口、同tick其他伤害借回执、死亡攻击者拒绝。每玩家每tick一条，候选和回执各最多32、副目标观察最多64；不更改命中集合。保守的实际生命检查可能省略纯吸收伤害装饰，不把它误报成生命伤害。

制作前方案见 `plan.json`。原生POSITION_COLOR几何使用12段粗折角全周细边和六段交叉平面、两端收窄的钢色月牙，两种硬边纯色。命中时全360度细边已出现，六tick旋转仅为视觉余势，原伤害没有延后。真实当时yaw与主目标胸部位置锁定为世界锚点，不跟随玩家后来转身或目标位移。它是半径1.31格的克制接触装饰，不能当成原3格扩盒伤害边界。没有新增生物模型、骨架或无用途geo/贴图文件；可编辑几何/时间轴以生产Java为权威源。单次48三角形、客户端12实例、32格广播/64格绘制；独立缓冲和原GL状态恢复器。网络字段和原编码保持一致，增加专用路由。
