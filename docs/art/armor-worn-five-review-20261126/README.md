# 五套旧穿戴 UV 的参考与验收清单

联合之前的注册覆盖、首版复现和槽位证据，复核了当前 28 套登记盔甲的 56 张穿戴图。青铜、将军、玉、天将、玄天的 10 张图仍与本地 Git 最早版本和已回放的旧模板相符。其余 23 套的 46 张穿戴图匹配已重画接入的 v15 哈希，保留原样。五套每套的头盔、胸甲、护腿、靴图标和物品模型也与已核定版本相符。范围限项目当前基础资源。构建外的资源覆盖与已运行客户端不在本次静态核对范围内。

| 目标 | 头部参考及用途 | 腰部参考及用途 |
|---|---|---|
| 青铜甲 | 压缩铁甲与 Atum 沙漠铁甲的连续额带、短护颊和中央开口 | Mythic Metals 青铜的铜材前侧分区和五行腰带，对照压缩铁的更短方案 |
| 将军铠 | Tyr 的眉下开口和窄鼻梁，对应现有深灰、金缘与酒红小点 | Tyr 的正面扣点和低调背面，对照 Immersive Engineering 钢甲单穿护腿时的躯干隔离 |
| 玉甲 | Atum 沙漠铁甲的额带和侧边，压缩铁甲的整块开口 | 疣猪皮甲的四面下缘覆盖和上部透明。结合玉甲自己的青玉大面与暗接缝 |
| 天将云铠 | Jerotes 漫游者皮甲的少量外帽覆盖，Hallowed 额饰作为遮挡风险对照 | Botania 泰拉钢的护腿腰线分槽，搭配本套现冷蓝和淡金边 |
| 玄天真龙甲 | Draco 双层额饰的窄缝作为风险对照，Tidesinger 额冠与眼鼻开口的区分 | Tidesinger 的前扣归护腿、胸饰归胸甲。以自身深蓝、金角和青色焦点为准 |

坐标沿用原证据。第一层只评估头和外帽正面。第二层检查躯干四面和两个盖面，双腿 UV 完整保护。已有胸纹的最后两行落在候选腰带内，验收时也要确认那两行没有保留胸纹形状。本轮引用既有 36 像素逐 RGBA 比对。后续在取得准入时分别检查单穿头盔、胸甲、护腿、靴子，以及整套和混搭。头盔看正、45 度、侧、背及抬低头，腰部看四面接续、动作遮挡，以及胸纹只随胸甲出现。

## Cold Sweat 变色龙四槽的覆盖层

固定 Momo-Softworks/Cold-Sweat 的 1.20.1-FG 提交 `e529039f96365812ade00923dd23be73d292b5d2`。实际查看四张 16×16 物品图和六张 64×128 穿戴图，以及原生头部、胸片与腰带的裁片。

`ItemInit.java` 第 57–64 行注册四槽。 `ChameleonArmorItem.java` 第 21–58 行在玩家的标准盔甲钩子返回 `EmptyArmorModel`，非玩家返回实际槽位模型。这个所谓空模型沿用标准人体网格，默认图的标准 64×32 区域全透明。 `RegisterModels.java` 第 164–173 行向默认臂与细臂玩家添加独立渲染层。 `ChameleonArmorLayer.java` 第 49–88、96–119、145–146 行依据装备槽匹配图集和可见根，按适应值选择红或蓝覆盖图及透明度。头、胸、鞋使用第 1 层，腿槽使用第 2 层。

变色龙甲的腿部模型仍有 8×12×4 的躯干腰盒。基础腰带竖直四面上六行透明、下六行着色。红蓝两种覆盖的非零 Alpha 都没有越出基础腰带任一竖直面的像素范围。头面裁片也显示额上有少量鳞片、脸部大面透明。疣猪皮和山羊毛甲已经实现相同的腰盒遮罩思路，变色龙甲的新证据在于动态覆盖也尊重该遮罩。红蓝属于同一件装备的效果，不形成独立设计。此案例只用于验证覆盖层与基础图的一致性，不要求 Dynasty 增加额外渲染层。

1000 例适用参考门槛仍未达到。旧账本 215 个保守学习组不等于独立有效参考总数，本轮正式计数增量 0。仅离线核对，待制作与实际穿戴验收。
