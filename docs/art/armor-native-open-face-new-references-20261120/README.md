# 开面盔与护腿腰带的新增参考核查

本轮补读项目内固定 Minecraft 1.12.2 原档中的金甲、钻石甲和锁链甲。实际查看三个整套各四件库存图和两张穿戴图，共十八张原图，并按 Dynasty 已固定的 64×32 坐标检查相关裁片。物品 JSON 的十二条纹理引用逐项对应。截图页是原图整数放大和 UV 裁片，游戏内效果未实测。

金甲和钻石甲的主头面开口完全相同，眉下逐阶露出两边眼区，中间留短鼻梁，外帽面透明。其护腿前后及双侧腰带都集中在最后五行。金甲两张整图的不透明布局与已有 1.20.1 铁甲基准相同，钻石甲第一层在其他部位有遮罩差异，但本任务相关开脸与腰部仍与金甲相同。将它们归入已使用的原版实心盔甲基准。可借鉴的是开口与护腿腰带的比例，尤其适合青铜甲和将军铠，纹样与材质继续用 Dynasty 自有图标作依据。

锁链甲的腰带也在最后五行，用网孔体现材料。其头面只剩交错像素，适合做透明孔隙和整体开脸的对照，不能指导五套实心甲的面口造型。此例仅作为部分适用的原版技术参考。

复核了此前固定的铁木、CaC 银甲和 Ender IO 深钢三笔原生穿戴观察，分别可复用开脸与窄腰、腰线上缘倒角、深色颊片开口。铁木对应已有整套学习族，CaC 银甲仍有银板甲语义重叠，深钢来自较老版本且只具备无面罩默认分支的布局辅助价值。三笔可复用观察均没有独立计数收据。账本已确认的 Roots 整套设计可继续用于盔甲材质学习，其自定义模型不直接验证本任务的两层原版 UV。

新增正式参考计数为零。此前的 215 个学习组也无法按现有证据直接转为有效独立设计总数。具体有效总数与缺口仍待核定，1,000 门槛未通过。五套已经确认的 UV 修复坐标继续沿用，本轮没有替换材质。
