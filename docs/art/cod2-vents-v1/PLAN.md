# 蒸汽/火焰喷口：制作前说明

完成cod2追加清单的单个组合条目：`steam_vent/flame_vent：IDLE→WARNING→ACTIVE→COOLDOWN，先预警后伤害。`不据此删掉完整千机城、阿兰若或隐仙观要求。

两件均用16单位宽的方底板、12×12×11压力腔、阶梯收窄的8宽前口与2单位厚边框。蒸汽喷口有顶部粗方管和两道格栅；火焰喷口有一对短厚导热块和中央点火芯，轮廓不相同。北面为喷射方向，FACING旋转模型与喷射区。体块都用Cuboid，不使用圆柱、细斜面或零碎铆钉堆积。

方块采用Java原生静态模型与房间时钟；不套人形骨架、不制作无用途Gecko动画文件。动作由IDLE→20tick烟雾预警→4tick喷射→36tick冷却驱动，冷却沿用现有RECOVERY枚举。预警不伤害，接触仅由服务端时钟触发一次；蒸汽维持原3点接触伤害和有限击退，火焰接触3点并短暂点燃，不放置火方块。前向3格的有限AABB及遮挡射线共同限定范围。

各自使用实际16×16白底一格边距PNG，最多4纯色，2×2色区，UV只采有效色岛；保存bbmodel。检查正面/45°/90°/背面/纯黑剪影，再集中构建与服务端回归，用一个静音隔离Forge客户端检查两件四向、原时钟阶段、真实玩家受伤和资源重载。
