## 结构与绑定

九霄天将是器物中的超自然核心，中央雷印承担注视，低悬滑行、槌摆与两侧雷鼓体现活动。主构件为顶梁28×7×23、侧壁6×32×24、前框24×10×4/24×6×4、观察核心16×16×8、17×20×12双鼓、半径32/27的八折雷环。单位1/16格，前窗是真空隙。`root→body→chest→head/雷环/双鼓/载臂`，摆槌属于body；装备继续通过左右grip绑定。地面AI仍为原实现，没有赋予飞行或新攻击。

实际链路：DynastyClientEvents → BossCuboidRenderer → geo/animations/textures/entity/boss_cuboid同ID。全部PNG逐面UV，无平均色预览。描绘针对头、腹、壳、连接、角与攻击构件；不使用RNG噪点、不使用全盒子描边模板。图集是重绘原像素，没有把16px图放大当成果。

九霄碰撞0.7×2.3→3.8×4.25，龙王1.2×2.8→1.62×3.78；只同步实体实际体量。矩形受击框含身体内空腔、宽度不覆盖所有装饰尖端，不能视作精确逐部件命中。Minecraft地面近战Goal会根据实体宽度计算默认接近/触及阈值，尺寸变化可能间接影响近战触及；没有修改伤害、冷却、武器与技能逻辑。保留原导航，需要在实际地形验收通行能力。军阵场地源码为51×51、净高8格，模型可容纳；自然维度仅检查到原有生物群系刷新绑定，未验证实际生成地点。没有改变世界生成。

龙帝完整动作采样发现继承walk/attack最低点分别约−1.392/−0.775模型单位。仅增加root Y补偿，旧骨骼旋转、时长与技能入口不动；新采样最低点非负。龙王动画文件字节保持原样，两个龙的几何（除UV/纹理声明）完全一致。

## 可重复制作

在仓库根目录，用带Pillow/NumPy的Python执行：

```sh
python tools/art/boss-checklist/refine.py
python tools/art/boss-checklist/export_bbmodel.py
python tools/art/boss-checklist/validate.py
python tools/art/boss-checklist/review.py
python tools/art/boss-checklist/gallery.py
```

`export-owner.json` 是本源的上一版输出哈希；遇到手工或并发资产修改会在任何写入之前拒绝导出。旧 `secondary-cuboid/build_bosses.py` 的预检也拒绝覆盖新资产。不要更新旧16px生成器的基线以绕开保护。

交付页面包含同机位前后对照、五方向、灰模/黑剪影、原PNG与4倍图、UV编号/方向、18段完整WebP、普通观察距离、30张最终原生截图和三份可编辑bbmodel。
