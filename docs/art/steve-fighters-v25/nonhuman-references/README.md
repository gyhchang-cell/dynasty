# Nonhuman source visual study: 100 identities

100 distinct mob identities, not 100 class names: 83 AlexsMobs, 14 TwilightForest, 3 Goety. All ten corrected sheets inspected visually. Two gray software views per identity. Java Y-down is converted to world Y-up and camera up is positive world Y. Raven additionally uses the explicit landed foot Y=21 from its own setupAnim; initial source Y=0 would detach the feet.

Scope caveat: this is **100 nonhuman mobs of mixed sizes**, not evidence that all 100 are small. Whale, elephant, Laviathan, giant squid, Sunbird and other large species are retained as anatomy references, not small-unit scale references. Independently auto-framed cards must not be used to compare in-game sizes. No native screenshots, texture/alpha reconstruction, full animation/rig study, or gameplay attack verification is claimed. Flat alpha-masked legs/wings/antlers appear as opaque rectangles. GiantSquid is an elongated vertical bind pose; DeathTome pages use the unanimated layer layout.

Primary source commits:
- AlexModGuy/AlexsMobs: `09755dade2cfbdf14839e026d3af446f9d3ff843` (local official checkout).
- TeamTwilight/twilightforest 1.20.x: `e5d776e3b18258548f7fd618adf65315fbc8d053` (official pinned source; not claimed identical to the local 4.3.2508 jar).
- Polarice3/Goety-2 1.20: `02adbe7491767210f63857fa763a6f1de1262cbd` (official pinned source; not claimed identical to the local 2.5.51.0 jar).

No local jar textures copied. No production edits, installs, build, sound, UI or commit. Source cache and interpreted geometry are research artifacts only. `ledger.json` contains every per-source URL, SHA-256, geometry path, cuboid count, per-visual layout/support/interaction observation, and limitations. Items, skins, babies, multipart heads/tails, humanoids and incomplete procedural assemblies do not add identities. IceCrystal and QuestRam are deliberately omitted from the final set.

Relevant design observations: carp_spirit can draw on CosmicCod (16), DevilsHolePupfish (20), Mudskipper (50) and Snapper (98): axial torso, separate tail pivot, thin independent fins, and an explicit jaw rather than a humanoid torso. tree_spirit can draw on Flutter (26) and Leapleaf (100): central plant body, radial canopy/flower parts and low stable contacts; these are plant references rather than literal trees. clockwork_rat can draw on Jerboa (39), Raccoon (55), Skunk (67), SugarGlider (73), Squirrel (95): separate head/ears, four contacts, articulated tail and a horizontally biased small body. These are interpretation notes, not copied assets.
