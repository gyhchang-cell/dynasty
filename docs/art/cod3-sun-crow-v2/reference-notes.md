# 金乌：新增100张参考画面

已逐页查看247张有效候选图的13张联系表，排除图标、界面、宣传文字主图及重复图；按文件SHA256与已有cod3参考去重。这里是100张画面，不是100个模组。每张来源与原图地址见references.json。

主要观察：Alex’s Mobs的Sunbird展示了远空中展开翼的识别度；Roadrunner以头喙和腿区分鸟形。Mythic Mounts的飞行动物将翼根、翼尖和躯干分开读；Wyrmroost的Alpine上举翼、平翼与侧视显示，翼幅变化和末端羽片比细碎纹饰更决定轮廓。Dragon Mounts的滑翔与悬停图强调翼根连接和尾部配平；Naturalist的秃鹫、鸟群及Untitled Duck的鹅图用于检查喙、胸腹和腿的非人结构。其余图对照低面数体块、亮暗分区及地形中的可读性。静态参考不能证明对方动画时序，Dynasty的关键帧自行设计。

落实：保留原有乌金像素UV，双翼由翼根带动，外翼延迟翻转；三足前后错开且中央足更低，让正面和侧面均能辨认；保持长方体羽片、无粒子羽毛替身、无球体或圆滑曲面。不复制任何来源模型、贴图或动画。
