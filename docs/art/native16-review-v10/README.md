## 准确引用与间接影响

所有候选文件与未来目标完整对应见 [candidate-manifest.json](candidate-manifest.json)，每项包含候选路径、批准后目标路径、原文件哈希、备份路径、候选哈希及状态。候选路径以 `candidate/assets/dynasty/` 开头，未来仅映射到项目 `src/main/resources/assets/dynasty/` 的对应文件。

- 汉白玉与两种矿石保留原纹理名，现有 cube_all 与物品 parent 无需改动。
- **汉白玉也是 `dynasty:herbal_basin` 的共用盆体材质**。未来启用候选会改变药浴盆的石面；几何、UV、玉石边框、状态与功能不变。见 [共享材质影响](shared-material-impact.json) 与 [盆体对比](previews/herbal-shared-material.png)。药浴盆没有独立重绘或JSON改动。
- 修补炉候选 `models/block/jade_mending_forge.json` 只改纹理表和面纹理引用。3个元素坐标、默认UV、父模型、所有其他字段与原模型完全相同。北面为正面；东西南面为普通侧面；仅最上台面up使用工作面；底座与中柱up仍用普通底材；down使用底面。
- 新的 `models/block/jade_mending_forge_active.json` 继承上述模型，只覆盖 `front` 和 `top` 两个纹理键，无独立几何。
- 候选 `blockstates/jade_mending_forge.json` 只把四个 `lit=true` 分支改为 active；四朝向0/90/180/270与待机分支保持。物品模型继续继承待机模型。

### 修补炉实际 UV 与用途

| 现有元素 from → to | 上/下面 UV | 北/南 UV | 东/西 UV |
|---|---|---|---|
| [1,0,2] → [15,3,14] | [1,2,15,14] | [1,13,15,16] | [2,13,14,16] |
| [5,3,5] → [11,10,11] | [5,5,11,11] | [5,6,11,13] | [5,6,11,13] |
| [0,10,2] → [16,14,14] | [0,2,16,14] | [0,2,16,6] | [2,2,14,6] |

UV表由本机1.20.1 `BlockElement.uvsByFace` 与当前模型坐标核对；右下界不含。正面变亮像素仅 `(7..8,8..10)` 共6个，顶面仅 `x=1/14,y=6..9` 共8个，均位于可见面。没有新增动画帧或 `.mcmeta`。

现有功能是主手持受损装备，消耗背包玉×2与铁锭×4，修复最大耐久25%；所有面都可右键，没有实体投料槽、储存或后台加工。纹理的工作面与玉槽只帮助识别用途，不宣称新交互。成功后现有代码设置lit持续40tick，并已有10级方块光照。本轮只是局部状态配色，不新增emissive材质、自发光着色器或光照功能。
