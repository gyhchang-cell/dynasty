## 实际图像观察

已查看五张银甲PNG（四图标和64×64穿戴图），另四张三件衣袍/64×128图集作对比；没有缩改原图。`native-source-images.png` 是整数最近邻源码分析页，不是游戏。`raw-uv-crops.png` 展示银甲10方块的60个原始UV面矩形，UP有符号V仍存在JSON，裁片未模拟旋转、镜像和面绕序。

银甲正面大块浅蓝白，边缘青灰，侧面用两到三档方块明暗。胸图标为短宽胸片、上方分离的肩臂负空间和下方横腰带；不是整个人台。裤图标有完整横腰与两个直腿，腿间保留大开口。靴图标筒长、脚尖阶梯外展，透明腿间隙清楚。盔图标有前方立鼻片、侧下颊片与顶部折面，不是仅用白底填满头部。青灰深边是主体轮廓，不能误当背景删除。

逐面裁片看到胸前以大浅色斜阶片接蓝灰腹带，背面以一条窄竖亮块隔开暗侧，肩块仅5单位高；腿前是细长阶梯亮边与较大暗块，并非整条银白。顶/底盖面留较统一蓝块，避免每面铺同密度亮点。盔主方块的面罩区域留透明，额外guard只有两面有细窄亮片，其余大片透明；因此不能按guard的10×10×10包围体把它认成实心立方头罩。guard绕Y0.7854弧度，原UV矩形与最终世界正面有区别。靴为4×6×4下腿壳，腿甲为4×9×4与独立腰裆片，足槽/腿槽分工清楚。可学大块金属、短肩与腰腿分离，不复制像素。

三件衣袍图标用深蓝紫主体和较亮紫色阶梯折叠，长袍从胸肩延展到下摆，但不是裤子。穿戴图集将帽檐、分层帽尖、胸披袍、袖口、靴口和左右/背部下摆拆岛。其14单位大帽檐、分段弯帽尖不适合直接套用 Dynasty 普通盔甲比例；只作衣料面积、暗面和折边参考。染色版本不另计案例，也不凭文件名补出不存在的腿甲。

## 固定源码实际消费路径

Registry四条注册声明→SilverArmorItem(Type)→Material；四个物品模型分别引用对应item图。CLIENT MOD事件RegisterLayerDefinitions注册SilverArmorModel.createBodyLayer，AddLayers烘焙进共享SILVER_ARMOR_MODEL。每件IClientItemExtensions实际回调按getEquipmentSlot设置slot，copyFromDefault后setupAnim，返回模型；getArmorTexture明确覆盖为textures/entity/silver_armor.png，四槽共用一张专用64×64，不是普通layer_1/layer_2。

ArmorModel重建9个空别名根，headParts/bodyParts按槽分别选择头、身臂、腿与骨盆、双足。初始HumanoidModel.createMesh留下的普通腿仍是姿态来源，不能把这些根当作额外可见盔甲块。银甲自身有10个实体方块，具体层级、原点、姿态、膨胀、镜像与60个UV矩形均保存。

`copyFromDefault` 在 `setupAnim` 之前读取继承腿姿态，共享模型跨槽复用的最终时序没有运行验证。本批不把方法存在当作姿态正确，也不改外部源码。实际五视角、接缝、动作和运行消费仍待验。
