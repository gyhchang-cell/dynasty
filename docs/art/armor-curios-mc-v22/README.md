# 十张盔甲与器物图标重做 v22

本轮完成麒麟鳞甲、鸿蒙帝铠的头盔/胸甲/护腿/靴子共八张物品栏图标，以及玉如意、朱雀羽扇两张现有物品图标。先检查了上一批未选项、五把弓、其他资源和115张盔甲/相关图标；五把弓放大后已有完整材质和装饰，保留，不因尚未纳入原稿链就重画。相关审查见 ../remaining-assets-audit-v22/ 及 ../bows-curios-mc-v22/README.md。

制作前实际查看两套64×32穿戴UV，wearable-reference.png 为最近邻审查图。麒麟继续青绿鳞片、浅金边，鸿蒙继续靛紫、金属灰和古金边，图标加强鳞片、护膝和靴头分区。没有替换实体穿戴UV/模型；这八张修改的是物品栏及手持物品模型图标，不把图标变化声称为穿戴建模重做。玉如意保留云头、玉柄、金箍和红穗；朱雀羽扇由细杆状旧图改为明确的大扇面、朱红羽片和短握柄。

每件通过内置imagegen单独制作，提示词和路径见 selection.json，原稿在 sources/。第一次鸿蒙头盔错误生成了整套装备展示，审图后拒绝，保留在 rejected/，通过内置图像编辑重做为单件头盔后才发布。其他图检查单件主体、名称、两套配色、靴子与护腿区分和32px缩略。保持粗像素台阶边缘、有限材质色块；未缩成16px、未量化，运行PNG以方形透明裁框保留主体比例、再补2px边；只裁透明区域，主体RGBA精确匹配原稿。

统一 inventory-refresh/install.py 原稿发布链。八件盔甲和玉如意沿用原版generated的显示变换，朱雀羽扇沿用solid_handheld左右手变换；通过现有original_item加载器按新轮廓生成侧边。注册ID、装备属性、穿戴UV、技能、配方、存档保持原样。无图形原生解码/模型侧边/UV/图集检查见 native.log，逐像素检查见 review.json。本地JAR和现有导出文件只替换10PNG、10模型、图集过滤表，保留其余载荷，见 DELIVERY.json 和 installed-readback.json。

comparison.png 每四件一组，上旧下新，来自实际运行PNG；after.png 为新稿总览，inventory-32px.png 为小图审查。它们是资源展示，不是游戏截图。没有启动/重启/关闭游戏，未操作声音、亮度或存档，真实客户端持握和界面画面尚待实机检查；未推送GitHub。
