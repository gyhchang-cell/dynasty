- 当前图标32×32、8种RGBA（含透明），是金边的窄竖牌形，缺乏肩甲和领口轮廓。`tools/art/gen_armor.py` 记载沿用旧玄天贴图的起源。

## 设计

深钢护片作为主体，铜金边只落在领口、肩沿、束带和连接处。胸前保留小型青玉扣。图标采用明确的开口领、宽肩、胸腹叠片与短腰甲，正面平面构图，无人物、长袍轮廓或斜视3D图。

图标在32×32网格内直接绘制，12个可见颜色，透明度仅0/255。穿戴图单独在已有64×32展开图内绘制，没有将物品栏PNG贴到人物上，也没有生成高分辨率大图再缩小。
