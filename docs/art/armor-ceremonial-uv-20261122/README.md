# 礼仪甲头部双层与腰部对照

以固定 Forbidden Arcanus 提交 `189c3ca451af186415e3e2f3f0fbb4d8226819b6` 的 Tyr 与 Draco Arcanus 两套为对照。八件装备的四槽注册、物品模型、物品 PNG 和两套穿戴图都核到了本地原档。两套都是直接用材质和装备类型构造的 ArmorItem。此处沿用已固定的原版两层 UV 上下文，查看了两套四件图标以及从四张穿戴图取出的原始裁片。

Tyr 的主头面有窄鼻梁，外帽正面留空。主头与外帽按相同像素行对齐，下方连续三行没有遮挡像素。其四面腰带只占最后四行，金扣集中在前片，后片和侧面收成小亮块。对青铜和将军，最可复用的是开口留白、短腰带和前后区分。

Draco 的外帽包含额饰及侧翼，主头和外帽都保留中间眼缝。按同索引对齐后，眼缝所在行共有六个透明像素，后续三行各剩两个，远少于 Tyr 的开口。它更适合作为天将和玄天保留外饰时的遮挡风险对照，不适合作为扩大开脸的直接目标。两层具有不同膨胀量，同索引透明数只用于定位后续检查，不能替代正视和斜视的真实遮挡验证。Draco 的腰带使用最后五行。两套的上下躯干盖面均透明。

两套已各有固定来源和整套观察，本轮补充的是主头与外帽联合透明区域，以及四面腰带在同一坐标下的对照。两者间的装饰差异保留为设计观察，不新增独立设计信用。首稿和修复范围沿用已有收据。有效参考门槛仍未达标，五套继续待制作和实机验收。
