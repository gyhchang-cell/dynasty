## 实际修正

旧版方解石连接线固定在y=17，部分埋在收窄后的洞顶上面。现在逐列找到最高空气方块，将星图线嵌入其上方的第一块实心顶壳，让线的底面在洞内可见。五个紫晶星结贴合阶梯顶面，中心发光晶尖有不同高度；四角晶簇改为收尖主柱与错位副晶，保留不同高度。中央五格宽、四格高净空的十字通道与四个入口保持完整。

结构仍为31×19×31、单片jigsaw，只使用已有原版方块/贴图和9个海晶灯。无动画实体、粒子、声音、奖励或玩法逻辑。生成高度、间隔、群系与旧存档行为不变。`scenic_caves.py --crystal-only` 仅导出水晶穹顶，保留冰洞资源和记录。
