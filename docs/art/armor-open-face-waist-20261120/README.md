# 五套穿戴 UV 修复范围与原图参考

本轮实际查看了原版铁、皮甲及 Twilight Forest 铁木、Caverns & Chasms 银甲、Ender IO 深钢四槽套装的 10 张固定原生穿戴图。并列查看两层完整图集、头面和外帽面、护腿躯干四面。铁木与原版皮帽的前脸透明布局相同，可参考少量色点如何提高辨识度。已回查它的四槽及图集绑定，仍属历史铁木家族。原版铁面保留短鼻梁，下缘逐行打开。CaC 银甲的眼缝较窄，护腿前后在腰带上沿倒角，供较厚甲片完成转角时对照。Ender IO 深钢保留深色两颊和前面缺口，只参考旧版贴图布局。它的 1.12.2 特殊面罩和涂漆分支不用于 Dynasty。三套模组参考此前已归档，原版两套只作 UV 基准，本批不增加设计计数。

五份第一层外帽正面都透明，主头面各有自己的开口轮廓。第二层前、背和双侧主要集中在最后五行，CaC 例在前后多一行局部倒角，两个躯干盖面在五份样本中均透明。后续可用最后四或五行腰带作为 Dynasty 的初稿比较，按原设计选形。用边界像素检查折角，不直接复制任何参考图的颜色或轮廓。

## 每套的处理重点

| 套装 | 头盔前脸需保留的身份 | 护腿腰部需保留的身份 |
|---|---|---|
| 青铜 | 短铜盔和左右颊片，中间留开脸 | 铜边与暗夹层 |
| 将军 | 金边、深灰板与酒红小点，眉下留开口 | 深灰重板和窄金扣 |
| 玉 | 青玉眉缘和两侧包边，留眼鼻开口 | 玉绿大面和暗接缝 |
| 天将 | 冷蓝与金色短冠，额下留开口 | 冷蓝底及少量淡金边 |
| 玄天 | 金角冠的额缘与蓝绿焦点，收住面部装饰 | 深蓝腰带和有限的金、青色扣点 |

第一层只允许改头正面 `[8,8,16,16)` 和外帽正面 `[40,8,48,16)`。其他朝向、躯干、手臂、双腿与靴的像素逐一保护。两层头面需要同时检查，避免外帽挡回主头面的开口。正面 UV 边缘若与侧面有断口，先标出接缝再决定是否需扩大保护范围。

第二层把躯干四个侧面按腰线检查，上部清空范围与可调整腰带范围分别落在 V=20–26 与 V=27–31。两个躯干盖面也纳入核对。腿部 UV 整体保护，库存模型与图标按当前哈希保护。每套的确切矩形、ID 和验收约束已写入 JSON。当前只记录可改范围和方向，具体验收还须检查单穿护腿、全套、正侧背及抬头低头。1,000 个有效参考门槛维持未通过，未替换项目贴图。
