# Runite 与 Tidesinger 穿戴对照

从 Mythic Metals 的同一固定 1.20.1 提交补查两套四槽装备。原档核对 32 个条目，逐件照读图标模型，目视八张图标、两张专用头部用图，以及 Runite 实际护腿图的腰带裁片。图页只放大原始 UV，面片的世界投影和叠层遮挡仍待实机。

Runite 只有头盔派生自 HallowedArmor，进入同一个 Fabric 渲染器。头部用 64×32 专用图集，面甲的正面裁片是 [7,28,17,32)，主头面仍占 [8,8,16,16)。对应像素掩码与前一批 Hallowed 的主头面和倾斜面甲逐行相同。Runite 少了两侧翼，仍归入同一种头盔专用渲染机制。这套护腿用标准第 2 层，前后腰带均保留最后五行。

Tidesinger 四槽均派生自 HallowedArmor，走同一注册器但返回 128×128 的专用模型图集。默认图集和五个珊瑚分支由装备数据选取。本次只查默认图，珊瑚分支保留为同套变体。头壳正面切片 [9,35,18,44) 有连续开口，额冠独占平面 [0,118,15,128)。躯干根的腰带方块和腰扣平面只在护腿槽开启，胸甲片和胸饰只在胸槽开启。腰带前面 [45,13,55,16)，后面 [61,13,71,16)，腰扣前面 [43,122,52,128)。这样单穿护腿时可保留腰带和扣而隐藏胸片。可复用的是分槽边界和额饰留出脸区的思路。Dynasty 五套候选仍按现有 64×32 坐标做贴图修复。

Tidesinger 的四槽分件和腰扣机制区别于只替换头盔的 Hallowed、Runite，也区别于腿槽只绘制双腿的 Electrum。作为一套新增候选等待全局去重及验收。当前批准计数没有增加。
