# cod6 本地 Boss Cuboid 资源改造

真实范围来自 DynastyEntities、ArmyEncounters.BOSSES 和现有章节任务：叛将、宦官首领、亡故始皇、九霄天将、龙王、龙帝。镇渊帝君的最终 Boss 身份和已认可模型保留。先在隐藏、静音的原生 Forge 客户端检查六只当前模型，baseline-01 的24帧仅为旧模型对照。

最差首批三只不是只按面数选：宦官和始皇在实际游戏中仍是相同的直立主体加悬空碎片；龙王仍有普通人形脸，三只256px贴图各逾一万种颜色。此批实际新增 geo、animation、PNG，并通过客户端 GeoReplacedEntity 接到原有实体；没有修改实体、战斗、任务、AI、存档或碰撞。旧 Java 模型与旧资源仍保留兼容。

| 实体 | 体块比例和独立结构 | 骨骼/动作 |
|---|---|---|
| eunuch_mastermind | 34单位高，胸8×7×4、腰5×2×3、骨盆7×4×4；长袖、分片袍摆、面罩方冠与背部符匣 | 31骨/38 Cuboid，肘下独立袖骨、手与握点、袍片/符匣流苏；施术举袖，呼吸克制 |
| undead_first_emperor | 34单位高，胸10×9×6、腰6×3×4、骨盆8×5×5；厚棺甲、空洞脸、冕旒与垂带 | 35骨/42 Cuboid，胸甲/肩甲、五条冕旒、分片棺裙、背部束带；缓慢摆带和沉重举臂 |
| dragon_king | 44单位高，水蛇下盘、宽鳍、前探龙吻、珊瑚分叉角、爪臂、三节贴地尾；没有人类双腿 | 24骨/39 Cuboid，lower_coil→tail链，胸→颈→头/下颌/角/须/鳍；尾摆、开颌与爪臂发力 |

三只贴图实际16×16，三种角色色加白色共四纯色，2px白边、2×2硬色块正面肖像。逐面UV复用非白色岛，不把白背景采到实体。六个独立动画文件片段：idle/walk/attack/cast/hurt/death。静态验证逐项检查拓扑、UV、颜色、骨引用、循环接缝和当前资源SHA。review图是软件六面检查（正面/45/左右90/背面/黑剪影），不能当游戏截图。

首批原生重验记录以 accepted-runs.json 为准，当前最终运行 first3-cuboid-04 为每只五个实际角度及六个资源动画，共33阶段。客户端真实读取16px PNG、烘焙六段动画，校验握点为手的子骨；另外逐帧视觉检查实际装备。first3-01 的剑和三叉戟横放、02 的三叉戟向下、03 的三叉戟偏离手掌，均是诊断版而非验收版。04 对剑保留正确骨空间，对原版三叉戟使用其内置模型并把柄中段放在实际掌心；不再套用假定人形显示矩阵。始皇肩甲的共面也已修正。

所有客户端只使用一次性世界，禁用声音，隐藏窗口且不聚焦，不操纵亮度或屏幕电源。run_native.py 在启动前复制资源、Java类与QA类，各次 runtime-manifest.json 绑定精确版本。QA类和隐藏窗口agent不进入生产JAR。产物SHA和主工作区同步列表记录于 primary-sync.json；产物基于23:33隔离源码与本轮美术，不能冒充含其他开发者全部最新修改的整合包。

**cod6 提示词继续保留。** 当前33阶段只验证资源与自动选择的动作，不证明真人游玩、自然施术命中时钟、受击/死亡真实落地、竞技场技能锚点或12–18禁卫成队负载。cast资源尚未绑定服务器私有技能计时，需在对应战斗开发者提供同步状态后接入。叛将的独立甲胄和物理攻击时钟保留；下一批修龙帝现有四足/九节尾巴的UV和前爪支撑，以及九霄天将分层甲胄、冠翼和雷楔，保留已有雷阵表现。

格式和坐标依据此前读取的 [Blockbench](https://github.com/JannisX11/blockbench)、[GeckoLib](https://github.com/bernie-g/geckolib/tree/1.20.1)、[blockbench-plugins](https://github.com/JannisX11/blockbench-plugins) 原始源码；固定提交与具体文件在 ../secondary-cuboid-v1/README.md。运行接口核对本仓库实际 Forge1.20.1 / GeckoLib4.8.4 JAR。没有复制其他模组美术。
