# 600 个真实方块的原生 16×16 参考审计

这批文件是本机只读参考研究，不是 Dynasty 贴图，不可装入游戏资源目录。参考的是色块组织、结构和细节密度，不使用他人像素图案制作 Dynasty 候选。

## 来源与计数

来自原版及 28 个模组命名空间。单个非原版模组最多 21 个样本。整合包是本机安装来源，不是素材作者。

每个样本由真实 `blockstates/<id>.json` 开始，解析变体、模型父级、`elements.faces.texture`、`#` 绑定，再取得 PNG。审计记录真实 block ID、整合包、JAR、方块状态路径与哈希、模型父链与哈希、具体面、纹理绑定、PNG 路径、尺寸、文件 SHA-256 和 RGBA 像素 SHA-256。

全局 600 个 ID 和 600 个像素哈希都互异。只选静态 16×16；不将动画帧、不同模型面、不同版本 JAR 计成额外方块。透明像素的不可见 RGB 统一后再做哈希。对于每个方块，仅第一张满足尺寸要求的代表面参加抽样；若这张面已出现，整个方块淘汰，不换取其他面来补数。显式排除 waxed、infested、budding、楼梯、台阶、围墙等外观复用变体，以及羊毛、混凝土等染色家族。原始采样脚本里曾允许重复首选面换到第二面，已在最终审计中删除该行为并全量重采样；以当前 JSON 和联系表为准。

样本按类别轮流挑选，以 ID 哈希排序，不是每个模组按字母顺序取前 20 张。类别是方便浏览的命名启发式，不是游戏功能的权威分类。

## 视觉观察

已逐页检查最终 12 页，共 600 个代表面。以下是结构观察，不是可复制的图案授权。

1. **原版石砖 #009、暮色城堡砖 #081、Goety 高岩砖 #203**：主要形体先于纹饰。砖缝是同色系的一档暗色，砖内仍有几组不规则的短灰簇；并非把矩形画上统一斜角高光的界面按钮。浅石应保持低对比，避免每条边白亮。
2. **原版凝灰岩 #017、Create 层状深板岩 #125、Meadow 石灰岩 #383、Undergarden 寒石 #484**：粗糙可以由成簇色块与方向表达。凝灰岩较碎，层状深板岩偏水平，寒石偏斜向断面；一套材料选择一种主要组织方式。不要给每块石材都布满相同随机点阵。
3. **原版铜矿 #018、钻石矿 #022、Create 锌矿 #128、Ice and Fire 蓝宝石矿 #248、Undergarden 钙铁矿 #485**：石头是连续背景，矿物只占有限面积。矿物有 2—5 像素的可读小面及内嵌亮点，簇的间距和形状不同。把矿画成一个大菱形宝石会变成贴在石头上的物品。
4. **原版高炉 #027、熔炉 #033、Create 铜外壳 #129、Galosphere 燃烧台 #345、Meadow 炉砖 #396**：槽、格栅、框和开口比徽章更容易传达用途。用大一点的交互区域和次要边框；正面不应被装饰纹样占满。这里仅研究面材质，盆、炉、台的实际中空结构仍依赖模型。
5. **原版铜块 #041、铁块 #043、Create 黄铜 #132、Quark 铁板 #460**：用有限明暗段落和少量方向性反光表达金属，不需要照片反射。原版铜允许较亮局部，但整面大面积白色会失去铜的体色。
6. **Decorative Blocks 木梁 #262—273、Ecologics 木板 #421/#430、Bountiful Fares 木材 #434—439**：纵向木纹与横向板缝读得清，结疤或亮边是少量局部特征。不同木种除了色相，还改变纹理宽窄和节奏。
7. **雕纹与高饱和特殊块**：Chipped #293、Malum #574/#583、外末地冰晶 #534 的饱和度或对比明显高于普通建筑石。它们适合了解特殊材质上限，不应成为 Dynasty 普通墙面的默认对比度。不能照抄其徽记、螺旋或专属纹章。
8. **适用于 v11 的判断**：让墙砖在 1× 时先读成墙，让矿石在 1× 时先读成石中矿簇，让功能方块先读出开口与工作位置。最近邻放大用来审像素组，3×3 用来审砖缝接续和重复斑点。图案的“干净”不等于大面完全纯色；需要受控、成簇、低对比的材质细节。

## 范围限制

每个样本只展示实际模型使用的一张代表面，不等于完整方块渲染。少数复杂模型会出现支座、框架或面板材质，不能从这张面推断整个模型外形、碰撞、交互或发光。比如磨石的木支架面、工作台的侧面都只是模型的一部分。没有启动游戏，不能由联系表宣称游戏内效果验证。对结构有用的参考与高反差特殊材质均被保留，不主张全部 600 个都符合 Dynasty 的目标风格。
