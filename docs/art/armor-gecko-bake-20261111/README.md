# D38 Gecko 原生几何与版本边界

仅研究，未启动 Java/游戏，未改任何生产资产。16份 GeckoLib Forge 1.20.1/4.8.4 源文件取自官方 Maven sources archive，校验上游 SHA1、归档 SHA256与解包字节。实际阅读范围和固定条件见 source-contract.json。

逐项记录 Ars 三份原生geo的61体、366面；41体逐面UV、20体boxUV，8镜像、2旋转。按原生规则记录X坐标变换、膨胀、pivot、角度、六面顶点路由、UV、分槽可见骨与slim子树。局部尺寸与UV检查通过。基础部位可见时，轻/中/重四槽体数分别2/6/4/2、6/7/4/2、2/6/4/4；不是49个独立设计。

重要新边界：Ars固定源提交声明4.4.4，而Dynasty目标是4.8.4。已读取两版本实际diff，局部cube几何规则相同；4.8.4新增UV旋转，本批没有非零UV旋转。原生盔甲槽可见性在两版本不同，不能忽略baseModel的部位可见状态。具体见version-review.json。没有把差异当已确认游戏故障。

没有生成穿戴三维图。完整层级/实体基模/动画/外部hook与自定义factory仍需闭合；本地数值研究不是原生Java执行或实机穿戴验收。累计仍652名称、638盔甲名称、215保守组，独立设计信用未新增，1000门槛未达。289保护文件不变，未删除提示词。
