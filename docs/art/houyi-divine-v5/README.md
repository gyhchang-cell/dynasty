# 后羿神祇形态

后羿虚影由长方体拼接改为独立曲面网格：收腰胸廓、颈部与下颌、鼻梁、耳朵、发光双眼、上臂和前臂、关节、手掌和手指、分离的双腿与靴履。装备包括曲面胸甲、叠层护肩、护臂、日轮神冠、腰封、分片战裙、长发与曲面飘带。

模型仍在玩家身后约 4 格的位置，以约 10 格高度、2 秒的时间逐渐形成。显形平面直接裁切曲面多边形。渲染改为独立的半透明明暗表面，不再描绘长方体轮廓。

后羿虚影自己的头顶新增两层旋转法阵，形成位置分别在虚影脚底上方 10.35 格和 10.55 格。玩家原有的小八卦保持独立。

`preview.png` 由实际网格与法阵代码导出，展示全身及面部细节，不是游戏实拍。生成入口为 `tools/art/HouyiAvatarPreview.java`。

验证：Java 编译、完整打包、4 项 Forge GameTest 均通过（空中护盾、范围伤害与玩家排除、清障范围与容器保留、锁敌与遮挡）。尚未做实际游戏画面的视觉验收。
