# 术士袍穿戴参考与历史研究复核

Eidolon 的术士袍原生套装由帽、袍、靴组成，共三件。三件均用 `WarlockRobesItem` 注册，各有自己的物品模型和工作台配方。穿戴全部接到同一个 `WarlockArmorModel` 和专用 64×128 图集，未染色时读取 `warlock_robes/blue.png`。头槽画帽体，胸槽画袍身、袍背及双袖，脚槽画双靴。基类虽支持腿槽，原生注册没有术士裤。

实际查看三张物品原图及蓝、黑、白三张穿戴原图。蓝色胸像用深底和较浅的交襟表现衣服结构，短袖末端用同一亮色呼应衣襟。帽沿和靴口保留清楚的粗阶梯。可用于审视 Dynasty 布甲和锦衣的衣襟辨识度与袖口收边。宽帽沿和长袍使用专用几何，不能作为原版盔甲图标比例，64×128 图集也不能直接套入 Dynasty 的穿戴 UV。

染色共用同一套几何和四槽选择规则。染色分支、单件和图集页都归入同一设计。已有法师参考也有尖帽和长袍，当前材料不足以确认术士袍是全账本新增独立语义设计。先归入既有法师帽袍学习范围，新增正式计数为零。

历史账本内 43 份来源哈希均可验证，654 个历史名称中 640 个被映射到 215 个保守学习组，另有 14 个范围排除项。43 个整套复核键与 48 个后续条目可作研究索引，彼此也可能与上述组重叠。账本中有 1 个经确认且复验回执的本地独立整套设计。参考总计与精确缺口仍未核定，1,000 个参考门槛仍未通过。逐项审计范围、去重说明和历史来源见同目录 JSON。
