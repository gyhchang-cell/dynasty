# Mythic Metals 六套穿戴参考合并审查

核查三份历史收据及其列出的 113 个文件。实际比较六套的注册路径、头面像素、面甲及躯干腰带。

青铜沿用基本双层渲染，作为现有开面材质范例。Hallowed、Runite、Banglum、Metallurgium 共用一个仅替换头盔的机制，其余槽回到标准蒙皮。Hallowed 与 Runite 的主头和面甲正面裁片透明掩码一致。Banglum 与青铜的主头开口除顶部一行外也一致。不同头饰与绘制细节保留为设计观察，四套专用头盔先按一个待审核家族归档。

Tidesinger 的单独腰带、腰扣可以随护腿槽绘制，胸片同时隐藏。这份消费链与 Electrum 脚本直接绘制腿块不同，保留为最高优先的整套候选。全局语义去重和独立验收未完成。本批最多保留两个候选家族，新增正式计数为零。
