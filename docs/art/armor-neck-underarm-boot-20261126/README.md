# 五套旧盔甲的头颈、腋下与靴口

沿用青铜、将军、玉、天将、玄天的旧模板证据。本轮看了九张图集的指定裁片，分别记录头颈底面、袖片近肩侧和靴口。Dynasty 五套第一层的头底、帽底、胸顶、袖片两侧上四行、靴顶和靴正面上四行都全不透明。胸顶与靴顶属于不同槽位，像素实占也不等于实际姿态中的遮挡。

| 固定参考 | 槽位归属与图集观察 | 对五套的用途 |
|---|---|---|
| Aether Valkyrie | 采用原版分槽。头和外帽底、胸顶、靴顶与靴筒正面前四行留空。袖片两侧近肩仍满铺。 | 最贴近天将和玄天的礼仪金边分配，也可作其余三套的孔口基准。袖部覆盖保留为可行方案。 |
| Cold Sweat 山羊毛甲 | 按槽返回专用模型。头底留空，毛领挂躯干随胸甲，位置按视角调整。独立靴模型的靴顶与正面前四行留空。 | 青铜和玉甲可借鉴头底与胸领明确归属、降低无效覆盖。动态毛领只作分槽对照。 |
| The Betweenlands Ancient | 一张图集由独立槽位子树消费。头罩底透明，近肩护片侧满铺，靴顶透明但筒口正面四行都有颜色。 | 将军铠优先参考短护肩和靴筒边缘。靴口透明可以与连续靴筒同时存在。 |
| Ad Astra 基础太空服 | 专用图集与槽位可见性。头槽独立启用头壳和面罩，底面分别有 62/64、20/64 个非透明像素。脚槽启用专用靴层。 | 密封环是封闭设计的例外，可用来界定何时头底满铺有意义。太空轮廓和材质与五套无直接关系。 |

近肩侧裁片只能确定材质实际铺到该位置。裙袖或袖片在摆臂时是否挡住腋下，要看胸槽单穿、抬臂与混搭。脚部先实测单穿靴、单穿护腿与组合，再确认内外层边界。上料与修复沿用原 64×32 UV。头底、胸顶、袖片和靴口都在先前冻结的编辑范围之外，当前列为只读验证项。

四个来源分别采用标准分槽、逐槽模型、共享图集切子树和独立面罩/靴根。它们已有整套研究，这次只是提取更贴近缺口的部位证据，不重复累计。门槛未达到。未修改生产 PNG、共享包或清单，未启动游戏。
