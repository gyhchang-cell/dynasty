资源ID为 `dynasty:scenic_fire_tree`；模板原点为最小坐标角，y=0是封闭沟底，不是岸面。相对原点：根锚点 `[24,9,25]`、效果锚点 `[24.5,26,24.5]`；入口 `[7,7,0]` 与 `[39,7,0]`；观景点 `[12,11,18]`、`[12,11,37]`、`[34,11,21]`。16个粒子可用花芯坐标在 `geometry.json` 的 `bud_centers`。若按方块中心发出，应各坐标加0.5。旋转/镜像必须与模板设置同一变换，不能只旋转模型不旋转效果锚点。
