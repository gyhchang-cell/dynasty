本次新发现：

- 纹样沿弧长推进UV，可以保持图案密度；按点序号会随采样疏密拉伸。
- 折角投影厚度需下限，零长度/视线平行需备用轴；圆角细分不作为MC造型方案。
- 出生位置/缩放/模拟空间须分开，跟随护体与已经散出的余纹不能混用变换。
- 出生、延时、终态和子效果各自有明确刻序；曲线须clamp到寿命终点，避免最后一帧错误放大。
- 多层符面挂点需按左右手镜像；稳定实体相位和独立层比只有换色更适合流派辨识。

本轮具体发现：

- 真实残影必须保留历史姿态；仅记录旧位置再渲染当前实体不等于姿态残影。
- 第一/第三人称、左右手、FOV与武器长轴的矩阵顺序需要独立核对；ALONG_MOTION的90度校正放错层会丢失俯仰。
- 跟随实体的护体纹样应按实际UV尺寸重复；临时骨骼缩放、第二皮肤隐藏与shader状态必须还原原值，不能统一重设1或默认色。
- 联机纹样寿命用一致世界时钟；渲染帧中重复spawn/update会造成帧率依赖。
- 迎面束流叉积退化、短距离hull计数为零、零长向量与遮挡是必须补验的边界；没有将读源码当作这些边界已经实机通过。
- 方形环带、延时重算的Cuboid残影与少量独立符面适合本项目；球壳和密集三角星芒不作为新造型依据。
