## 对后续本项目贴图有用的结论

1. 符面先看粗主干、中心留孔、符首/符尾和节点节奏。不同元素若只有颜色不同，不能称为两套学院身份纹样。
2. 装备先保留足够的大块底材。金属硬高光、布褶和链甲分别集中在合理局部；白金、铜灰等配色不靠全套描亮边。
3. 原版纹饰的稀疏线与留白可用于校准 MC 感；不能把其原像素挪到王朝作品里，再用换色冒充原创。
4. 上下层和多面必须在同一实际 UV 下协调；非对称符字不得随意镜像。只有完整绑定后才可判断接缝和朝向。
5. 既有镇岳刀、北辰枪、两弓、笔杖、天子剑的精致原稿保持；当前图片核看不是授权重画它们。尚未接入的专属纹样也不能靠放一张无人引用的 PNG 宣称已完成。
