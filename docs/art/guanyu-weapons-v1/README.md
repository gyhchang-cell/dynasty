# 天子剑/青龙刀新贴图与关羽护卫

## 贴图

使用内置图像生成分别重画，完整提示词见 `image-prompts.md`，原始透明图在 `sources/`，旧贴图在 `before/`。

- 天子剑：银金剑身、龙纹护手、红宝石、红色缠柄。
- 青龙偃月刀：宽银刃、青金龙纹、龙首刀座、青金长柄、红缨。
- 游戏贴图为 128×128 RGBA；实际可见轮廓分别为 122×122、123×123，约占物品格宽高的 95.3%、96.1%。只留 2–3 像素透明边，不把轮廓裁掉。
- 继续使用标准 handheld 模型；本轮只改贴图，不改武器攻击距离、基础伤害或物品栏 GUI 缩放。

## 关羽

主手拿出青龙偃月刀后，背后约 4 格的位置自动浮现约 9 格高的关羽模型，约 2 秒由下往上形成。换掉刀后消失。替换的是原先背后的青龙护卫，头顶结阵/天降青龙伤害机制保留。

参考照片中的红脸、长须、绿袍、金甲、头冠、左手持刀与右手抬指。模型有独立的脸部、胡须束、手指、披袍、甲裙、双腿和刀，不是照片贴片。它仍然是风格化游戏模型，不能当成参考雕像的写实复刻。

复用神像曲面渲染管线，关羽 34,112 个面，最近 32 格内最多绘制两尊以控制开销。客户端和服务端应同时更新（网络协议 5）。

## 清除遮挡

只有持刀时关羽当前已形成部位的近似占用形状会清除普通方块，每 10 tick 最多清除 64 块。正常产生方块掉落，不自动恢复地形。容器/机器等方块实体、液体、基岩等不可破坏方块跳过；遵守玩家建造权限、出生点保护及 Forge 破坏事件取消。旁观模式不清障。其他保护模组的兼容性需对应环境验证。

**这是实际破坏地形的功能，建议先备份存档或用测试存档试玩。** 本轮没有打开玩家的存档执行清障，只在自动测试世界验证。
