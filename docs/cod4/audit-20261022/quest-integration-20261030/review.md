# 当前新增内容的任务衔接审查

已逐项核对六把机巧兵器的当前任务正文、直接前置、六份配方，以及 ContentProgress 和 ProgressionMerchant 的取得/制作回执与交易条件。全书结构扫描覆盖 1259 个节点；31 份 COD4 配方映射到 65 个节点关联。关联数包括多个既有备料任务及不同配方共用物品，不是 65 件新增内容、65 个独立机制或新增研究信用。

六兵器现有路线合理：主线精钢 → 奇门机括 → 奇门钢索 → 连弩/绳镖/飞爪；鸳鸯钺从机括分支进入。重弩同时承接连弩和第四章龙晶，流星锤同时承接绳镖和第四章龙晶。重弩配方消耗连弩，正文已明确提示。当前任务依赖没有缺失 ID 或循环。此结论仅限任务图，不证明材料自然取得或实机表现已完成。

商店是有条件的获取途径：官阶3或护卫3开放部分机巧商品，需找到尚书、潜行主手交互、真实付款，并使用玩家保存的每日库存。配方书发现条件和实际使用门槛应分开，不能为了任务衔接新增基础使用门槛。补给品仍以实际制作记录推进，不能改成持有即完成。

这些是后续接入位置和待审边界，尚未写入生产任务书。新增节点前仍须满足用户要求的该范围1000处真实相关实现研究，固定来源、具体阅读证据、语义去重与独立验收。历史机器辅助1000结构比较不自动满足此次 NBT 变体语义研究。

制作时应先查清现有制作/灌注事件能否提供原生回执，严格匹配实际结果 NBT；不能凭配方文件名创造不存在的独立物品注册、不能用基础物品持有冒充变体制作，也不能再次发放旧任务奖励。材料说明可回链原节点，基础物品/已完成进度及原奖励 ID 保留。毒烟可作可选支线，不强制改写主线讨伐路线。

验收分开记录：结构（节点/配方/前置）→ 实际制作或交易及材料付款 → 重登/重载不重复奖励 → 两人归属 → 必要的自然生存获取。既有31原生节点通过记录保留，本次没有重跑它们。当前缺口继续归属原 COD4-7 闭环整项，不额外复制待办、不删除未完成整项。
