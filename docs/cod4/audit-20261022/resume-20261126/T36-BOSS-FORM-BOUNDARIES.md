# Cod1 首领形态交界

核对断代凶镬·饕宴之尸和殉节盲帅·公孙无妄。私有候选包与离线重建包的两套实体、注册类和模型选择类字节一致。四个形态的包内模型和动画与工作区逐字节一致。采样以站立底中心 (12.5, 80, −8.5) 为示例，输出面向 +Z 和 −X 时的挂点世界坐标。实际战斗切阶段前的动作、移动与方位由场景决定，转场前一帧采用一期待机作为对照。

源码在血量阈值切阶段，只更新阶段数据、时钟和移速，没有随形态改变站立 AABB。上述越界表示模型相对于该 AABB 的空间差异，独立部件是否遮墙或被攻击命中仍需实际世界判定。所有可见支撑在这段采样中都没有穿过模型局部地平面。

## 公孙无妄

- 阶段切换时立即加载步战 Geo。第 0 tick 的旧马子树保持可见，摆架仍收起。四蹄接地，武器轴心在局部高 2.6875 格，与骑乘待机相同。
- 第 30 tick 之后，两个步战摆架出现。第 32–48 tick 同时可见两摆架和四蹄。第 50 tick 旧马和四蹄归零，只剩两个摆架，直到第 60 tick 返回二阶段待机。各可见支撑底面维持局部 Y=0。
- 刀的双握架从高 2.6875 格下降到 1.6875 格。登记 AABB 仍为 5.2 × 3.8 格；刀头在转场开始高过 AABB 顶 2.0125 格，转场后仍高过 1.0125 格。主要身体的誓台枢轴与武器同步下移。不能用刀的外沿高度代替整只的可碰撞高度。

## 可复用画面与缺口

饕宴已有 0、24、31.99、32、40、64 tick 的专用软件帧，工序文件明确使用二阶段模型和 32 tick 的纹理选择。公孙无妄可沿用对应步战文件夹的变形连帧。两组都缺能绑定当前包、同一实体 UUID、阶段时钟和实际碰撞盒的游戏连帧。历史服务端断言没有给出这些字段。

实机采集建议按各自阈值触发，用同步的 SHIFT 时钟找第 0 tick，同时记本体位置、yaw、AABB 与足底；饕宴优先 24、31、32、33、48、64，公孙无妄优先 30、32、40、49、50、60。变形后发生的首次攻击应另存技能起始标记。没有实机文件时保留建模离线子项，不注销 Cod1 待验项。
