# COD4 六阶段成长路线静态可达性审查

本轮只读正式实现，所有新文件均在本目录。未启动游戏、未操作GUI、未复测食品，未修改Java、资产、任务源、主表或待办。原规格对照 `docs/cod4/request.txt:383–392`；既有1000条同范围实现研究只读复用，不作为1000次实玩。

**结果：当前1259个任务节点没有缺失前置或依赖环。595条王朝配方形成6组循环关联，均存在循环外来源或替代配方候选；未证实必然死锁或必然不可获取。已确认5项顺序/成本事实，见下文。静态审查不能关闭六阶段自然生存、2–3小时开局替代节奏或刚获得即淘汰的体验验收。**

## 五项已证实事实

1. **木矛主任务提示在铁基础设施之后。** 当前 `1000000000000000` 的祖先包含铁镐 `1000000000010020`、水桶 `1000000000010021`，其基础配方合计需要6铁锭。木矛自身仅2木棍+1木板。可提前制作木矛；这里证实的是提交/提示顺序较晚，不是制作被任务锁住，也不能据此认定首次拿到即废弃。
2. **布衣成本会带入竹甲，单NPC初始丝绸报价不够走完胸甲递进。** 3线→1生丝、3生丝→1丝绸；布衣胸甲8丝绸=72线，全套24丝绸=216线。竹甲胸甲还要原布衣胸甲+2竹子+1丝绸，合计81线。百宝金丝绸基础价12铜钱、初始8次交易：96基础铜钱只够布衣胸甲，继续竹甲还少第9匹。该NPC类未见补货逻辑，不能假设睡觉补货；可从其他NPC实例、既有宝箱、九尾狐或线合成补足，因此不是永久不可得。实际需求/折扣可能改变付款，基础报价不是本轮交易实付。
3. **旧兵器架与废兵工坊的任务解锁时间不是物理获取时间。** 对应任务 `1000000000c40026`、`1000000000c40024` 前置较晚；交互实现不查FTB前置。兵器架配置600tick后给75%损伤铁剑，兵工坊3600tick后给机括。三种现有旅途结构样式实际放置全部15种互动；随机放置、排除区和实际遭遇时间未测。不能单凭任务链断言铁剑/机括必然晚到。
4. **凤凰羽/麒麟角有实际维度群系来源，但入口成本不能省略。** 凤凰在天朝海等维度群系、麒麟在玉林等群系有刷怪条目；对应维度生成器引用这些群系。玉门注册指向天朝，配方8玉块+1龙晶→2玉门；8玉块相当于72玉。主世界另有玉矿和龙晶矿配置，不能仅因门需要龙晶就推导循环。此处只确认配置链，不证明自然刷出、到达耗时或战斗可负担。
5. **中终盘必须计入真实前驱分支。** 官银剑 `sword_silver` 消耗玉笛+3银锭+图纸；玉剑继续消耗官银剑+3玉+图纸；玉甲胸甲消耗将军甲。玄天胸甲消耗龙鳞胸甲及玄天玉/龙晶/帝骨/帝印；鸿蒙胸甲同时消耗龙皇胸甲与混元胸甲，再加帝骨/帝印。守御最终ID是 `xuanwu_blade`。不得跳过旧件及并行分支只算末级材料；本轮没有添加附魔或ForeignData继承契约。

每项完整任务链、原配方、生产源码行号/哈希及结论边界见 [findings.json](findings.json)。以上是成本/顺序事实及风险，不是5个已确认需改正式行为的缺陷。

## 循环和来源复核

6组配方关联循环是钱币互换、青铜块/锭、玉块/玉、酒的升级自引用、符纸自引用、骨粉自引用。**关联图有环不等于每条配方都强制走环**：青铜合金、玉矿/冶炼、纸+朱砂直接制符纸、原酒基础配方、原版骨→骨粉及现有回收/掉落都能提供循环外候选。钱币也有实际掉落/交易/任务奖励入口；必须支付材料及满足NPC条件，不作为无成本起点。标签可能包含产物，单纯展开所有标签会制造伪自环。本轮只读相关配方，没有复测食品。

初轮21个来源漏项逐项处理：铜锈钱、碑拓、赑屃壳、铜铆钉、发簪、轿帘、白绢、巨猿板、机关图、将军残刀/盔/誓、画朱砂、寒铁、狻猊机芯、陶魇鼎耳、防水墨绢、龙吟刀、湛卢，以及凤凰羽/麒麟角。对应真实提供者是结构遭遇实体、沉沙补给箱、事件成功奖励、纪念台和原生试炼领取，不拿注册/描述文字充当获取源。

事件寒铁的 `dependencies` 在实现中检查注册项存在，不要求先拥有寒铁；不能误报“奖励要求先拿奖励”的自锁。陶魇需要3根原版骨祭献；太清试炼要求3项有序行为在1800tick内并满足伤害取消等条件；龙吟领取要求实际庭院胜利及玩家资格。这些均保留为真实条件，不当免费根节点。细节和全部44项原始掉落定义见来源复核JSON。原始 `nonrecipe-material-sources.json`/summary中的候选列表保留解析阶段历史，最终处理状态以 `nonrecipe-provider-review.json` 和summary.provider_review为准。
