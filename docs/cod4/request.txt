## 1.0 定位与通用标准

- 定位比 cod1 核心怪**更轻**：世界密度、小规模战斗、材料来源、环境特色。**不推翻 cod2 生态**，只提供 Spawn Hook。
- spawn 只提供 Hook（biome/时间/天气/结构 tag），不重写 cod2 生态。
- 通用骨骼：人形用分段真实骨架（pelvis/waist/chest/neck/head/upper_arm/elbow/forearm/wrist/hand/thigh/knee/shin/ankle/foot）；兽形用「头/颈/躯/尾/四足」5 段；飞行用「头/身/双翼/尾」；水生用「头/身/鳍/尾」。
- 通用 AI 状态机：`idle / wander / hunt / flee / attack / special / evade`；无寻路负担（次级怪）时用低阶 Goal，不堆复杂战术。
- 通用性能：次级怪面数 ≤ 基础怪，同屏 ≤ 20 只不卡；掉率低、掉落轻；无 Boss 条。
- 通用 multiplayer：次级怪为常规敌对/中立，无共享 Credit 问题；掉落由击杀者拾取，不重复。

## 7.3 原则重申

- 任务 = 内容解锁 + 引导层，**不是单纯发奖按钮**。
- 成长逻辑：任务出现在什么阶段 → 玩家当时有什么装备 → 奖励解决什么 Build 需求 → 多久被替代 → 被替代后有无继续用途（升级/锻造/系列联动/特定场景优势）。
- 找不到对应现有任务时：写 `NO_CURRENT_TASK_LINK`，并建议在哪个现有任务分支加一个 Stage/Objective，**不因此新建一条主线**（见 COD4-15 大表）。
