## ① 饰品格式：从 v1 八格 → v2 十一格

| | v1（前几批） | v2（本轮起） |
| --- | --- | --- |
| 一行 | `{id, 属性1, 值1, 属性2, 值2, 效果, 等级, 条件}` | `{id, 属性1, 值1, 属性2, 值2, 效果, 等级, 条件, 属性3, 值3, 条件3}` |
| 条件 | 整行**只有一个**（两格属性共用） | 前两格共用第 8 格，**第三格有自己的条件** |
| 能写什么 | 单一状态加成 | 「白天 +22% 攻击、夜里 +10% 移速」这种两面设计 |
| 效果 | 原版 buff（夜视 / 抗性 / 再生…） | **模组自有效果** 21~27（龙威 / 铁壁 / 疾风 / 威慑 / 天命 / 忠诚 / **内伤**） |
| 代价 | 基本写不了 | 属性 **9 = 生命上限 %**（用负值）+ 模组「内伤」当常驻代价 |

* 改动文件：`src/main/java/com/dynasty/DynastyTrinkets.java`
  * `applyExtra`：读第三格（`row.length > 10`，按列数判断 → 老 8 格行照旧生效）；
  * `applySpecAttr(player, id, slot, code, value)`：新增 `slot`，三格用三段 UUID（0~99 / 100~199 / 200~299），
    修掉「同一属性写两次会互相覆盖」的隐患；新增属性编码 **9 = 生命上限 %**；
  * `conditionMet`：新增 **6 = 满血**、**7 = 雷雨**；
  * `applySpecEffect` + 新增 `modEffect()`：21~27 走 `DynastyEffects` 的模组效果，1~12 旧编码保留；
  * `clearAttrs`：三段一起清，卸下不留幽灵加成；
  * 老的 4 参 `addAttr` / `multiplyAttr` 保留成**兼容重载** → 旧饰品 UUID 逐字节不变、代码不用改。
* **顺带补上悬浮说明**：饰品原来**完全没有 tooltip**（前几批都没做），玩家在背包里看不出效果。
  现在表驱动饰品是 `CharmItem`，悬浮直接显示 `§7[白天] §f攻击 +22% §8· §f移速 +10%`、
  `§7效果：§d龙威 I`；`attrText` / `effectName` 两张中文表要跟着编码表一起扩。

## ⑤ 需要你进游戏确认的点

1. **昼夜切换**：戴「破晓刃坠」白天攻击 +22%，等到夜里变成移速 +10%（切换应有 1 秒内生效）。

5. **任务书**：打开「十二、饰品图鉴」确认 118 条排成一整块、节点之间都点得开、不重叠。
