# 沉沙玄宫：100个独立建筑参考


日期：2026-10-18。范围：墓葬、陵寝、金字塔、地下城和地下祭祀空间。已阅读原作者项目说明并查看原页静态建筑图；未播放视频，未下载地图或复制模型。每个独立项目计一次，不按图片数计数。非秦汉建筑仅参考空间、承重、路线与层次，不直接搬用异文化立面。


本目录 `references.json` 保存原页与图片地址、当时的观察笔记。以下是逐项目取舍；这100项仅用于沉沙玄宫，不冒充另外九座建筑各自的100项参考。
