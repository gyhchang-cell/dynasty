# Dynasty — a Chinese history and mythology RPG modpack

Dynasty is a Minecraft 1.20.1 Forge modpack built around the original Dynasty mod. Its world is inspired by ancient China and Chinese mythology, with themed equipment, characters, creatures, bosses, structures and progression. It combines exploration and combat with crafting, currency, imperial ranks and the examination system. The Chinese introduction below provides further details about the project's themes.

## Important: manual setup required on Modrinth

**This Modrinth edition is not a complete one-click installation. Install the five dependencies below BEFORE opening a world.** The Dynasty mod and its quest configuration are included, but the full quest book, team progression and quest rewards need FTB Quests, FTB Library and FTB Teams. FTB Ultimine provides the original pack's vein-mining functionality. Item Filters is also part of the original quest setup.

FTB binaries are not redistributed here. Download these exact Forge 1.20.1 files from their authors' pages and place them in the installed instance's `mods` folder:

- FTB Library **2001.2.13**: https://www.curseforge.com/minecraft/mc-mods/ftb-library-forge/files
- FTB Teams **2001.3.2**: https://www.curseforge.com/minecraft/mc-mods/ftb-teams-forge/files/7499810
- FTB Quests **2001.4.22**: https://www.curseforge.com/minecraft/mc-mods/ftb-quests-forge/files/8078538
- FTB Ultimine **2001.1.8**: https://www.curseforge.com/minecraft/mc-mods/ftb-ultimine-forge/files/7880472
- Item Filters **2001.1.0-build.59**: https://www.curseforge.com/minecraft/mc-mods/item-filters/files/4838266

Do not use Fabric, NeoForge or Minecraft 1.21 files. The included `DYNASTY-INSTALL-FIRST.txt` lists exact filenames and hashes. Back up existing worlds, and do not open an existing quest world until all dependencies are installed. In multiplayer, install the same required dependency versions on both clients and the server. Keep the included quest configuration.

If you want automatic installation of the complete original dependencies, use the author's CurseForge edition instead.

## What to expect

- **Equipment and crafting:** ancient-Chinese and mythological weapons, armour, accessories, crafting materials and alchemy.
- **Progression:** imperial ranks and examinations, with themed quest chapters once the required FTB dependencies have been installed.
- **Exploration and combat:** custom structures, mythological creatures, military characters and boss encounters.
- **Supporting tools:** recipe lookup, navigation, inventory conveniences and performance mods alongside Dynasty's own content.

Version **1.4.0 is a beta/development release**. The project is still being improved; features and balance may change. Requirements: **Minecraft 1.20.1, Forge 47.4.10 and Java 17**. This pack does not work on vanilla clients or vanilla servers.

Dynasty's original content belongs to the Dynasty project. Included third-party mods retain their own licences and credits; AllTheLeaks is included with its MIT licence notice. No FTB mod binaries are bundled in this Modrinth upload.
