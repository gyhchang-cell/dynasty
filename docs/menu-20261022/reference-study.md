# 大型整合包来源研究（100 个）

研究对象为作者说明与真实发布包的 modrinth.index.json。每个候选至少有 100 个 mods/*.jar 引用；不是只用项目名凑数。按项目 ID 去重，并排除 Better MC/Medieval MC 的加载器变体以及 Prominence 汉化重复版。下载量是筛选信号，不证明质量。本记录不宣称逐一启动 100 个包，也不宣称看过 100 个菜单截图。

本轮界面原则：保留现有王朝主视觉；青玉底、古铜主操作与纸色文字贯穿创建页面；较小圆角与边缘覆盖；原生输入、标签切换、游戏模式及创建逻辑不替换；仅移除基础通用教学，保留技能与数据。
