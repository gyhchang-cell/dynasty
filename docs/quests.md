# 王朝任务系统（遊历指南 / Quest System）

《王朝》内置一套类似 FTB Quests 的任务系统，玩家无需任何指令即可上手，按章节顺序体验全部内容。

## 入口（两种，都不用指令）

1. **背包左上角按钮**：打开背包（E）后，左上角会出现「✦ 王朝任务」按钮，点击即可打开任务界面。
2. **王朝手札**：合成一本《王朝手札》，右键打开同一界面。
   - 合成：书 ×1 + 丝绸 ×1 + 竹简 ×1（竹简 = 甘蔗/竹子 ×2 + 线 ×1，丝绸 = 生丝 ×3，生丝 = 线 ×3）

## 界面说明

- 左栏：六个章节；中栏：该章节的任务（`✔` 已完成、`✦` 可领奖、`·` 进行中，后面是进度）；
- 右栏：任务描述、目标进度、前置任务、奖励图标；满足条件时出现「领取奖励」按钮；
- 底部显示总进度 `已领取 / 总任务数`。

## 章节与推进顺序

| 章节 | 任务 | 说明 |
| --- | --- | --- |
| 一、初入王朝 | 玉石在手 → 第一桶金 → 熔铸青铜 → 铸剑为凭 → 造纸制符 | 采集与基础合成 |
| 二、朝堂之路 | 科举中第 → 官阶初授 → 拜见大臣 → 玉玺在手 | 用**科举试卷**答题（界面答题，不在聊天框）；拜见大臣 NPC |
| 三、军旅生涯 | 虎符调兵 → 龙鳞披甲 → 讨伐叛军 → 安抚民心 | 用**虎符**调兵（右键打开阵型界面） |
| 四、天朝·龙庭 | 踏入天朝 → 龙晶之美 → 龙晶神兵 → 营造宫室 | 穿过玉门进入天朝维度 |
| 五、地府幽冥 | 下探地府 → 幽冥斩妖 → 帝陵取宝 | 穿过冥门进入地府 |
| 六、神兽与帝王 | 祥瑞麒麟 → 凤羽在手 → 龙帝陨落 → 天下共主 | 结交麒麟、击败龙帝、晋升大学士 |

任务进度保存在玩家数据中（`dq_p_*` 进度 / `dq_c_*` 已领取 / `dq_e_*` 事件标记），退出重进不会丢失。

## 无指令化的系统入口

| 系统 | 物品入口 | 操作 |
| --- | --- | --- |
| 任务 | 王朝手札 / 背包左上角按钮 | 右键 / 点击 |
| 科举答题 | 科举试卷 | 右键 → 界面中选择 1/2/3 |
| 军阵列阵 | 虎符 | 右键 → 选阵型与人数（潜行右键 = 威慑） |
| 王朝档案（官阶/功名/忠诚/叛乱） | 玉玺 | 右键（潜行右键 = 赐福） |
| 图鉴 | 王朝图鉴 | 右键 |
| 节日 | 节令灯 | 右键开启当令节日 |

`/dynasty` 指令仍然保留，仅供管理员调试使用，正常游玩完全不需要它。
