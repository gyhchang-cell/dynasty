100个不同模组项目的界面资料核对

资料类型：作者发布的项目说明、界面操作说明及其引用的图库链接。
另有9个官方仓库的100个界面源码实现，见 manifest.json。
没有把源码文件数当作模组数；也没有声称逐张看完100张界面截图。

本轮采用的原则
1. 采用原版容器的灰底、明暗边框、物品格和短标签。避免大面积绿色装饰。
2. 主要操作放在界面中直接可见的位置。虎符维持一套军阵，点兵员后直接点阵位。
3. 搜索按显示名与别名过滤，核验有匹配和无匹配两种情况；不是只确认物品存在。
4. 短属性和来源优先；次要来源按Shift展开，药水用原版“当生效后”属性区。
5. 分页/功能标签只用于不同职责，不增加用户已拒绝的保存/载入和预设。

下列100项均为不同项目ID；包含独立界面、容器扩展与终端附属模组。
