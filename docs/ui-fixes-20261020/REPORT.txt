本轮修改
1. 血量显示
   使用愚者实例同版本 ArmorPoints++ 3.1.1 和对应配置，移除冲突的旧血量渲染。
   五种实际客户端/服务端状态验证：16/20、16/16、27/36、160/240且吸收24、恢复16/20。
   实际上限为16时显示8颗心；高血量分层着色，并显示真实当前值和上限。
   保留盔甲、护甲韧性和吸收值的对应显示。
2. 物品名称与搜索
   结构罗盘统一中文名；英文为 Structure Compass，兼容旧英文 Explorer's Compass。
   增加中英文、拼音、分词、首字母和注册名搜索别名，覆盖4111个翻译键。
   创造搜索逐字输入：结构罗盘/Jiegouluopan/Structure Compass 各只得到1个正确物品；
   不存在的检索词得到0个结果。JEI的4种名称查询也通过。
   检查全包2255个物品名称可解析；816件王朝注册物品没有重复显示名。
   区分观星盘方块与星盘饰品；补齐新增结构的罗盘名称翻译。
3. 任务文字和配图
   1259个任务执行统一清理：删除背包持有说明、重复配方、重复来源和多余内部解释。
   操作橙色、目标黄色、材料绿色、风险红色，时间/距离等用蓝色。
   26张说明图换为游戏内真实字体、物品模型与灰色方格，配方与摆放步骤更直接。
   对比修改前完整任务：ID、目标、数量、依赖、奖励、任务类型、位置和布局字段均相同。
4. 虎符
   改成原版灰色边框、按钮和列表，保留一套可自由指定阵位的军阵。
   去掉预设阵型、保存与载入控制；兵册、招募、编队、出阵、收阵、转向及关卡仍可用。
   实测招募3种兵员，点击真实界面按钮，把第一名士兵放入第3阵位，服务端确认生效。
5. 饰品简介
   精简重复名称与用法；90件物品的宝箱来源从实际战利品表递归生成。
   普通展示前三处来源，来源更多时按Shift展开；没有宝箱来源的物品不编造出处。
   修正若干介绍与逻辑不一致之处：金印冷却60秒、玉蝉低血条件、战鼓3秒间隔等。
6. 药水
   去掉“王朝药水”和把所有药水效果混写一段的说明。
   每种药水只在“当生效后”逐行展示自身属性，使用原版蓝色属性行。
   铁壁示例：+20护甲值、-30%承受伤害；没有无关的攻击/生命数值。
7. 模型与资源
   修复方块模型引用的实体纹理未加入图集导致的紫黑缺图。
   修正磨制玄武岩贴图路径，并修补后续美术生成工具，避免再次清空图集补丁。
   816件王朝物品实际烘焙检查：缺失模型0。
