# 饰品与任务重制 · 2026-09-18

## 玩家会看到的变化

删除「王朝饰品」专属槽。119 件饰品各有一个分类：头部、项链、戒指、手镯、手部、身体、背部、腰带、护符。
每类开局 1 格，戒指 2 格；另有 1 个 Curios「万能饰品」槽，能接纳带 Curios 标签的其他模组饰品和全部王朝饰品，仍尊重对方物品自己的装备限制。

安装 Curios 时只计算已佩戴的饰品，背包与副手不生效，同名物品仍然去重。未安装 Curios 时，独立本体保留背包兼容。

奖励按玩家保存，不会因为重复领取、重置任务或更换队伍反复叠加。死亡与退出重进保留，旧存档已完成任务以及队伍进度每 5 秒补查一次。未装 FTB 时跳过补查，不影响本体加载。

## 任务展示

12 章 438 条任务、846 条前置关系保留。所有原任务 ID、目标和顺序不变，避免旧进度串位。
目标、制作路线、行前提示、佩戴位置、奖励分段，使用金、青、紫三种强调色。
加槽节点使用金色标题、六边形和清晰的奖励副标题；普通节点与支线入口缩小，降低拥挤感。
保留各章的横排、竖排、放射形状，但在生成器中避让过近节点，自检新增最小间距门槛，防止图标互相盖住。

参考依据：本机《愚者 0.2.2》任务配置中的分组、主次节点、分段说明；[《落幕曲》作者发布页](https://bbsmc.net/modpack/luomuqu)的伪线性任务与完整引导定位。没有搬用其任务文本或美术资源。

## 实现与生成

- `tools/art/gen_curios.py`：119 件饰品分类、标准槽定义、万能槽定义和玩家槽配置。
- `tools/art/gen_ftbquests.py`：任务文案、节点、奖励；同时生成 `data/dynasty/curios_progression.json`，供 Java 查找任务。
- `DynastySlotProgression`：个人永久解锁、死亡复制、FTB 反射补发；管理命令 `/dynasty unlock_curio <milestone>` 需要 2 级权限，FTB 临时提权执行。
- `DynastyCuriosBridge`：仅修改本模组固定 UUID 的永久槽位修饰符，不清空其他模组的加槽奖励。
- `verify_gear.py` 已接入 `verify_curios.py`，原导出流程的装备自检也会检查分类与里程碑。

不要把所有饰品加到 `curios:curio` 物品标签：Curios 5.14.1 的标签谓词会让这些物品进入任意分类槽。
万能槽通过独立的 `dynasty:accessory` 校验器接纳饰品，分类槽仍使用自己的标签。
