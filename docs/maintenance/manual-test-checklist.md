# 游戏内人工测试清单（manual-test-checklist）

> **状态说明**：本轮**没有启动游戏**，所以下面每一项的复选框都是**空的**，状态统一标「未实测」。
> 预期结果全部来自当前代码/配置（括号里给了依据），不是我实测出来的结论。
> 版本：整合包 `modpack/`（FTB Quests + Curios + 王朝 1.4.0 本体）；单人测试建议开创造另存一份。
> 勾选规则：**只有实际跑过并符合预期才勾**；不符合预期就把现象写进 `bug-report-template.md`。

## A. 新手任务（主线第 1 章）

- [ ] **T01 · 任务书能正常打开并落在主线**
  操作：进游戏后按任务书默认按键（默认 `E` 旁边的 FTB 键，或背包左侧的书图标）打开，展开左侧「主线旅程」。
  预期：左侧出现主线章节树，第 1 章的第一个节点是未完成状态，右侧有「为什么做 / 现在怎么做 / 完成后去哪」三段。
  状态：未实测

- [ ] **T02 · 木矛节点**
  操作：用「木棍×2 + 橡木木板×1」（无序合成，`recipes/mu_mao.json`）做出**木矛** `dynasty:mu_mao`。
  预期：任务节点检测到物品并自动完成；物品悬浮说明里的攻击力是 **5**（1+0+4，见 `weapons.md`）。
  状态：未实测

- [ ] **T03 · 基础生产节点（工作台 / 箱子 / 火把 / 熔炉）**
  操作：按第 1 章各节点「现在怎么做」依次做出四个基础方块。
  预期：每做完一个，对应节点自动打勾；没有节点要求提交物品（只检测背包）。
  状态：未实测

- [ ] **T04 · 拿到《王朝图鉴》**
  操作：按主线提示拿到 `dynasty:dynasty_guide`（任务奖励；管理员也可用 `/dynasty guide`）。
  预期：物品拿在手上**右键**打开「王朝图鉴」界面（标题 `screen.dynasty.guide`），可翻页/滚动，按 `Esc` 关闭。
  状态：未实测

- [ ] **T05 · 「读这一页」类节点**
  操作：点开一个只要求阅读的节点（描述里写「阅读无奖励，不阻塞主线」的那种）。
  预期：打开后即完成，不消耗任何物品；图鉴 / Boss 攻略页都是这一类。
  状态：未实测

- [ ] **T06 · 章节衔接**
  操作：清完第 1 章全部节点。
  预期：下一章（第 2 章）解锁，节点顺序与编号（`01 ·`、`02 ·`…）一致，不会出现「跳号但点不动」的节点。
  状态：未实测
