# 问题反馈模板（bug-report-template）

> 复制下面整块内容，填完贴到 GitHub Issue / QQ 群 / Discord / 评论都行。
> **复现步骤越具体，修得越快**。只要能让别人按你的步骤重现，就是好反馈。

```text
=== 王朝 Dynasty 问题反馈 ===

【版本】
* 整合包版本：（例：Dynasty 1.4.0 / 自己组的包）
* 王朝本体版本：（例：1.4.0，可在 mods 文件夹里看 dynasty-1.4.0.jar）
* Minecraft 版本：（例：1.20.1）
* 加载器与版本：（Forge 47.x / NeoForge xx）
* 安装了哪些关键附属模组：（Curios / FTB Quests / JEI 等，写版本号）

【运行环境】
* 单人或多人：单人 / 多人（多人请写：你是房主还是连别人）
* 如果多人：服务端是专用服务器还是局域网联机：
* 是否使用光影：（是 / 否；如果开了，请写光影包名字；请再关掉光影试一次并说明结果）
* 是否装了性能模组（Sodium / Embeddium / OptiFine 等）：
* 客户端内存分配：（例：4G）
* 操作系统：（Windows 11 / macOS 15 / Ubuntu 24.04）

【问题描述】
* 一句话概括：
* 影响程度：进不去游戏 / 崩溃 / 任务卡住 / 数值不对 / 只是观感问题

【复现步骤】（最重要，请编号）
1.
2.
3.
（写清：在哪个维度、用哪件物品、右键还是左键、有没有开创造、是否必须先完成某任务）

【预期结果】
* 我以为会发生：

【实际结果】
* 实际发生的是：

【发生频率】
* 每次都能重现 / 偶发（大约几次一次）/ 只出现过一次
【能不能自己恢复】
* 重进游戏就好了 / 重进也没用 / 换个存档就正常

【截图或短视频】
* 拖进 Issue 即可（推荐：物品悬浮说明、任务节点、Boss 血条、崩坏地形各来一张）

【日志】← 提交前务必先处理隐私，见下面「隐私提醒」
* 崩溃报告 crash-report：`crash-reports/crash-<时间>-client.txt`（整合包目录下）
* 最新日志：`.minecraft/logs/latest.log`
* 如果崩溃发生在服务端：服务端目录的 `logs/latest.log` 与 `crash-reports/`
* 出问题的那一段（贴前后各 30 行即可，不用贴整个文件）：

【其它线索】
* 上一个动作是不是「升级装备 / 换维度 / 完成任务奖励 / 戴脱饰品」：
* 存档玩多久了（新档还是老档）：
* 用 `/dynasty stats` 输出的内容（可选）：

=== 隐私提醒（提交前请务必做） ===
1. 日志里会带**本机绝对路径与用户名**（例：C:\Users\你的名字\... 或 /Users/你的名字/...），
   请用编辑器全部替换成 `<用户目录>`。
2. 多人日志可能带**服务器 IP / 域名 / 端口**，请替换成 `<服务器地址>`。
3. 不要贴：正版账号邮箱 / 登录令牌 / accessToken / refreshToken / 会话 ID / 支付信息。
4. **不需要**提供完整存档或整个世界文件夹；除非维护者明确要求，并且你能接受存档被他人看到。
5. 截图前注意关掉含聊天记录的窗口、服务器地址、以及别人不愿公开的 ID。

=== 提交渠道 ===
* GitHub Issue（附本模板）
* 或先在此次提交的评论区贴「版本 + 一句话 + 截图」，维护者会追问细节
```

## 填写小抄（常见「没法复现」的写法）

| 不好 | 应该改成 |
| --- | --- |
| 「Boss 打不到」 | 「在**天朝**用**龙帝玉玺**右键**法阵·祭坛**，周围 8 格摆了 6 块玉石块，右键后没有出现 Boss，也没有提示，重复 3 次都一样」 |
| 「任务卡住了」 | 「主线第 3 章『剿灭 叛将 ×1』节点，我已经杀了 2 只叛将，节点还是没打勾，背包里有叛将首级。重启游戏仍不打勾」 |
| 「饰品没用」 | 「把**深渊珠**放进**万能饰品**槽后，属性面板的攻击力没有变化；放进项链槽就正常。Curios 版本 xx」 |
| 「游戏崩了」 | 「进入**东海龙宫**后 10 秒内崩溃，附 `crash-reports/` 文件与前 30 行日志；去掉光影后仍然崩」 |

## 维护者可能需要你补充的信息

* `mods` 文件夹的完整列表（可以只贴文件名，不要贴网盘链接）。
* 是否**只在这个存档**能复现（新开一个创造存档试一次是最好的对照）。
* 出问题前**最后一次改动**：换了模组版本？改了配置？加了数据包？
