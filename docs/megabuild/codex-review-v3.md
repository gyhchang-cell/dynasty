# 巨型建筑 v8

修复超平坦地形被自然生成高度守卫拒绝的问题。新增管理员命令：

    /dynasty_build tiangong_citadel
    /dynasty_build tiangong_citadel confirm

站在西北角，向东、向南覆盖 176×176×56 方块区域，包括清空房间。先备份存档、选择空地。每 tick 搭建一个区块，自动加载当前区块，不需要提高视距，不永久强制加载。完成前不要退出；意外停止会留下已经搭建的部分。采矿庄园使用 tiangong_mining_estate（96×96×36）。

天工山城改为切角台地、错位楼群、三类屋顶和不同层数，补水院桥梁、树庭、铁砧/酿造/熔炉/工作台摊位。旧 v2 结构起点继续使用旧蓝图，避免未生成区块与原有建筑错接。

验证包含完整山城在独立测试世界的逐区块放置，以及入口、宝箱方块实体、工坊校验。预览图是代码蓝图投影，不是游戏实拍。更新包不含存档；没有覆盖玩家修改的建筑。
