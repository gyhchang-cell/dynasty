# 天工山城 v9：保留玩家修改后的修缮

## 玩家作品与安全边界

读取的是 Dynasty 王朝唯一存档“新的世界”，主世界超平坦。建筑原点 (-80,-60,-96)，176×56×176，旋转 180 度。已将保存到磁盘的完整存档备份到 `build/player-city-20260926/original-save`，附逐文件 SHA-256 清单。本轮未直接写入原存档。

从玩家改动提取 807350 个光明方块、42 个楼梯修正及 6 个地板方块。其余诸如树叶距离、铜氧化、Lootr 容器转换不冒充玩家建筑设计。

新版保留 753694 个光明方块；39083 个位置被新的实体建筑替代，14573 个位置仅在战斗室、局部楼梯与通道净空中清除。逐位置检查这三项之和恰为 807350，不按大半径清空整片照明。

## 建筑与探索

- 修复楼梯再次被 StructurePiece 镜像而反向的根因，真实世界放置验证四种旋转。
- 屋顶降低坡度并补齐山墙、天花、梁架，解决敞口和悬空拼接。
- 加入八角主亭、环形二层、花园弯廊、柱列与不同用途的楼层；144201 个非光明实体方块。
- 18 间封顶隔光战斗室，曲折入口、遮光玻璃；僵尸与骷髅各类刷怪笼，范围 2、每批 2、附近上限 4，避免同时大量刷新。
- 新材料箱、宝库箱使用独立原版池和王朝池，保证两类材料都有；原有已开箱内容不清空。

参考 Minecraft 官方文章 [A Peaceful Place](https://www.minecraft.net/en-us/article/peaceful-place) 中的布达拉宫创作，借鉴主次体量、错层轮廓与立面层次，不复制其建筑资源。当前预览为真实蓝图投影，不是游戏截图，也不代表已经达到参考作品的美术完成度。

## 光照与实测

不使用绕过光照的自定义刷怪规则。刷怪笼范围 2 对应 5×3×5 候选区域，不能只清掉笼子旁几格光明方块；隔墙、屋顶与曲折入口阻断外围光线，保留大厅照明。

GameTest 在真实服务器光照更新后检查全部 18 处候选区域，方块光和天空光均为 0；还实际执行刷怪笼逻辑并检测生成的僵尸和骷髅。需要非和平难度，且玩家进入激活范围。81 项必要测试通过，包括路径、四向楼梯、分块放置、宝箱双池、原地差异修缮与保留后来改动。

## 原存档怎么更新

1. 保存并完全退出游戏，备份存档，安装 v9 更新包。
2. 重新进入原来的“新的世界”，输入 `/dynasty_renovate` 查看原位置提示。
3. 输入 `/dynasty_renovate confirm` 分批修缮。只修改仍符合已备份基线的差异位置；不匹配的后来改动跳过，现有宝箱保留。完成后显示修改及跳过数量。
4. 查看建筑再继续手工改，改好后保存退出再交回。

不要对原作品运行 `/dynasty_build`：那是覆盖整片体积的新空地搭建命令。新世界自然生成采用新版；既有区域不会自动重建。
