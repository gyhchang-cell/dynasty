# 大型建筑接入补丁（Codex 合并；本轮按分工未直接改公共文件）

## 1) 注册两个 DeferredRegister
在 DynastyContent（或等价的 modEventBus 注册点）加两行：

    import com.dynasty.structure.megabuild.MegabuildStructures;
    MegabuildStructures.STRUCTURE_TYPES.register(modEventBus);
    MegabuildStructures.PIECE_TYPES.register(modEventBus);

## 2) 结构 / 结构集 JSON（已生成，无需手改）
    src/main/resources/data/dynasty/worldgen/structure/tiangong_citadel.json
    src/main/resources/data/dynasty/worldgen/structure/tiangong_mining_estate.json
    src/main/resources/data/dynasty/worldgen/structure_set/tiangong_citadel.json   （spacing 96 / separation 48）
    src/main/resources/data/dynasty/worldgen/structure_set/tiangong_mining_estate.json（spacing 64 / separation 32）

## 3) 语言增量（合并进 lang 或它的生成器字典）
    docs/megabuild/lang-additions.json
