## 你继续改建筑的方法

使用原来的创造建筑存档，先备份，找远离现有作品的空地。建议至少200×200空地放山城；至少110×110放庄园。以下命令会在指定位置放建筑，请不要朝着旧作品执行。

站在计划建筑的西北角地面，输入：

```mcfunction
/place template dynasty:tiangong_citadel ~ ~ ~
```

另一块空地输入：

```mcfunction
/place template dynasty:tiangong_mining_estate ~ ~ ~
```

这是搭建模板，不要求符合自然生成地形条件，适合超平坦工坊。模板只放建筑方块，不清理原地形，务必使用空地。放置巨大模板时可能短暂卡顿。两个模板都已经通过Minecraft模板管理器读取测试；没有在你的世界自动执行任何放置命令。

你改完后把人物留在建筑附近，保存退出，告诉我改好了即可。保留原放置点或截图更方便比对；也可以沿用WorldEdit导出schematic。后续我会读取存档差异再合并；这次没有写入或覆盖你的存档。

## 复现

1. `python3 tools/megabuild/gen_deliverables.py`：数据与语言。
2. `./gradlew -I tools/megabuild/qa.init.gradle runGameTestServer --offline`：几何、注册、分块裁剪、四朝向、NBT、模板读取测试；导出模板到build/megabuild-templates。
3. 把两份导出NBT复制到src/main/resources/data/dynasty/structures，再运行build。
4. `gen_ftbquests.py`、`test_quest_story.py`、`verify_ftbquests.py`。
5. `package_visual_release_v6.py --output dist/dynasty-megabuild-v7-update.zip` 打包；安装器只更新JAR和任务且备份，不动saves。
