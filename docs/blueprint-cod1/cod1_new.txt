# 第一项：剩余21种基础怪物设计

下面是**尚未启动的基础怪原设计**。按原设计做，不要把它们简化成换皮僵尸。


### 9. 披甲叛将护卫（重装防卫人形）
- **类型**：叛军重型步兵
- **出现区域**：叛将大帐、地下军械库、关隘顶层
- **外形与体型**：身高2.15米。极其厚重的宋式步人甲改制型，肩扛兽吞金护肩，胸前有圆形护心铜镜，双手持两柄开山短斧。
- **纯黑剪影特点**：极其倒三角且下盘极稳的厚重体块，双臂自然向外扩张，肩部兽头尖锐朝上。
- **武器**：双手精钢开山阔刃斧。
- **移动方式**：步步为营的侧向踏步，每次迈步均有甲胄摩擦声。
- **普通攻击**：双斧左右向内横向合夹，伤害极高。
- **特殊能力【霸体反击】**：正面承受3次攻击后，自身触发0.5秒霸体金光，随后不可打断地进行一次360度大风车双斧横扫。
- **死亡表现**：双斧脱手跌落插地，护卫身形后仰，单手捂住胸口护心镜，重重仰面倒下，震起周围一格灰尘。
- **掉落物**：开山斧刃、精炼熟铁锭、破损护心镜。
- **模型分件与骨骼**：肩部兽吞为独立多边形骨骼，胸前护心镜带法线反射贴图，双斧带攻击轨迹绑骨。

### 10. 阴兵鬼卒（无视物理灵体怪）
- **类型**：灵体/鬼怪
- **出现区域**：浓雾古战场、阴气深涧、乱葬坑
- **外形与体型**：身高1.8米。下半身为虚浮青烟，上身为残破半透明古代铠甲，头盔下方空无一物，仅有两团幽蓝色鬼火闪烁。
- **纯黑剪影特点**：完全没有双腿支撑，由一条逐渐变细并向后拖曳的烟雾带连接地面，长戈前指。
- **武器**：虚幻锈蚀战戈。
- **移动方式**：完全平滑的漂浮滑行，可无阻碍穿过其他非首领实体。
- **普通攻击**：戈尖虚刺穿透护甲，造成冰霜冷缩魔法伤害并降低玩家攻速。
- **特殊能力【幽冥遁入】**：被近战攻击命中时有35%几率瞬间虚化并闪现至玩家身侧3格处，虚化期间不可选中。
- **死亡表现**：铠甲失去灵力托举，“哗啦”一声全部散落堆叠在地面，鬼火消散升空。
- **掉落物**：聚阴寒玉屑、幽冥残缕、古币锈块。
- **模型分件与骨骼**：空心铠甲内无头颅骨骼，幽火为双点漂浮光晕骨骼，尾部烟雾为3段渐变弯曲骨链。

### 11. 尸变力士（膨胀型行尸怪）
- **类型**：鬼怪/行尸
- **出现区域**：潮湿古墓前室、悬棺崖壁下
- **外形与体型**：身高2.3米。肌肉极度肿胀发黑的古代搬山力士干尸，表皮紧绷发青，经脉爆起紫色发光液体，双手粗大如石滚。
- **纯黑剪影特点**：严重夸张的上肢体积极大，双臂垂直下垂接近地面，手掌宽度达到正常人的两倍半。
- **武器**：生铁缠手重拳。
- **移动方式**：沉重拖脚行走，发现目标后转为低姿态双臂撑地跳跃奔袭。
- **普通攻击**：双手合抱式地面巨力锤击，产生碎石小溅射。
- **特殊能力【腐尸剧毒】**：受击时体内紫色汁液四溅，在周围地面留下存在4秒的尸毒黏液斑，踩踏进入造成持续减速与中毒。
- **死亡表现**：腹部急剧膨胀至球状后破裂，喷出大团黑雾，身躯萎缩塌陷成干瘪死皮。
- **掉落物**：发黑的腐骨、凝固尸油、力士铅腕套。
- **模型分件与骨骼**：巨型手掌单独具备三段粗指骨骼，背部斜方肌巨大突起作为独立骨骼。

### 12. 缚魂白布童子（诅咒型妖灵）
- **类型**：鬼怪
- **出现区域**：荒村枯井、荒芜祠堂、夜间古墓
- **外形与体型**：身高1.2米。孩童比例，通体裹着发黄的陈旧裹尸白布，仅露出一只漆黑无瞳的大眼睛，头顶梳一个朝天小辫，怀抱一盏白色白骨引魂灯。
- **纯黑剪影特点**：娇小但头大，头顶一根细细的小辫突起，胸前悬浮一盏带长柄的骨灯，身周漂浮三块撕裂的布条。
- **武器**：引魂惨白骨灯。
- **移动方式**：倒退着漂浮移动，始终面向玩家微笑凝视。
- **普通攻击**：摇动引魂灯，发出一圈刺耳笑声波纹，造成直面视野受损（视线泛白）。
- **特殊能力【定身冤咒】**：在玩家背后蓄力2秒，若玩家未在时间内回头注视它，玩家将被白布缠足定身1.5秒并剥离10%当前耐力/饱食度。
- **死亡表现**：白布猛地散开随风飞散成碎片，骨灯掉落跌碎，空气中留下一声童音叹息。
- **掉落物**：白蜡灯泪、冤魂碎布片、惨白乳齿。
- **模型分件与骨骼**：白布飘带带有4根独立独立摆动骨节，悬空骨灯带有三维惯性旋转锚点。

### 13. 纸人剑客（轻盈诡异构装傀儡）
- **类型**：鬼怪/纸扎造物
- **出现区域**：荒废义庄、官宦墓道中庭、冥婚废宅
- **外形与体型**：身高1.85米。纯由涂色竹篾与白竹纸扎成，脸部为浓重腮红与诡异笔墨五官，手持一柄纸糊长剑，动作呈非连续抽搐感。
- **纯黑剪影特点**：极薄的平面感！正面看与人无异，侧面看只有3厘米厚度的刀片状轮廓，肩颈折角极为僵硬。
- **武器**：纸扎开锋细剑。
- **移动方式**：像被狂风吹拂般沿贴地Z字形极速飘行，伴随纸张哗啦摩擦脆响。
- **普通攻击**：快如残影的侧身纸剑横切，附带割裂流血效果。
- **特殊能力【纸蜕替身】**：承受致命伤时，身躯瞬间散落为普通无害的白纸人，真身在玩家正后方5格处伴随纸屑重聚现身。
- **死亡表现**：被击中后瞬间燃起纯白业火，0.5秒内化为灰烬，地面留下一滩黑墨。
- **掉落物**：极轻的韧竹篾、裁纸小刀、点朱丹砂。
- **模型分件与骨骼**：全模型采用极薄单层面片叠加；关节动作全部设计为零帧补间的机械瞬移卡顿姿势。

### 14. 墓穴飞颅（游荡空战死灵）
- **类型**：鬼怪/飞头
- **出现区域**：古墓盗洞、深层岩洞、陵墓顶部穹顶
- **外形与体型**：直径0.8米。一颗腐烂干枯的古代军士头颅，头戴倒扣带刺盔，断颈处倒悬垂下数条赤红发黑的肠脏与内脏管道，如水母触须般蠕动。
- **纯黑剪影特点**：上方圆球形带头盔犄角，下方多条不规则软质触手向下飘垂收拢。
- **武器**：外露尖锐獠牙、倒刺胃肠。
- **移动方式**：在空中3至5格高度像浮游生物般吸气喷吐沉浮飞行。
- **普通攻击**：向下俯冲咬合，随后快速拉升回高空。
- **特殊能力【污血淋漓】**：悬停在玩家头顶盘旋，自断颈处向下喷淋腐蚀黑血，在地面形成小范围毒血滩，破坏玩家护甲耐久。
- **死亡表现**：头盔爆裂，头骨直坠地面碎成骨粉，下方肠脏化作黑烟消弭。
- **掉落物**：尖锐死人牙、生锈盔顶刺、阴气囊。
- **模型分件与骨骼**：头颅下颚带咬合旋转骨骼，下方内脏触须各分配4段柔性物理骨骼。

### 16. 赤目朱蛤（两栖跳跃剧毒异兽）
- **类型**：异兽
- **出现区域**：沼泽水洼、阴暗溶洞潜水区、水畔芦苇荡
- **外形与体型**：体宽1.4米，高1.0米。通体暗红色的大型毒蟾蜍，背部密布如同煮沸熔岩般散发微弱火红荧光的毒腺脓包，双眼赤红突起。
- **纯黑剪影特点**：扁平下趴的巨大半球形，侧面隆起数个圆形鼓包，下颌气囊巨大膨胀。
- **武器**：带有倒刺肉钩的长舌、背部毒液。
- **移动方式**：静止不动等待，启动时进行跨越6格距离的高抛物线重压跳跃。
- **普通攻击**：长舌瞬间弹射出5格距离穿刺玩家并向后拉扯1格。
- **特殊能力【火毒喷射】**：受到重击后，背部脓包同时向四面八方喷射6枚灼热毒液弹，落地形成燃烧与剧毒双属性区域。
- **死亡表现**：四脚朝天翻倒，白色腹部剧烈抽搐几下，体表脓包全部瘪塌流出白浆。
- **掉落物**：火红朱蛤腺体、粗糙坚韧蛙皮、毒凝胶。
- **模型分件与骨骼**：下颌气囊具备缩放变形骨骼，长舌分为5段延伸骨骼，四足大腿肌群带厚重分块。

### 17. 枯木树精（伏击伪装植物怪）
- **类型**：妖物
- **出现区域**：阴沉古林、腐烂老树桩群、荒山野径
- **外形与体型**：高2.8米。外形与周围枯木树干无异，表皮呈裂开的黑灰树皮，腹腔内是空洞的树心，布满暗黄色的树胶粘丝与发光菌菇。
- **纯黑剪影特点**：完全是带有几个分叉枯枝的直立粗木桩，没有明确的脖颈与头部分离，手臂似折断的粗壮树桠。
- **武器**：硬化盘曲树根重槌。
- **移动方式**：伪装时完全静止；激活后由地底钻出数根粗大主根作为多足蹒跚挪动。
- **普通攻击**：粗大的树干手臂横向猛挥。
- **特殊能力【地刺根须】**：将根足刺入地面，在玩家脚底生成牢笼般的绞杀树根，禁锢玩家走位并造成持续窒息伤害。
- **死亡表现**：主躯干自中央裂成两半崩塌，树皮剥落破碎，化作三节普通朽木掉落地面。
- **掉落物**：千年老树心、坚硬枯木皮、荧光寄生菇。
- **模型分件与骨骼**：底部6根根须独立受力弯曲骨骼，胸前裂缝带有开合嘴状动作骨骼。

### 18. 鸣沙石蝎（多足穿沙构造异兽）
- **类型**：异兽/多足构造
- **出现区域**：戈壁荒滩、干涸河床、风化沙谷
- **外形与体型**：长2.2米，宽1.5米。体表覆盖着如同黄砂岩层叠堆积的厚重矿物硬壳，拥有6条多节步行足，双螯宽大如石磨，尾部倒钩为天然黄铜色石针。
- **纯黑剪影特点**：扁平贴地多足剪影，前方有两个巨大的半圆螯轮廓，后方高耸一段多节向前弯折的锐利蝎尾。
- **武器**：碾压石螯、淬毒金石尾刺。
- **移动方式**：潜沙穿行（仅露出尾尖石刺在地面拖行），出沙后多足极高频横向小步切移。
- **普通攻击**：左螯夹住目标限制其动作，右尾刺迅速下点。
- **特殊能力【金石鸣沙】**：尾端摩擦甲壳发出高频刺耳噪音，使半径5格内的玩家产生反胃与屏幕剧烈晃动，同时大幅降低玩家的挖掘与护盾举起速度。
- **死亡表现**：石化硬壳发出龟裂白光，随后整具身躯如石雕坍塌碎裂成一堆碎沙石。
- **掉落物**：鸣沙石硬壳片、金石尾刺针、精纯黄砂。
- **模型分件与骨骼**：左右各3条多节步足（共6条独立IK链），尾部由7个独立石块环扣骨骼组成。

### 19. 碧水玄蛟幼崽（中型水陆蛇形妖）
- **类型**：妖物/蛇形
- **出现区域**：地下暗河、高山深潭、瀑布水穹
- **外形与体型**：体长4.2米，体粗0.35米。无足，通体碧绿带黑色环纹，背部生有一排半透明骨质鳍叶，额头生有一个小巧的钝角鼓包。
- **纯黑剪影特点**：起伏蜿蜒的长条S形曲线，前三分之一身躯昂首直立，头部生有两道向后飘拂的肉须。
- **武器**：倒生锐利细齿、强韧蛇身绞杀。
- **移动方式**：水中极速波浪式滑行；陆地上以极快速度贴地游走，游走时有轻微水花粒子。
- **普通攻击**：弹射突咬，造成冰冻减速。
- **特殊能力【寒潭盘绞】**：若玩家处于水中或水边，突然前扑将玩家身躯紧紧缠绕，使玩家无法使用主副手物品并强行往深水区拖拽溺毙。
- **死亡表现**：蛇躯由头部至尾部逐节失去力量，仰面露出泛白肚皮，缓缓沉入水底或瘫软在陆地。
- **掉落物**：幼蛟细鳞、寒潭水精、滑腻蛟胆。
- **模型分件与骨骼**：全身由14节等距脊椎骨骼串联，背部游水鳍挂载柔性二级动画。

### 20. 巨臂石敢当（不对称畸形构装体）

### 基础怪物战术组合（Encounter Design）

#### 组合一：【官军铁壁箭雨阵】
- **成员配置**：1名 橹盾甲士 + 2名 连弩阵卒 + 1名 拒马长枪兵
- **AI协同行为**：
  - 橹盾甲士始终处在最前线，开启【钢铁壁垒】为身后的连弩阵卒遮挡玩家所有的射击和直线近战攻击。
  - 两名连弩阵卒以盾兵为中心向左右两侧错开半个身位，进行交替定点三连射，压制玩家走位。
  - 拒马长枪兵则游弋在盾甲士斜后方2格。一旦玩家试图使用疾跑、位移技能绕过巨盾强切后排弩手，拒马长枪兵立刻横向跨步上前使用【枪阵拒马】直接打断玩家冲刺并击晕，随后前排盾兵接盾击击飞，后排弩兵瞬间集火爆头。

#### 组合二：【乱军突袭自爆潮】
- **成员配置**：1名 符法祭酒 + 2名 铁索斥候 + 3名 溃军死士
- **AI协同行为**：
  - 符法祭酒在后方高台或掩体后引导【兵煞附体】，将强化血光加持在最前方的溃军死士身上，使其获得高额移速与免击退霸体。
  - 铁索斥候不直接攻击，而是从两侧极速绕后，向玩家投掷飞爪【锁镰飞掷】，强行打断玩家的撤退走位，将玩家往被强化的溃军死士怀里拖拽。
  - 溃军死士借由霸体顶着玩家攻击狂笑近身，一旦接近立即引爆【绝命爆裂】，形成致命的连环爆破网。

#### 组合三：【古墓诡变窒息锁】
- **成员配置**：1名 缚魂白布童子 + 1名 纸人剑客 + 1名 煞水浮溺鬼
- **AI协同行为**：
  - 煞水浮溺鬼首先潜伏在通道积水中，待玩家踏入时突然展开【溺水缚足】将玩家禁锢在原地且无法跳跃。
  - 缚魂白布童子立刻漂移到受困玩家的正后方开始蓄力【定身冤咒】。
  - 纸人剑客则凭借薄片身躯与极速折角走位从正面强攻，玩家若被迫正面招架纸人剑客的快攻，则无法回头注视身后的白布童子，从而触发童子的定身诅咒；若玩家强行转身看童子，则后背完全暴露给纸人剑客的高伤割裂斩。

# 工程实现要求：剩余21基础怪

## A. 共用底层

复用工程现有注册、攻击同步、生成、网络和GeckoLib系统。若已有 `AttackState / SkillDefinition / Faction / MobRole / VisualEvent` 等价实现，直接接入，不另起第二套。

每只怪必须真正完成：
`注册 → 属性 → 模型 → 贴图 → Idle/移动/Attack/Hurt/Death → 特殊技能 → AI → 生成 → 掉落 → 单机 → 双人联机 → 最新构建证据`

只有全部完成才允许 DONE。

人形继续使用分段骨骼；非人形必须按体型做真实骨架。服务器决定伤害和状态，客户端只表现。所有大批量视觉都用少量逻辑判定+客户端批量视觉。

## B. 剩余21只的世界落点与实现方式

### 9. 披甲叛将护卫
- 维度：`minecraft:overworld`
- 主地点：叛军大帐、地下军械库、关隘顶层。
- 生成：结构固定护卫/Encounter，不加入普通Biome自然刷新。
- 数量：同一据点1～2只；局部上限2。
- 实现：双斧攻击分左右合夹；正面承受3次攻击的计数必须有时间窗口，触发霸体反击后清零。360°横扫每目标每技能只命中规定次数。

- 组：2～5；局部上限按阴司/古战场单独配置。
- 实现：能穿过其他非Boss实体，但不要穿实心方块逃出结构；35%虚化必须有内部冷却；闪现只选合法站立点。

- 组：1～2。

# 第1～5项世界落点硬规则

1. 不新增维度。优先使用现有：
   - 主世界：绝大多数军队、山林、古墓、机关遗迹、河湖、雪山；
   - `dynasty:underworld`：阴司/忘川相关精英、Boss与结构；
   - `dynasty:jiuxiao`：雷泽巨灵、云顶/九霄内容；
   - `dynasty:dragon_palace`：明确龙宫/水府内容；
   - `dynasty:celestial_dynasty`：已有天界内容，只有设计明确匹配时使用；
   - `dynasty:zhenyuan_arena`：镇渊终局相关，不能随便塞普通怪。

2. 普通怪必须区分 NaturalEcologySpawn 与 Structure/EncounterSpawn。墓穴、机关、军队、纸人等不能为了省事全塞Biome自然刷新。

3. 15精英每只要写：
`dimension / primaryLocation / spawnMethod / respawnRule / maxAlive / bossDependency`

4. 12 Boss 默认不自然刷新，只能由结构BossTrigger、祭坛、任务或Arena启动；每个要写：
`dimension / arena / summonCondition / requiredProgress / firstKillReward / repeatKillReward / respawnPolicy / worldStateKey`

5. 混元祖兽：只做终局前置/隐藏Boss，不替换镇渊帝君。

6. 25神器必须有真实来源。对应第6项地下城尚未完成时，先注册Reward Hook，不得偷改普通工作台合成或随便塞怪物掉落。

7. 神影不自然生成。只由对应神器技能触发，默认允许所有该神器可用维度。

# 第二项：15种精英怪设计

### 1. 陷阵断头将（斩首死斗型重装精英）
- **基础与模型特征**：身高2.6米。一尊失去头颅的重铠大将，脖颈断口处被一道翻滚的青色凶煞符文封印覆盖，不断向外冒出怨气冷焰。左手倒提着一颗双目圆睁滴血的巨大头盔（头颅在头盔中嘶吼），右手拖曳一把比人还高的破阵重型双手大阔刀。
- **武器**：巨型双手破阵阔刀（长2.4米，刃宽0.4米）。
- **技能一【断头咆哮】**：
  - *攻击前摇*：提起左手中的头颅，头颅双目亮起刺目红光，发出持续1.2秒的刺耳吸气风声。
  - *释放动作*：将头颅向前猛推，嘴部喷出一道宽3格、长10格的锥形灰黑怨气音波。
  - *危险区域*：前方锥形区域。
  - *识别与规避*：看到头颅红光闪烁并听到吸气音时，立刻向左右两侧翻滚躲避，切勿尝试用盾牌格挡（音波直接穿透格挡破盾）。
- **技能二【破阵回旋旋风斩】**：
  - *攻击前摇*：躯干极度向右后方扭转蓄力，大阔刀在地面拖出剧烈火花，持续0.8秒。
  - *释放动作*：不可打断地进行连续三圈360度大范围低姿态挥砍，每次旋转位移向前推进2格。
  - *危险区域*：以自身为中心半径3.5格圆形区域，随其位移延伸。
  - *识别与规避*：地面火花伴随沉重金属拖地声，看到其腰部扭转即可起跳拉开距离，在第三圈旋转结束有长达1.5秒的大硬直。
- **技能三【掷首锁魂】**：
  - *攻击前摇*：停步，右手大刀驻地，单手高举头颅蓄力，头顶出现血色锁链标记。
  - *释放动作*：将手中头颅如流星锤般猛砸向玩家落脚点，落地后产生腐蚀血池，头颅再由黑气锁链收回。
  - *危险区域*：目标位置半径2格圆形。
  - *识别与规避*：玩家脚下会出现圆形血迹预警圈，预警持续1秒后砸落，保持横向跑动即可离开。
- **死亡表现**：手中的头颅终于闭上双眼发出一声长叹化为黑灰，高大的无头身躯伫立原地良久，手中大刀“咔嚓”一声寸寸断裂，身躯轰然跪地化作一具空铠甲。

### 2. 鬼车九首鸟（空中空袭型多头异兽精英）
- **基础与模型特征**：翼展5.0米，躯干形似长尾秃鹫。拥有9条细长蛇形脖颈，其中8个长着惨白的女人面孔鸟喙头颅，最中央的主脖颈则是一处不断滴落污血的断肉桩（传说中被天狗咬断的一首）。羽毛呈死寂的灰红色，飞行时滴落污血。
- **武器**：九嘴尖喙、腐蚀性血弹。
- **技能一【八首乱啄】**：
  - *攻击前摇*：双翼猛地后拍在空中悬停，8个头颈同时像拉满的弹弓向后收缩蓄力0.6秒。
  - *释放动作*：8个长颈如暴雨般交替向下方地面急速啄击，连续啄击16次，将地面石块啄得粉碎。
  - *危险区域*：下方半径2.5格。
  - *识别与规避*：在其悬停收颈的瞬间，离开其下方阴影范围，此技能释放期间它无法移动位置。
- **技能二【九婴啼血】**：
  - *攻击前摇*：所有头颅仰天发出刺耳如婴儿啼哭的尖叫，中央断颈处污血沸腾剧烈冒泡，持续1.0秒。
  - *释放动作*：向下方扇形空投下8枚剧毒血爆弹，落地后滞留剧毒血雾，踩踏者获得虚弱与凋零效果。
  - *危险区域*：正前方6格宽度的地毯式轰炸带。
  - *识别与规避*：听见刺耳婴儿尖叫声时，立刻向其侧后方穿插跑位。
- **技能三【低空掠食抓投】**：
  - *攻击前摇*：拔高身位至8格高空，收拢双翼斜向下俯冲对准玩家，发出破空锐啸。
  - *释放动作*：利爪贴地抓掠，若抓中玩家则将玩家拉至高空随后狠狠扔向地面岩石。
  - *危险区域*：直线路线上1.5格宽度的路径。
  - *识别与规避*：在其俯冲接近至3格的刹那按下格挡或侧滑，可令其俯冲失控撞击地面陷入2秒瘫痪。
- **死亡表现**：所有头颅互相撕咬悲鸣，庞大的身躯在空中失速盘旋坠落，重重摔在地上，羽毛散落一地并化为黑血蒸发。

### 3. 千机百炼偃师（远程机关召唤与操控精英）

  - *释放动作*：庞大沉重的身躯如炮弹般高高跃起，飞跃8格距离以泰山压顶之势砸向玩家，将地面砸出大坑。
  - *危险区域*：落点半径3格范围。
  - *识别与规避*：空中飞行时间约1秒，在其跃至最高点的瞬间向其落点反向冲刺，利用滞空差穿越其胯下。
- **技能三【怨血喷涌】**：
  - *攻击前摇*：双拳用力捶打自身腹部伤疤，伤疤缝合线崩断，持续0.8秒。
  - *释放动作*：从腹部裂口向前喷射出一道漆黑腥臭的尸血洪流，对正面所有目标造成高额击退与持续护甲腐蚀。
  - *危险区域*：正面直线锥形通道。
  - *识别与规避*：看到其自残捶腹动作，立刻侧向位移，其喷射期间无法调整朝向。
- **死亡表现**：腹部伤口彻底爆裂，黑血如喷泉般冲天而起，沉重的身躯重重前扑砸在地上，背后的残兵震飞散落一旁，化作焦臭黑泥。

### 11. 墨家绝影刺客（潜行暗杀与分身瞬移精英）
- **基础与模型特征**：身高1.75米。身着极其紧身的黑白两色玄水软甲，面蒙黑巾，周身缠绕着类似游墨般的微小黑色墨滴粒子。双手各持一柄反握的无光墨晶短匕首，几乎没有任何脚步声。
- **武器**：双持无反光纯黑墨晶匕首。
- **技能一【水墨遁形】**：
  - *攻击前摇*：原地身形瞬间化作一滩溅落的浓墨，彻底在玩家视野与仇恨中消失，潜伏潜行。
  - *释放动作*：潜伏持续最长4秒，随后突兀在玩家正背后1格处浮现，双手匕首直刺玩家后颈致命处（造成3倍背刺暴击）。
  - *危险区域*：玩家身后极近距离。
  - *识别与规避*：他潜行时地面会有微小的黑色墨点水滴印记移动，仔细观察地面墨迹；背刺瞬间有极其轻微的出鞘声，听到声音立刻反向起跳或转身格挡。
- **技能二【八方墨影斩】**：
  - *攻击前摇*：在玩家身周2格处插下四根墨竹标枪，形成封闭领域，蓄力0.5秒。
  - *释放动作*：身化四道墨色残影，在四根标枪之间以折线轨迹以极高频率穿梭穿透玩家四次。
  - *危险区域*：四根标枪围成的矩形区域内。
  - *识别与规避*：标枪出现瞬间使用范围横扫技能打断任意一根标枪即可破坏领域阵法。
- **技能三【墨滴爆裂】**：
  - *攻击前摇*：向后撤步翻滚拉开距离，单手向地面甩出三枚墨丸。
  - *释放动作*：墨丸在1秒后爆开成三团浓密墨云，使进入其中的玩家陷入“完全失明”5秒。
  - *危险区域*：三团黑色球形迷雾。
  - *识别与规避*：不要穿过墨云，绕行或使用吹息类技能吹散烟雾。
- **死亡表现**：身躯并未倒下，而是如同被清水冲刷的浓墨画卷般，迅速稀释融化，化作几道黑白墨纹在地面扩散并最终渗入地底。

### 12. 撼山铜甲巨猿（四足狂暴攀援精英）
- **基础与模型特征**：四足站立时高2.2米，双足直立时达3.4米。一头体型极其庞大的古铜色巨猿，脊背与头骨上被古代机关师用滚烫铜水浇筑了厚重的青铜甲板，双臂由于铜甲强化而极其硕大粗壮，眼眸呈现疯狂的熔金色。
- **武器**：青铜浇筑巨拳、断裂青铜桩柱。
- **技能一【铜臂狂乱大捶打】**：
  - *攻击前摇*：双足直立站起，双臂重重擂击自身胸口铜甲，发出刺耳的金属敲钟声，蓄力1.2秒。
  - *释放动作*：向前迈步，双臂巨拳以极快频率左右连续砸向地面，每砸一下砸碎一格地面，连续前进敲击8次。
  - *危险区域*：正前方宽2格、长8格的连续推进破坏带。
  - *识别与规避*：不可正面硬接，利用其转弯不便的缺点，向斜后方切角跑位拉开距离。
- **技能二【拔木穿石】**：
  - *攻击前摇*：单臂猛插入地面岩层或废墟，周围石块颤抖，持续0.9秒。
  - *释放动作*：硬生生从地底扣出一块直径达1.5米的巨型岩石，对准远处玩家双手暴力投掷而出。
  - *危险区域*：巨石飞行轨迹及落点碎裂溅射区。
  - *识别与规避*：巨石飞行速度适中，但落地会崩碎成三块小飞石，不仅要闪避巨石本体，还要跳跃躲避二次散落碎石。
- **技能三【飞跃震荡扑杀】**：
  - *攻击前摇*：四足极度屈膝蓄力，后背铜板缝隙中喷出灼热蒸汽，持续0.6秒。
  - *释放动作*：跨越整个战场跳跃扑击，落点产生大范围击退风暴。
  - *危险区域*：大范围圆形。
  - *识别与规避*：看准地面出现的巨猿落点红圈，在其落地前0.3秒向外翻滚闪避。
- **死亡表现**：胸口浇筑的铜甲由于过热而崩裂，巨猿仰天长啸一声，双足直立定格，随后如同一尊沉重的青铜雕像向前轰然栽倒。

### 13. 青灯判官鬼差（点名裁决与怨锁禁锢精英）
- **基础与模型特征**：身高2.2米。身穿深紫色破旧官袍，腰束官带，面部由一团旋转的漆黑迷雾构成，仅有一只苍白发光的巨大眼球在迷雾中央凝视。左手持一本燃烧阴火的生死簿铁册，右手提着一杆巨大的镔铁断头判官笔。
- **武器**：镔铁点穴判官笔、阴火生死簿。
- **技能一【生死勾名】**：
  - *攻击前摇*：翻开生死簿，判官笔在虚空中划出一个血红的“死”字，玩家头顶同时浮现血字倒计时，持续2.0秒。
  - *释放动作*：倒计时结束时，无论距离多远，一柄虚幻的巨型判官笔自天空笔直刺向玩家头颅。
  - *危险区域*：单体绝对锁定点。
  - *识别与规避*：头顶血字闪烁到第三次（伴随心跳音效）的瞬间进行极限闪避，即可让虚幻巨笔刺空插在地面；若贪刀不躲将受到极高纯粹灵魂伤害。
- **技能二【铁画银钩】**：
  - *攻击前摇*：单臂持笔向前突刺，笔尖绽放出漆黑的墨气枪花，持续0.5秒。
  - *释放动作*：连续向前刺出五道凌厉笔风，带出五道在空气中停留不散的黑色墨痕刀刃，触碰墨痕同样受创。
  - *危险区域*：正面直线多段突刺。
  - *识别与规避*：向侧向滑步闪避，切忌向后退步，后退容易吃满五段伤害并被墨痕割伤。
- **技能三【勾魂铁索牢】**：
  - *攻击前摇*：生死簿合拢，四周地面浮现四根雕刻恶鬼的青铜立柱，持续0.8秒。
  - *释放动作*：四柱之间拉出粗壮的黑色阴气锁链，将玩家强制锁在直径6格的擂台圈内无法逃离，持续8秒。
  - *危险区域*：整个封闭擂台。
  - *识别与规避*：擂台形成后无法外逃，专心与判官在圈内贴身近战死斗，击中其背部弱点可提前打碎牢笼。
- **死亡表现**：手中的生死簿铁册化作满天燃烧的黑蝴蝶飞舞，判官笔折断两截，官袍失去了支撑软软塌落在地，化作一滩阴水。

### 14. 烈风金雕羽士（浮空箭雨与羽刃风暴精英）
- **基础与模型特征**：身高1.95米。身着金黄华丽长羽编织而成的羽衣，头戴长长金羽冠，身后生有一对巨大的金雕金羽飞翼。双足退化为尖锐的铁铸鸟爪，悬浮在4格高空，手持一把由金雕肋骨打磨而成的巨大长角弓。
- **武器**：金骨长角神臂弓、金羽飞箭。
- **技能一【破晓千羽落】**：
  - *攻击前摇*：高高拉开长角弓指向天穹，身后飞翼完全舒展遮天蔽日，弓弦金光汇聚成耀眼光球，蓄力1.5秒。
  - *释放动作*：向天空射出一支光矢，随后在玩家头顶天顶分裂成数十道金色箭雨倾泻而下，覆盖大面积地面。
  - *危险区域*：地面直径8格的密集金色光圈。
  - *识别与规避*：地面出现密集小光圈交织，需立刻寻找坚固建筑物天花板躲避，或使用盾牌举过头顶持续招架。
- **技能二【翎羽风刃切】**：
  - *攻击前摇*：双翼猛烈向前合拢护住身躯，金羽摩擦发出金属刮擦声，持续0.6秒。
  - *释放动作*：双翼骤然向外振开，向前方180度扇形射出36枚如匕首般锋利的破甲硬羽。
  - *危险区域*：大角度中近距离扇形。
  - *识别与规避*：硬羽散布呈扇形，距离越近承受伤害越恐怖，近战玩家在看到合翼时必须贴地滑铲向其正后方脱离。
- **技能三【旋风俯冲突刺】**：
  - *攻击前摇*：在半空高速自身自转，化为一团金色小旋风，持续0.8秒。
  - *释放动作*：像金色钻头一样从高空高速旋转俯冲撞击玩家，落地后引发猛烈击退强风。
  - *危险区域*：俯冲下落点及周围2格。
  - *识别与规避*：用重武器在其俯冲撞地的一瞬间精准反击挥砍（拼刀机制），可直接破除其旋转并令其坠机陷入5秒大硬直。
- **死亡表现**：双翼的金羽全部失去光泽脱落凋零，身躯从半空失控倒栽葱坠落地面，角弓断弦，羽士的身躯化为一阵金色风沙散去。

### 15. 镇墓狻猊铜吼（四足青铜喷火巨兽精英）
- **基础与模型特征**：长3.6米，肩高2.0米。全金属铸造的雄狮状青铜机关异兽，颈部鬃毛是由无数片薄铜齿轮层叠而成，胸腹部镂空刻有香炉状兽面纹，内部燃烧着永不熄灭的赤红地心石火，四足踏着滚烫青铜法球。
- **武器**：青铜烈火獠牙、腹腔地火风箱。
- **技能一【地心石火喷】**：
  - *攻击前摇*：四足紧抓地面，腹部镂空处猛烈向内抽气，铜片鬃毛急速倒转发出呼啸风箱声，蓄力1.2秒。
  - *释放动作*：从口中喷出一股持续3秒的极度灼热橙红烈焰柱，并随头颅左右横扫90度。
  - *危险区域*：前方8格距离、宽4格的烈焰横扫面。
  - *识别与规避*：看到腹部吸气发红，立刻向其侧面或后腿跑位；烈焰横扫移动慢，紧贴其后腿可安心输出。
- **技能二【青铜踏碎】**：
  - *攻击前摇*：抬起单只前蹄青铜足，足下踩踏的铜球高速旋转飞射火星，持续0.5秒。
  - *释放动作*：狠狠下踏，将地面石板踩成粉碎，引发一道直线推进的地裂火缝。
  - *危险区域*：直线延伸5格的地裂火焰带。
  - *识别与规避*：向左右横跳脱离直线裂缝，切勿站在裂缝上，火缝会持续喷出碎石岩浆火柱。
- **技能三【铜兽怒吼】**：
  - *攻击前摇*：猛然仰头长啸，全身齿轮鬃毛倒竖，持续0.7秒。
  - *释放动作*：爆发出一圈纯物理的高压空气震波，将周围所有实体无条件震退6格并破除所有正在举盾的防御状态。
  - *危险区域*：周围半径4格圆形。
  - *识别与规避*：观察到仰头长啸瞬间，后跳利用距离衰减规避，或使用霸体技能硬抗冲击。
- **死亡表现**：体内的地火风箱过载炸开，从腹部镂空处喷涌出大量熔岩火星，四条青铜腿关节断裂坍塌，庞大的青铜兽首砸在地面化为无生气的青铜废古董。

# 第三项：12个原创Boss设计

### Boss 1：断代凶镬·饕宴之尸
- **称号**：食尽万军无生冢
- **背景**：战国末期坑杀四十万降卒之地，怨气聚于祭祀军神的大铜镬中，残骸与断肢熔铸入青铜器，吞噬无度，终成贪残不化的饕宴行尸。
- **体型**：高4.5米，宽3.2米（超大型重型人形混合物）。
- **完整模型设计**：
  - **头部**：头颅半嵌在一个巨大的青铜爵杯口中，没有五官，面部是一整面被血浸黑的青铜饕餮面具，巨口中探出三排锋利的森白人骨尖牙。
  - **胸部**：胸腔直接由半截镂空青铜大鼎（镬）构成，鼎内翻滚着沸腾的滚烫尸油与残骨，胸骨化作鼎耳向两侧伸出。
  - **肩部**：双肩各挂一只青铜大钟，走动时撞击出沉闷死丧钟声。
  - **手臂**：异化极其严重。左臂是一条由数十根人腿骨与青铜索绞成的惨白长鞭骨手；右臂则粗壮如柱，小臂套在一整根巨大的攻城铁撞角中。
  - **腿部**：短粗的青铜铸造三足鼎足支撑着庞大的身躯，每足踏碎地面形成深坑。
  - **背部**：背部隆起如同小山般的兵刃残骸堆，插满折断的锈枪断戟。
- **武器**：右臂覆装式攻城铁撞角、左手绞骨长鞭。
- **纯黑剪影特点**：一个极其庞大的圆鼎状下盘，上方突起锋利的倒刺武器堆，一侧是一根粗壮笔直的巨大圆柱撞角，另一侧是细长垂地的弯曲骨鞭。
- **推荐骨骼分段**：下肢三足独立IK步进骨骼；胸腔青铜鼎设独立流体晃动骨；右臂攻城锤带两级活塞伸缩骨节；左骨鞭由12节细密关节相扣。
- **Boss场地【万卒沸镬坑】**：圆形下沉式古坑，直径40格，地面铺满风化碎骨，四周环绕着十二根燃烧着青色人油长明灯的白骨巨柱，场边无护栏，下方为沸腾的深渊尸油。
- **登场动画【残骨铸躯】（8秒）**：
  - *时间轴*：
    - 0-2秒：场地中央沉寂的大青铜镬突然震动，四面青色油灯剧烈摇晃，低沉钟声响彻地底。
    - 2-5秒：四面八方的碎骨与断刃如磁石般向铜镬疯狂吸附聚拢，铜镬内涌出冲天黑血，一只巨大的青铜饕餮巨爪撕开血雾扣在地面。
    - 5-7秒：庞大的身躯自鼎中拔地而起，右臂攻城锤重重砸在地面震碎石板，背后残兵燃起幽幽青火。
    - 7-8秒：饕餮面具的大口张开，喷出一股灼热白汽，Boss血条【断代凶镬·饕宴之尸】伴随沉闷擂鼓声显现。
- **阶段一机制（100%-60%血量）**：
  - *技能1【铁撞角碎岳】*：右臂攻城锤向后大幅度收缩蓄力1.0秒，随后以极快速度直线冲撞整整12格，沿途碰碎一切障碍物并对玩家造成碾压破盾伤害。
  - *技能2【骨鞭扫千军】*：左手骨鞭在空中甩出一圈脆响，横向进行270度超大范围低空横扫，将玩家击飞并施加流血。
  - *技能3【沸油泼地】*：胸口青铜鼎猛烈倾斜，向前方泼洒出一大滩沸腾尸油，形成半径6格的持续燃烧陷阱区。

### Boss 2：殉节盲帅·公孙无妄
- **称号**：孤城死守三百年
- **背景**：死守边关孤城直至最后一兵一卒的老帅，双眼被风沙射瞎，身被百创而不退。死后其忠魂与坍塌城墙、战马残骸熔铸为一体，成为永恒巡视空城的盲目怨魂。

    - 3-6秒：破损的城门轰然倒塌，一匹幽火骨马发出一声令人心碎的凄厉长鸣踏碎残门而出，老帅手持斩马刀傲立马背。

  - *技能2【裂地回旋劈】*：在奔驰交错的一瞬间，借由马匹冲力，单手大刀自右向左平斩而出，斩出一道掠地5格的风沙狂刃。

  - *技能4【残矢齐射】*：挥刀下令，城墙四周的兵魂虚影同时向瓮城内抛射一轮覆盖性箭雨。

  - *技能5【十方俱灭狂斩】*：连续向前踏出七步，每一步斩出一刀暴烈血色刀光，并在地面留下持续爆炸的裂隙。

- **掉落物**：公孙无妄的断刃斩马刀（神器胚体）、盲帅残破凤翅兜鍪、孤城血战誓书。
- **击杀后环境变化**：漫天黄沙停歇，温暖的阳光穿透厚厚云层洒入瓮城，坍塌的城墙上长满青葱的野花，所有战意残魂化为安详微风升空。

### Boss 3：九霄木鸢·鲁班遗煞
- **称号**：千机机关主
- **背景**：春秋鲁班所造木鸢之遗骸，原本能乘风飞三日不下。岁月流转中被盗墓方士植入煞石驱动核心，化为一尊拥有自我意识、盘踞于高空云海中的巨大机关造物。

- **完整模型设计**：

  - **胸部**：由成百上千个精密的紫檀木榫卯齿轮箱构成，胸腹部带有可开合的轰炸弹仓，腹部涂有古老的朱砂镇灵纹路。

  - **手臂（双翼）**：完全由红木羽片与青铜折叠滑轨构成的多节机械翼，羽片边缘被打磨得如剃刀般锋利。
  - **腿部**：收拢在腹部的两只巨大的四爪青铜起落鹰爪，足尖为打孔穿金爪。
  - **背部**：安装有四组由火油发动的青铜喷射气筒，喷吐出炽热尾焰。
- **武器**：剃刀滑翔羽翼、腹部雷煞飞火弹、起落重爪。

    - 0-3秒：摘星台周围云海剧烈翻涌，天空中传来巨大齿轮高速咬合的轰鸣声与破空气流声。
    - 3-6秒：一道巨大的黑影自深不见底的云海下方高速拉升，巨翼掀起剧烈狂风将平台上的碎瓦刮飞。
    - 6-8秒：木鸢以不可思议的机动性在平台上方掠过，随后巨翼翻转，双爪在木平台上抓出四道深深的划痕滑行停驻。
    - 8-10秒：木鸢双翼完全展开向天长啸（尖锐机关齿轮鸣响），额头煞石爆发强光，Boss血条【九霄木鸢·鲁班遗煞】浮现。
- **阶段一机制（100%-60%血量）**：

  - *技能2【天女散雷火】*：在平台上方盘旋，腹部弹仓开启，向下投掷8枚下落缓慢的木制雷火弹，触地后引发连续爆炸。

  - *技能5【天枢引雷落】*：额头核心连通天际雷云，引导四道巨大的落雷轰击平台，使被击中的木地板起火坍塌（平台面积缩减15%）。
  - *技能6【绝灭神机冲】*：飞入极高天际消失，3秒后化作一颗燃烧的巨大火流星垂直撞击平台中心，引发毁天灭地的全屏震荡波（玩家必须卡准落地前0.5秒起跳躲避地波）。

  - 额头雷煞石碎裂爆炸，双翼木榫卯寸寸断裂脱落，庞大的机械鸟身失去升力在空中剧烈翻滚，最终砸穿摘星台边缘斜向坠入万丈云海，沿途脱落无数旋转的黄铜齿轮与木羽。
- **掉落物**：天枢木鸢核心机括、极韧朱砂木羽片、鲁班天工机关图残页。
- **击杀后环境变化**：高空罡风平息，阳光穿透云海形成壮丽的日晕环，摘星台中央升起一座机关通天绳梯，直通下方探索区域。

### Boss 4：沉渊骨龙·烛阴残蜕
- **称号**：冥海覆浪之脊
- **背景**：古神烛九阴退化蜕下的一节死灭脊骨，在终年不见天日的深渊海沟中吸收死尸与冥水，诞生的无目白骨巨蛟，所经之处万物化冻为死寂幽水。

- **完整模型设计**：
  - **头部**：一颗巨大扁平的苍白巨龙骸骨颅骨，没有肉体与眼睛，颅腔内燃烧着一团纯白色的不灭烛阴死火，上颚生有四颗交错的巨型龙牙。
  - **胸部/前段**：覆盖着厚重如盾牌般的骨质外骨骼，两侧生有退化成船桨状的惨白骨鳍。
  - **躯干**：由三十六节粗大的环形脊椎骨严密咬合而成，每节脊椎两侧均生有一根倒生的肋骨尖刺。
  - **尾部**：尾端分叉为三道如巨大骨剪般的锋利骨片。
- **武器**：烛阴苍白冻火、巨型白骨身躯、尾部三叉骨剪。
- **纯黑剪影特点**：一条在战场上空与地面循环翻滚游走的修长蜿蜒巨龙轮廓，头部那团巨大的冷火在黑暗中极具压迫感。

- **Boss场地【永夜冻潭水宫】**：一座被极寒死水浸没的巨大半淹没溶洞，水深及膝，四周是参差不齐的玄冰石笋与倾颓的龙纹石柱。
- **登场动画【破冰惊渊】（12秒）**：
  - *时间轴*：
    - 0-3秒：水潭表面瞬间结出一层黑冰，四周空气温度降至绝对冰点，玩家视线周围浮现厚厚白霜。
    - 3-7秒：厚重冰面自远处呈直线连续爆裂冲天，一条庞大无匹的白骨龙脊破冰而出跃入空中，随后优雅滑翔回旋。
    - 7-10秒：巨龙自天顶倒悬盘旋在中央最大的石柱上，龙头低垂，颅骨内的苍白冷火“呼”地暴涨三倍照亮全场。
    - 10-12秒：巨龙发出无声的灵魂震波，全场水花飞溅，Boss血条【沉渊骨龙·烛阴残蜕】以冰晶凝结特效显现。
- **阶段一机制（100%-65%血量）**：
  - *技能1【幽冥冰霜吐息】*：龙头蓄力吸气，苍白火焰收缩，随后自左向右喷射出一道极寒死亡吐息光柱，将沿途水面瞬间冻结成尖锐冰刺。
  - *技能2【骨剪摆尾】*：庞大的尾部自水中猛力甩出，360度大扫击，将接触到的石笋齐腰扫断并拍碎。
  - *技能3【潜水盘绞】*：没入膝深水中快速潜游，水面露出耸立的背刺如鲨鱼般向玩家冲来，命中后将玩家拖入深水绞杀。
  - *技能4【冰魄陨坠】*：身体重重撞击洞顶，震落大量巨大的尖锐钟乳石冰锥砸向地面。
- **阶段二机制（65%-0%血量）**：
  - 骨龙颅内的苍白冷火突然外溢，包裹整具白骨身躯，水潭水位退去，变为纯粹的极寒光滑滑冰地面，玩家移速受滑冰影响减速且难以制动。
  - *技能5【烛阴开眼·天地皆昼】*：整个阴暗的溶洞瞬间爆发出极度刺目的苍白极光，全场陷入白昼，所有直视龙头的玩家被强制冰冻在原地3秒（玩家必须背对Boss低头看地躲避极光）。
  - *技能6【黄泉逆流穿刺】*：骨龙冲入地下冰层，随后从玩家脚底垂直向天空冲天而起，随后再度折返贯穿冰面，连续穿刺三次。
- **死亡动画【玉碎冰消】（14秒）**：

### Boss 6：赤练红罗·蛇母娘娘

# 第五项：12种神器神影显圣设计

- **显圣模型**：仅有一截自虚空漩涡中伸出的玉白色巨大神明食指，指节晶莹剔透，指尖缠绕着流转不息的阴阳太极阴阳鱼气流。
- **出现位置**：出现在目标敌人头顶垂直上方两格处。
- **动作与配合**：在玩家完成八卦推演并指向敌人的瞬间，这根巨大的神之手指优雅从容地轻轻自上而下一指点在敌人的天灵盖上。没有剧烈爆炸，但接触的一瞬间空气静止，敌人周身的煞气与护甲如同玻璃般清脆崩碎。

### 9. 【上古夸父逐日奔影】（身侧并行冲锋虚影）
- **对应神器**：夸父逐日追光杖
- **显圣模型**：一尊高达八米、赤裸上身、肌肉如铜浇铁铸的远古夸父巨人虚影，手持桃木杖，大步流星。
- **出现位置**：出现在玩家奔跑时的正身侧（并排并行）。
- **动作与配合**：当玩家处于极速疾跑冲锋时，夸父虚影在玩家身旁与玩家以完全相同的步频狂野迈步奔驰，巨人的脚步在大地上震荡出轰鸣。玩家杖击时，夸父虚影同样将参天巨杖横扫而出，将冲锋路线上的所有障碍物全部夷为平地。

### 10. 【忘川摆渡幽冥客】（水面划船而过的虚舟）
- **对应神器**：幽都忘川招魂幡
- **显圣模型**：一条由青黑死气凝结而成的古老乌篷小舟，舟尾立着一位头戴蓑笠、看不清面目的撑篙黑影老翁。
- **出现位置**：在玩家挥幡时，直接贴着地面由虚空浮现，自玩家背后向前方滑翔穿过。
- **动作与配合**：招魂幡下指，这道幽灵孤舟便载着森森鬼火向前贴地高速滑行穿过敌阵，舟身穿透的所有敌人灵魂被强行拖出体外产生1.5秒的呆滞出窍状态，小舟随后化为一团冰冷的忘川冷雾消散。

### 11. 【墨家巨子千手天工枢】（背后辐射齿轮神臂机架）
- **对应神器**：天机匣式神机弩
- **显圣模型**：并非血肉躯体，而是一个由成百上千个旋转黄铜齿轮与连杆构成的巨大古老机关神环，神环周围向外展开八只由青铜构装拼接而成的巨型机械臂。
- **出现位置**：悬浮在玩家后背半寸处，随玩家一同移动。
- **动作与配合**：在玩家射出破甲重钢钎时，背后的机关神环八只机械臂同时开合，四只机械臂猛然撑地为玩家吸收全部恐怖后坐力，另外四只机械臂在空中拉动巨大的虚幻机括，为飞出的钢钎附魔上高速旋转的空气钻头风刃。

### 12. 【烈火祝融九龙绕体神像】（环绕型活体神灵环）
- **对应神器**：无相黑佛骨舍利（神火类兵刃）
- **显圣模型**：上古火神祝融之威严半身法相，赤发披肩，驾驭两条长达五米的烈火赤龙在玩家身周循环盘旋游动。
- **出现位置**：以玩家身体为轴心，呈同心圆高速环绕飞舞。
- **动作与配合**：在玩家进行烈火横扫时，祝融神像双臂结印大喝，两条火龙呼啸着脱离环绕轨道，交错螺旋冲向前方敌阵，将沿途地面化作一片翻滚的火海焦土，最后火龙回首融入玩家武器之中。

# 第二～第五项工程执行要求

## 精英怪
15只按3～5只一批。每个技能先写时间轴：
`选择条件 → WINDUP → ACTIVE → RECOVERY → COOLDOWN → 可打断窗口 → 玩家反制`
再编码。每只至少一个真实弱点/反制。不能只加血。

特别限制：
- 白面狐仙姑不篡改WASD；
- 墨家绝影刺客不做纯黑全屏；
- 九首鸟/蛛女/多足/巨猿等一个实体+骨骼；
- 召唤物必须owner+数量上限+死亡清理；
- 冲锋撞墙、背击、破卵、破标枪等写成真实服务器判定。

## Boss
复用/建立统一：
`Phase / Action / actionTick / cooldown / chooseNextAction / startAction / tickAction / finishAction / onPhaseChange / startDying`

每只Boss逐只完成后再下一只。技能Telegraph和真实Hitbox必须共用同一位置、半径、方向参数。
超大型Boss只少量multipart；飞剑/雷雨/蛇群等用少量逻辑判定+大量客户端视觉。
Intro期间玩家保持自由移动和视角。
Boss生命归零进入DYING，不立即discard；奖励只在唯一服务器关键帧发一次。

### 最终Boss保护
镇渊帝君保持正式最终Boss。
混元祖兽只实现为前置/隐藏Boss；若具体接入位置仍有冲突，先实现实体/技能/Arena接口但不要接管四象最终流程和唯一宝匣。

## 神器
统一ArtifactAbility框架。客户端只发送“请求使用”，服务器重新验证当前手持物、冷却、资源、距离、目标。
近战扇形/长枪射线/光束/链索/投掷等使用不同AttackProfile。
连段和拼刀由服务器gameTime判断，留网络延迟容差。
投掷、链索、容器相关必须防复制/越权。
暂时没有落地遗迹时保留Reward Hook，不能改成随便合成。

## 神影
默认客户端Visual，不是可攻击服务器Mob。
服务端只同步：
`phantomType / casterId / target/position / direction / startGameTime / duration / seed`

12种空间锚点保持不同：
`HEAD_ABOVE / PLAYER_OVERLAY / BACK_ABOVE / GROUND_RISE / WEAPON_ORIGIN / SKY_ANCHOR / SHADOW_ORIGIN / TARGET_ABOVE / SIDE_RUNNING / GROUND_PASS_THROUGH / BACK_MECHANICAL_RING / ORBIT_PLAYER`

任何Renderer必须恢复PoseStack、Blend、Depth、Cull、Shader状态。旁观玩家只能看到世界空间视觉，不执行施法者第一人称Camera/Overlay。第一人称near plane不得被大面片覆盖。
