# 怎样在游戏里看到新版任务

本轮已经更新桌面 `dynasty` 项目的：

- `modpack/config/ftbquests/quests/`：整套新版任务，包括新增章节与分组。
- `modpack/mods/dynasty-1.4.0.jar`：编译后的模组，含新增配方、归乡符修复和同步指南。

这些改动会出现在同一个项目的 VS Code / GitHub Desktop 中，尚未提交或上传。
没有自动复制到 HMCL 或其他启动器的游戏实例。

## 更新已有游戏实例

1. 完全退出游戏；多人服务器则先停止服务器。备份该实例的原任务配置、原模组 jar 和存档。
2. 把上面整个 `quests` 目录中的文件合并复制到实例同名位置，覆盖同名文件。不要只复制某一章，也不要删掉其他模组自己的章节。
3. 用新的 Dynasty jar 替换实例里的同版本旧 jar，确保只有一份 Dynasty。不要改动别的模组。
4. 多人服的任务配置以服务器为准；服务器与客户端都应更新 Dynasty jar。
5. 重启后打开 FTB 任务书，左侧选「主线旅程 · 从这里开始」，进入「01 · 安家与第一把兵器」。

不要删除存档里的 FTB 任务进度，也不要使用重置任务命令。旧 488 条任务的 ID、检测和奖励都保留；新增阅读提示无奖励。
如果仍看到旧版「一、初入王朝」，通常是正在运行的实例配置没有更新，不是图片缓存。

## 建议先在备份/测试世界检查

- 第一页：勾选阅读提示后，依次检测工作台、箱子、火把、熔炉。确认物品不会被任务收走。
- 第三章：科举答对、虎符实际列阵、叛将首杀是否自动点亮，个人万能槽是否只增加一次。
- 第四章：一次合成得到两座天朝门；携带第二座与归乡符进入天朝，在对面放门并测试往返。
- 归乡符：从异界使用后应回主世界出生点附近，而不是当前异界出生点；符消耗一张。
- 旧档：核对已完成任务仍完成，已领取的槽位不重复增加。
- Boss 页：点「查看攻略」进入对应图鉴，再点返回讨伐；核对首次寻找、召唤复战与打法说明。

自动检查已经通过，但本轮未在你的存档里实际游玩完整流程，也未自动打开本地浏览器预览。请把游戏中的问题页截图给我，下一轮按实际游玩反馈继续调节。
