# 王朝流派任务与图鉴布局

这轮保留 8 章主线、59 个主线节点的先后关系，以及 488 条旧任务的身份、目标和奖励。五个永久加槽里程碑未改。新增内容是中期可选玩法，不是通关的新门槛。

## 玩家会看到什么

首页「山河总览」用 8 个可点击图牌导航：左侧按安家、工坊、维度、毕业找当前阶段；右侧选四条流派。图牌不算任务，只保留一个随时可读的总览说明，所有返回链接仍指向固定 ID `1000000000040000`。

每条流派 12 个节点，其中只有开篇说明是阅读勾选，另外 11 个是实际物品、击杀、维度或服务器试炼检测。核心顺序是备料 → 武器 → 招式试炼，两件配饰和战备支线可按需做。

| 流派 | 真正的招式试炼 | 独有战备/演练 |
| --- | --- | --- |
| 玄武守御 | 镇岳刀正面接敌，窗口内满力反击 | 备用盾、僵尸接击练习、金创药、青铜补片、金苹果 |
| 游龙剑舞 | 同一可见敌人连续三次满力命中 | 轻靴练步、刺客应对、丝锦备料、天朝行走、末影珍珠换位 |
| 逐星射艺 | 两次满蓄命中同一敌人，第二箭消耗标记 | 64 支箭、骷髅对射、标靶材料、云台防坠、望远镜与观星建筑指引 |
| 道门律令 | 控制可见敌人，站定蓄势后满力笔击 | 符纸朱砂、兵俑练法、长生丹、幽冥行旅、石墙与照明 |

试炼由游戏服务端完成对应 `build_*_trial` 成就后检测；普通击杀任务不伪装成指定武器击杀。标靶/阵地节点明确只检测持有，不假装检测建筑完成。持有饰品也不等于已经佩戴。

各路线有三枚原生 QuestLink 引用旧防具、补短板饰品和毕业武器；导航、门、回程继续链接旧主线，不重复发奖励。所有新奖励为个人一次性经验，不添加可重复刷取或加槽命令。四种玩法不锁职业，可随时换装备。

## 饰品图鉴

九种真实 Curios 槽位继续各一章，177 件注册饰品全部覆盖，新增八件流派饰品以链接复用流派任务。小分类分别使用冠形、环形、扇形、翼形、护盾、丝带等布局，重要入口与普通收藏任务区分。

护符按实际 `DynastyTrinkets.EXTRA_TABLE` 数值与已核实的旧 switch 行为分四区，而非均分 ID：

- 进攻与命中增益：29 件。
- 防护、机动与功能：28 件。
- 条件触发：20 件。
- 负面代价：10 件。

分类优先级是负面代价 → 条件 → 进攻/命中 → 其他功能。一个饰品只有一个位置；所属分区不是强弱排名，也不表示所有效果无条件生效。具体条件、概率仍以游戏物品说明为准。

## 实现和再生成

- 唯一生成入口：`python3 -B tools/art/gen_ftbquests.py`。
- 流派合同：`docs/content/schools-v1-contract.json`；正文使用真实合同中的效果与试炼条件。
- 身份/节点：`tools/art/quest_routes.py`；布局/分区：`tools/art/quest_atlas.py`。
- 原生界面图牌：`tools/art/QuestAtlasArt.java`。这是 Java2D 生成的字体和几何 UI，不是 AI 模型图，也不是游戏截图。
- 重出 32 张 UI 图牌：`java tools/art/QuestAtlasArt.java src/main/resources/assets/dynasty/textures/gui/quests`。
- 配置预览：`python3 -B tools/art/preview_quests.py docs/quests-remaster/gallery.html`。

原生字段已对照实际 FTB Quests `2001.4.22` 与 FTB Library `2001.2.13` 的字节码：章节 `images`、图片 `click: "#<id>"`、`quest_links`、`can_repeat: false`。文案内蓝字继续走 `change_page`；不使用命令或外部网页跳转。

新增固定数字区间：四派任务 `0x30000/0x30100/0x30200/0x30300`，总览 `0x40000`，槽位说明 `0x41000` 起；章节 `0x500`、`0x510` 至 `0x513`。既有组 1–5 保留，新增总览组 6、流派组 7。

## 验证与边界

`test_quest_story.py` 当前 28 条通过，覆盖 488 个旧身份/奖励冻结、主线隔离、四派真实试炼、材料配方、DAG、布局无重叠、跨流派错误前置、图牌跳转、QuestLink、原生序列化和饰品分区。`verify_curios.py` 验证 177 件分类及五个旧里程碑不变。

新增装备后，`verify_ftbquests.py` 要在新 JAR 构建后执行；它从 JAR 校验物品与成就，不能拿旧 JAR 的缺失结果判断源数据。完整导出为 35 章、565 个任务、20 个 QuestLink、103 条前置，无环。

原有支线「王朝药水」仍保留获取来源待核实提示；本轮不将它加入主线或流派门槛。HTML 是配置预览，实际 FTB 游戏界面的缩放、点击与图片显示由统一实机验收确认。
