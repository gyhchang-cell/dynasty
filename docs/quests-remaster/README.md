# 王朝任务重制 v2

## 已实现

任务从一个大杂烩拆成五组：主线旅程、支线探索、装备与配方、饰品搭配、旧版记录。
共 30 章、505 节点，其中主线只有 8 章、57 节点；其余均为可选查询/挑战。

新增 Boss 攻略章：龙帝、叛将、宦官首脑、不死始皇、九霄天将、东海龙王，以及法阵·祭坛说明。
首次讨伐、重复挑战和对应信物任务内可点击攻略文字跳转，攻略可返回主线讨伐。
使用当前 FTB Quests 原生 change_page 链接，无需额外模组；首次自然寻找和取得信物后的祭坛复战分别说明。

1. 安家与第一把兵器：工作台、储物、照明、熔炉 → 木矛至铁剑 → 盾。
2. 工坊、图纸与配装：青铜材料 → 遗迹朱砂 → 竹简/徽墨/图纸 → 青铜剑 → 玉与配装说明。
3. 入仕与平叛：试卷 → 答对科举 → 虎符列阵 → 叛将首杀与信物。
4. 做好回程，再入天朝：符纸/归乡符 → 主世界深层龙晶 → 两座门 → 入境 → 宦官首脑与令牌。
5. 幽冥帝陵：地府入口 → 安全落脚 → 不死始皇 → 斩帝里程碑 → 帝骸骨/玄天玉。
6. 九霄试炼：入口 → 高空生存 → 天将 → 天将令。
7. 东海定波：水下准备 → 龙宫 → 龙王 → 第五项永久槽位里程碑。
8. 问鼎与毕业路线：返回龙庭 → 龙帝首杀 → 玉玺 → 自选近战/远程毕业装备。

每条主线都写明“为什么做 / 怎么做 / 完成后去哪”，说明配方、掉落与材料所在章节。下章名称直接写在章末。
饰品从混排改为九个槽位分类页面，169 件全部保留。武器与防具可随时查，不需要全收集。
6 条旧版守军击杀任务保留在旧记录中，不作为主线或推荐路线。

## 同步修复的实际断点

- 青铜基础合金配方：铜锭×3 + 铁锭 → 青铜锭×4。没有要求玩家找不存在的锡矿。
- 四种传送门补齐配方，每次产出两座；明确目的地不会自动创建回程门。
- 归乡符改为跨维度返回主世界出生点附近的安全落脚点，不是当前维度出生点，也不是玩家床。
- 龙晶主世界 Y=-60 至 -5 生成，铁镐可挖，不再写成天朝独有或必须先做龙晶镐。
- 宦官首脑在天朝自然生成，因此移到入境之后；不再安排玩家先在主世界宫殿等它。
- 避水珠与龙骨戒补上生存配方，避免它们及其后续合成链没有基础材料来源。
- 四把非合成兵器保留原机制，明确机缘条件：白天杀凤凰、达到尚书/丞相、击败五种不同 Boss。
- 内置指南同步入口、路线、官阶/槽位、回程与材料说明。

## 旧档兼容策略

`tools/art/quest_legacy_v1.json` 是改动前 488 条任务的只读身份快照。
所有旧任务 ID、目标 ID、检测目标与数量、奖励 ID 和奖励内容保持不变，只改位置、说明与依赖。
五项 Curios 里程碑仍使用原个人奖励及幂等解锁命令；`curios_progression.json` 未改变。
不删除玩家任务进度、不清空存档、不重置奖励，不把旧目标 ID 改成新任务。

阅读页需手动确认，均无奖励，不冒充穿戴/备战检测。旧档已完成节点保留；新增入门提示仍可能需要确认。
这是配置层兼容策略，尚未在用户旧存档里跑完整迁移测试。

## 验证与预览

```sh
python3 tools/art/gen_ftbquests.py
python3 tools/art/test_quest_story.py
python3 tools/art/verify_ftbquests.py
python3 tools/art/verify_curios.py
python3 tools/art/preview_quests.py docs/quests-remaster/gallery.html
./gradlew --offline build
```

17 项自动化回归覆盖：旧身份/奖励、生成稳定性、导出一致性、无环/坐标、主线与图鉴隔离、个人里程碑、配方备选项、材料顺序、维度与 Boss 顺序、攻略双向链接，以及故意破坏数据后的拒绝行为。
Gradle 编译通过不等于游戏内生存通关。仍需游戏中验证 FTB 页面、旧档进度、跨维度归乡符实际使用与节奏。

`gallery.html` 是从实际 SNBT 导出的交互布局预览，不是游戏截图。此次浏览器安全策略禁止自动打开本地页面，未完成浏览器视觉验收。
`book.json` 是便于审阅的完整编排；`source-audit.json` 列出未核实来源的旧可选节点。
当前剩余 `dynasty:dynasty_potion` 为独立旧物品，不能与酿造得到的原版药水物品混为一谈；明确标为未核实来源，不阻塞任何主线。
