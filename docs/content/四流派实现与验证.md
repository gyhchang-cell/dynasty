# 四流派：中期可选玩法

精确数值、材料与槽位的唯一合同为 `schools-v1-contract.json`。主线不依赖这些装备；可自由换装，不锁定职业。

## 内容与规则

- 玄武守御：镇岳刀右键定向半减伤，最长2秒；停止使用（含换槽）冷却6秒。成功抵挡敌人后一次满力反击+35%。镇关镜延长反击窗口；虎贲护腕增加反击控制。
- 游龙剑舞：流云剑同目标三次满力普通攻击，第三击+50%。弱击、换目标、超时、切武器重置。连城剑穗延长连段间隔；踏云佩在终结击赋予短疾风。
- 逐星射艺：逐星弓两次满蓄命中同目标，第二箭消耗标记+40%。一人只标记一个目标；投射物保留发射武器快照，切换帝兵不能借它的附魔/伤害。观星坠显形；鸣弦环在消标时减速。
- 道门律令：敕令笔右键影响5格内最近的最多8名可见敌对生物，之后站定持续按住2秒获得一次笔击增伤。司天印延长控制；定风帛仅在站定蓄势时加抗击退。

控制不穿墙，不影响玩家、普通动物、友军士兵。王朝六位主线Boss通过真正的 `BarHolder` 身份识别，使用较短控制；不以减伤百分比推测Boss身份。四个试炼由真实服务器操作授予，无额外经验、物品或功名。

Curios存在时，八饰品只有真实穿戴才生效；未装Curios才使用已有背包兼容逻辑。所有学校状态在登出、死亡、换维度和服务器停止时清理，不保存在世界实体或方块中。区域扫描只发生在敕令施放时，不逐tick扫周围。

## 与旧战斗机制的接线

饰品斩杀/雷罚的附加伤害保留玩家归属，用局部 `ThreadLocal` 上下文阻止再次触发饰品、偷用流派攻击；`finally`始终清理。没有改旧武器的固定攻击或帝兵数值。

吸血/斩杀/雷罚的后置处理从 `NORMAL` 内移到单独的 `LOWEST`，读取学校 `LOW` 加成后的Hurt金额。这里仍是护甲/吸收前的Hurt阶段，并非承诺改成实际生命损失吸血。太阳裁决仍绕过这条管线；青龙原始命中不提前结算，龙落地才结算一次。

## 可复现生成与验证

```sh
python3 tools/art/gen_schools.py
python3 tools/art/gen_curios.py
python3 tools/art/gen_codex_all.py
python3 tools/art/test_schools.py
python3 tools/art/verify_gear.py
python3 tools/art/verify_lang.py
python3 tools/art/verify_balance.py
python3 tools/art/verify_curios.py
./gradlew --offline runGameTestServer
./gradlew --offline -I tools/art/schools-curios-qa.init.gradle runGameTestServer
```

专属图像由美术任务提供；生成器不会覆盖任何PNG。12张图标及逐星弓3张真正不同拉弓帧均固定128×128。后羿/逐星的拉弓模型是显式渲染变体，不冒充注册物品。已重制旧饰品使用逐ID固定64/128尺寸表，其他旧物品仍执行32像素规则。

本轮验证：6项数据/资源测试、4,479条纯Java规则断言；含Curios实测49个GameTests全通过（原37项+新增12项）。记录见 `build/schools-curios-gametests.log`。
