# 帝陵与观星台空间重制 v2

这一轮重做建筑内部空间和轮廓，不提高战利品档位，也不新增机关伤害或 Boss 刷新逻辑。

## 帝陵地宫

- 保持已注册的 40 × 40 × 16 边界。南侧入口经过三重石拱、香炉壁龛进入宽主墓室。
- 主墓室有六组高壁柱、抬高的藻井、玉石与青铜地面引导线，北端石阶连接独立棺椁台。
- 四个侧室分别做成典籍室、葬器室、礼器廊、修兵廊；有书架、讲台、制图桌、陶罐、钟鼓和修理设施。
- 东西各一条回廊将南北侧室连通，玩家可以从主轴前进，也能绕路搜寻，再回到中央区域。
- 保留四只宝箱及原 `imperial_mausoleum` 掉落表，不因扩充装饰提高资源产量。

游览顺序：南门 → 神道石拱 → 南侧两间礼器/修兵室 → 两侧回廊 → 北侧典籍/葬器室 → 主墓室 → 棺椁台。

## 观星台

- 保持 26 × 26 × 20 边界，将原来的实心阶梯平台改为两层可行走空间。
- 下层是有照明、书架、制图桌、酿造台的环形回廊；四面石阶下留穿行拱口，回廊可以绕一圈。
- 上层四向楼梯使用实际楼梯方块，沿途净空已切开，不需要连续跳整块台阶。
- 上层有带缺口的栏杆、四座高柱、分段飞檐；中心为三向交叉的立体浑天仪，北斗七星镶在地面，不再挡路。
- 保留两只供箱及原 `ritual_circle` 掉落表。中央祭坛仍是现有祭坛方块，没有宣称新增召唤玩法。

## 保存兼容与生成安全

新结构起点将 `DynastyTombLayout` / `DynastyStarLayout` 写为 `2`。旧存档中没有该标记的结构继续走旧版布局，包括尚未生成的分块，防止半座新、半座旧的接缝。

已经生成的建筑不会自动覆盖；需要在尚未生成的区域找新建筑，或在备份的测试世界里用结构放置功能查看。

全部新放置仍通过原有 `StructurePiece.placeBlock` 路径，保留旋转与分块裁剪。没有新增方块实体循环、刷怪循环或定时逻辑。

## 自动检查

`VaultObservatoryGameTests` 直接截获实际生产代码的放置调用，检查：

- 所有放置坐标在保存边界内，写入量有上限；
- 帝陵入口通往四个侧室、两条回廊、宝箱附近与中央区域；
- 观星台下层闭环、四向楼梯可抵达上层；
- 原来的四/两只宝箱数量和掉落表不变；
- 新布局版本写入存档标记。

这些是逻辑与方块布局检查，不等于游戏内美术截图；实机仍需检查地形衔接、照明观感与材质风格。
