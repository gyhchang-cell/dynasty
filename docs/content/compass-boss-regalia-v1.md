# 罗盘联动与 Boss 立体轮廓 v1

## 罗盘不重复安装

项目已包含 Nature's Compass 1.20.1-1.12.0 Forge 和 Explorer's Compass 1.20.1-1.4.0 Forge。
官方说明：https://github.com/MattCzyr/ExplorersCompass 、https://github.com/MattCzyr/NaturesCompass 。前者找建筑，后者找生物群系。

新增 `/dynasty_find`：普通玩家可用，聊天里出现可点击的 12 个目的地。
主手拿探索者罗盘导航六种王朝结构；主手拿自然罗盘导航六位 Boss 的一种已核实栖息生物群系。
必须先进入目标维度；没有传送、赠送罗盘或免费绕过费用。
例如天朝龙帝：`/dynasty_find dragon_emperor`；国子监：`/dynasty_find academy`。
六页 Boss 图鉴已加入入口说明。

通过反射调用已安装 JAR 的公开 searchForStructure/searchForBiome 方法，复用原模组搜索工作器。
校验目标白名单、维度、持有物品、损坏状态、允许搜索列表和经验费用，附加 5 秒请求间隔。
没有罗盘模组时王朝仍可加载，调用给出缺失提示；接口不兼容时提示手动右键原罗盘。

**范围限制：不是全世界 Boss 实体雷达。** 当前 Boss 为自然刷新，建筑也并不保证驻守 Boss。
帝陵建筑在天朝，而不死始皇的自然栖息地是地府；菜单特意区分，不能把建筑坐标误当固定战场。
叛将本轮预设幽冥栖息区，不是声称主世界没有叛将。首次到达仍需探索，有信物后可祭坛复战。

## Boss 外形

- 龙帝：立体金玉分段背环、六枚缓慢公转印牌、冠饰，以及胸甲/侧腰甲/护膝。
- 九霄天将：两道反向旋转星环、六枚独立浮动的棱面雷刃、刃心环饰和立体护甲。
- 悬浮件是有厚度的多边形网格，不是圆圈粒子，也不生成额外实体。
- 只改这两位 Boss；保留原有人形动作基础，并未宣称全部 Boss 已成为非人形。
- 不修改 AI、血量、攻击判定与碰撞箱；悬浮装饰不能单独受击。
- 参考灾变作者页面中强调的独立 Boss 形象与战斗空间方向：https://www.curseforge.com/minecraft/mc-mods/lendercataclysm 。没有复制其素材，也未安装灾变为新依赖。

## 验证

导航目的地资源和六条实际刷怪区域核对、已安装 JAR 公开方法检查；17 项任务回归；800 帧纯网格顶点/面积/面数检查；实体注册检查。
独立 Minecraft 客户端离屏渲染真实模型，并检查 GL 错误。预览不是实际战斗截图。
罗盘真实搜索、多人使用和光影组合尚未实机验证；反射 API 检查不能替代这些。
改动只在桌面项目，没有同步启动器或上传 GitHub。
