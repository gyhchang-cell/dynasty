# 你直接搭建筑，我来接入游戏

最省事：在同版本王朝整合包中新建一个独立的「创造 / 超平坦」测试世界，像平常一样放方块搭建筑。不要拿长期生存存档做试验，不必安装新的建筑工具，也不必编写方块坐标。

做完后退出这个测试世界，在启动器的「游戏文件夹 → saves」找到它，把整个测试存档交给我即可。附一张入口截图、一张俯视图，告诉我建筑大概在哪里；只需建筑位置，不是每个方块的位置。导出结构、裁剪空气、分块、旋转和自然生成接入由我处理。

建议先做一座「你愿意进去探索」的院落：主入口明显、门至少两格高，主要道路留三格宽；有主殿、两三间各自用途不同的房间、回廊和小庭院。可用现有王朝方块、原版楼梯/半砖/围墙。不要为了细节塞满每一个空格，给玩家走路、战斗和看建筑的空间。

## 如果你愿意自己导出

1. 创造测试世界开启命令，输入 `/give @s minecraft:structure_block`。
2. 用结构方块的保存模式圈出建筑，名称填 `dynasty:submissions/my_palace_v1`，关闭「包含实体」。这是一次圈选边界，不是逐块填坐标。
3. Java 1.20.1 原版结构方块每个方向最多保存 48 格；大建筑拆成门楼、侧殿、主殿等模块，或者直接交整个测试存档。
4. 保存文件位于该世界的 `generated/dynasty/structures/submissions/my_palace_v1.nbt`。发这个文件并附入口方向、地面高度、截图和新增模组方块清单。

NBT 放进项目还不会自动自然生成。现在的建筑主要由 Java Piece 生成，后续我会把你提交的模板接入结构生成、宝箱表和地形适配，并验证旋转、跨区块和道路，不需要你写这些代码。

优先交独立建筑存档。你负责建筑审美和体验，我负责技术接入。
