# 王朝主菜单：使用与回退

主菜单使用本地宫阙云海、金龙背景与朱砂/墨青按钮；图片随模组一起打包，不需要在线下载。图片原始尺寸为 1672×941，界面读取真实比例后等比铺满，不强行拉伸。右下四条流派是介绍文字，不是按钮；小窗口会隐藏这组介绍，保留所有入口。

单人游戏、多人游戏、Mod、设置、Minecraft Realms、退出游戏、语言、无障碍沿用原版/Forge 的实际回调。多人权限限制、安全提醒、禁用提示、Realms 通知、Forge 更新标记保留。没有已有存档时，单人游戏会像原版一样直接打开创建世界界面。

按 Tab 切换按钮焦点，Enter 激活。按 F6 可回到原版主菜单；打开主菜单时按住 Shift 也会保留原版样式。若希望始终使用原版，可在启动器的 JVM 参数中加入 `-Ddynasty.vanillaMenu=true`，删除该参数即可恢复王朝封面。回退不会修改存档或账号权限。

## 维护入口

- Java：`src/main/java/com/dynasty/client/DynastyTitleMenu.java`、`DynastyTitleScreen.java`。
- 背景：`src/main/resources/assets/dynasty/textures/gui/title/imperial-dawn.png`；相邻 `.mcmeta` 开启平滑采样。
- 文案：`tools/art/gen_title_lang.py`，只合并本界面的 9 条中英词条，不运行装备/配方生成器。
- 独立验证：`tools/art/title-qa/`，不进入生产 jar，不改现有 `ImperialRuntimeQa`。

```sh
python3 tools/art/gen_title_lang.py
python3 tools/art/gen_title_lang.py --check
./gradlew --offline -I tools/art/title-qa/title-qa.init.gradle runClient > build/schools-title-qa.log 2>&1
```
