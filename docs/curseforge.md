## 摘要 / Summary（不超过 300 字符）
```
完整东方王朝模组：真实地形的天朝与地府两大维度、宏伟宫殿与帝陵结构、科举 GUI 与官阶系统、军队阵型、神兽与三大 Boss、酿造药水、节日活动与内置图鉴。A complete Eastern Dynasty mod: real-terrain dimensions, palace & mausoleum structures, Keju exam GUI, army formations, mythical beasts, bosses, brewing potions and festivals.
```

## 描述正文 / Description（可直接粘贴）

```
[h1]王朝 · Dynasty: Empire of the Dragon Throne[/h1]
[h2]一个内容完整的东方王朝模组（不是简化版）[/h2]

[h3]✦ 两个真实地形维度[/h3]
[list]
[*][b]天朝·龙庭[/b]：原版级噪声地形（大陆、山脉、峡谷、含水层），地表以汉白玉为基，海平面 63，天光明亮却妖魔横行。
[*][b]地府[/b]：黑石地底、y=32 以下岩浆海、天顶封闭、永无天日。
[*]共 6 个自定义生物群系：天朝平原 / 玉林 / 龙脊山脉 / 碧海云海 / 幽冥荒原 / 忘川河畔。
[*]玉矿与龙晶矿可在两种维度中开采。
[/list]

[h3]✦ 宏伟建筑（真正的世界生成结构）[/h3]
[list]
[*][b]皇家宫殿[/b] 48×48：三层台基、带垛口城墙、四座角楼、太和殿（重檐屋顶 / 金柱 / 龙椅 / 匾额）、御花园、廊庑宫灯与宝箱。
[*][b]帝陵地宫[/b]：墓道、东西耳室、主墓室、棺椁与陪葬宝物。
[*]支持 [code]/locate structure examplemod:palace[/code] 与 [code]/locate structure examplemod:imperial_tomb[/code]。
[/list]

[h3]✦ 科举 GUI 与王朝数值[/h3]
[list]
[*]右键【科举试卷】或 [code]/dynasty keju[/code] 打开答题界面（三选一）。
[*]12 级官阶：布衣 → 童生 → 秀才 → 举人 → 贡士 → 进士 → 翰林 → 侍郎 → 尚书 → 大学士 → 丞相 → 摄政王。
[*]功名 / 忠诚 / 叛乱 三套数值；叛乱爆表会引发叛军起义。
[/list]

[h3]✦ 军队与阵型[/h3]
[list]
[*][code]/dynasty army formation <square|wedge|crane|line|circle> [数量][/code]
[*]方阵、锋矢阵、雁行阵、横阵、圆阵；禁军会跟随、作战并传送归队。
[/list]

[h3]✦ 生物与 Boss[/h3]
[list]
[*]大臣（可对话赠民心）、刺客（隐身毒击）、弓兵（远程）、锦衣卫（重甲）、叛军、年兽（怕爆竹）。
[*]神兽：麒麟、凤凰、九尾狐（各有掉落材料）。
[*]Boss：龙帝（400 血 / 龙息火球 / 召唤禁军）、叛将（冲锋 / 召叛军）、宦官首脑（失明虚弱 / 放刺客）、亡故始皇（三阶段）。
[/list]

[h3]✦ 药水、丹药与美食[/h3]
[list]
[*]酿造台药水：龙威 / 铁壁 / 疾风 / 威慑 / 民心 / 天命（含喷溅、滞留）。
[*]丹药与食物：长寿丹、凝神丹、金创药、月饼、饺子、糖葫芦、龙须糖、火锅、茶、酒、仙桃。
[/list]

[h3]✦ 现实节日活动[/h3]
[list]
[*]春节（2/1–2/20，烟花与年兽）、端午（6/1–6/10）、中秋（9/15–9/25，玉兔）、重阳（10/1–10/10）、除夕（12/31–1/2）。
[*]也可用 [code]/dynasty festival <id>[/code] 手动触发。
[/list]

[h3]✦ 内置图鉴[/h3]
[list]
[*]《王朝图鉴》12 页内置指南，[b]无需 Patchouli 等前置[/b]。
[/list]

[h3]✦ 安装[/h3]
[list]
[*]Minecraft 1.20.1 + Forge 47.x，把 jar 丢进 mods 文件夹即可，无前置依赖。
[/list]
```
