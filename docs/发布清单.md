# 发布清单：什么格式发到哪个网站

导出位置：`~/Desktop/导出/`（IDEA 里跑 **③ 导出 Dynasty 整合包** / **② 导出 Dynasty 模组** 就会生成，或双击桌面 `3-打包整合包.command`）

| 文件 | 大小 | 格式说明 | 能发到哪 |
| --- | --- | --- | --- |
| `Dynasty整合包/dynasty-modpack-1.4.0.zip` | 12M | **CurseForge 整合包格式**：`manifest.json` + `overrides/`，模组由启动器按 CF 项目/文件 ID 自动下载 | **CurseForge**（新建项目→类型选 **Modpack**）；也兼容 **Prism / MultiMC / ATLauncher / HMCL / PCL2**（都能导入 CF 整合包） |

| `Dynasty模组/dynasty-1.4.0.jar` | 668K | **单个模组 jar**（本体） | **CurseForge**（类型选 **Mod**）、**Modrinth**（类型 **Mod**）、**MCMOD (mcmod.cn)** 收录、**9Minecraft**、苦力怕论坛、GitHub Releases、网盘 |

## 推荐发布顺序（重要）

1. **先把本体发成"模组"**（CurseForge / Modrinth 类型选 Mod）
   * 上传 `Dynasty模组/dynasty-1.4.0.jar`
   * 填：名称 `Dynasty 王朝`、简介、1.20.1、Forge、许可证（`mods.toml` 里目前是 All Rights Reserved，可改成 MIT/ARR 随你）
   * 通过后记下项目的 **projectID / slug**（例如 `dynasty-xxxxx`）
2. **再发整合包**（类型选 Modpack）
   * CurseForge 上传 `dynasty-modpack-1.4.0.zip`；Modrinth 上传 `dynasty-1.4.0.mrpack`
   * **审核常见要求**：整合包里我们的本体应改为"引用"而不是内嵌在 `overrides/`。把上一步的 projectID 告诉我，我把 manifest/index 改成引用形式重新出包（一次性改动）。
3. 第三方模组全部是公开发布的开源模组（Curios=LGPL-3.0、JEI=MIT、Overflowing Bars、Puzzles Lib），已用官方 ID 引用，属于正常整合包用法；请在你的项目简介里**保留署名**（我已在 `modpack/README.md` 列出作者与链接）。

## 各平台入口

| 平台 | 地址 | 上传什么 | 备注 |
| --- | --- | --- | --- |
| CurseForge | curseforge.com → Create Project → **Minecraft → Modpack / Mod** | CF zip / 模组 jar | 全球最大，启动器自动安装；审核 1–3 天 |
| Modrinth | modrinth.com → Create a project → **Modpack / Mod** | .mrpack / 模组 jar | 界面新、审核很快，支持自动下载 |
| MCMOD | mcmod.cn | 模组条目 | 国内最大模组百科；需要编辑权限或找编辑者添加，附上 CurseForge/Modrinth 链接 |
| 苦力怕论坛 | klpbbs.com | 帖子 + 网盘 / 附件 | 国内玩家社区，适合发"整合包分享帖" |
| GitHub Releases | github.com/gyhchang-cell/dynasty → Releases → Draft a new release | manual zip / mrpack / jar | 免费直链，适合当备用的官方下载点 |
| B 站 | bilibili.com | 视频 + 简介放网盘链接 | 国内最有效的推广方式（录一段玩法视频） |
| 网盘 | 百度 / 蓝奏 / 夸克 / 123 | manual zip | 记住设密码、写清"1.20.1 + Forge 47.4.x" |

## 上传前自测（1 分钟）

1. 用 **Prism/HMCL** 导入 `dynasty-modpack-1.4.0.zip`（或 `.mrpack`）→ 能进游戏 = 包没问题。
2. 或者把 `manual.zip` 解压，29 个 jar 丢进 1.20.1 + Forge 实例 → 能进游戏。
3. 进游戏后确认：收到《王朝说明书》，打开 Curios 面板能看到饰品槽，右键「任务书」能看到六个王朝任务章节。
