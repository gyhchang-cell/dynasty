# 第17批：小型岗亭尺度与高低变体

固定本地TREK中实际查看4份未读塔体的4幅整体图和4幅选层细节图，记录布局、比例、立面、屋盖、材料、门梯及地脚。另生成的通用平面／纵剖未作为已看图登记。**本批有效新增0，原三个范围仍4/7/1，各自目标1000，不允许制作。**

| 模板 | 本体尺寸 | 结论 |
| --- | --- | --- |
| F01 forest | 9×17×9 | 小石岗；主要顶台到y11，细旗不算室层，尺度不入原范围 |
| F02 medium | 11×22×11 | 小木岗；旗高不能膨胀驻守空间，不入原范围 |
| F03 mangrove_1 | 12×12×11 | 低岗屋加侧台；不另建用途账本凑数 |
| F04 mangrove_2 | 12×23×11 | 延长同轴梯／柱筒的高型；与F03同族，仍不入原范围 |

F03的原y3..6下室／侧台带向下平移1格，与F04的y2..5比，共168处非空气位置完全对应，167处方块名和属性一致；唯一差别是一个jigsaw朝向。此结论仅覆盖明确的4层下段，不是说整栋相同；高段仍有真实差异。尺度排除独立成立，不靠相似度自动算例。

4份与197个既有归档／成员身份做原SHA及四向分类／占位筛查，无精确匹配。197包含其他批已入索引但不一定已看过的候选、HOLD与组件，不是197个有效建筑，更不是本批新阅读数。近邻分数没有当新布局证明。

门位与梯换面逐栋保留。外围路径板、演员接口只读单级池定义，不拼装、不加例。旧两项011-F04、012-F03沿第16批证据继续HOLD，本批没有重新审它们，也没有另一个独立审阅者。
