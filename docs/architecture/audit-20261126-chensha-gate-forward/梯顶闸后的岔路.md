# 沉沙玄宫梯顶闸后的岔路

从梯顶闸内的中线脚格 **(32,25,53)** 起算。坐标相对结构原点，东为 X 增加，南为 Z 增加。玩家从下层上来穿闸后面向南。本文只核对闸后的中层路线。[上一段路线和开闸条件](../audit-20261126-chensha-stair-gate/回程闸与石碑.md)

## 去北部金吾玄室

出闸直走六格到 **(32,25,59)**，左转穿东侧门，门在 **X=39、Z=59–60**。保持在侧桥中间，抵达东耳室内的 **(47,25,59)**。向北走到 **(47,25,53)**，从水渠北侧的干石沿向东到 **(51,25,53)**，再向北通过这一列房间之间的桥。到东北玄室后向西过横桥，入北部中央的大房间。金吾设在桥另一端的室内落脚区 **(32,25,42)**。已验走法共 65 格，全程脚格 Y=25。转弯受墙柱影响，逐格路线见核验数据。东侧门须已放开，金吾实机出现还须满足入口三封印、同一结构实例的核心有效、难度和刷怪条件，并且该守卫未被清除。[逐格坐标](gate-forward-readback.json) · [守卫位置及准入](../../../src/main/java/com/dynasty/dungeon/ChenshaGarrisons.java#L27-L68)

在岔口向东过桥时，**X=41–42** 的桥面只在 **Z=58–61**。紧挨的北侧 **Z=57** 和南侧 **Z=62** 可落到脚格 **Y=19**，落差 6 格。西侧桥在 **X=21–22** 有同样的落差。底面是淡蓝玻璃，对应中层水银接触范围。逐格核对确认从这些底格无法沿普通干地步行回到桥面。可在任务书提示走桥面中央，进耳室后再向北转。向北回头过梯顶闸会沿原阶下行到下层。求近路时也不要从侧桥提早左拐。

## 去东南工匠室

过闸后沿水银房中线向南，穿 **Z=67** 的南侧试炼入口，走到南部桥交叉口 **(32,25,80)** 再左转向东。沿东南房间的西、南内侧绕到有瀑光的裂纹石砖。裂砖在 **X=51–53、Y=25–27、Z=87**。入口前淡蓝玻璃在 **X=50–53、Z=85–86**，踩上可能受水银影响。可以沿玻璃外缘走到东侧干石 **(54,25,86)**，从东端破出两格高通口，再经 **(53,25,86)** 直入。这条路径只踏过一格玻璃，破墙前查清身后空地。补给箱在 **(52,25,91)**，箱北有脚格 **(52,25,89)**。沿室内北边绕白骨装饰，到工作台西侧脚格 **(54,25,91)**，工作台在 **(55,25,91)**。[裂砖、地面和家具](../../../src/main/java/com/dynasty/dungeon/ChenshaPiece.java) · [玻璃接触和瀑光](../../../src/main/java/com/dynasty/dungeon/ChenshaEnvironment.java#L23-L54)

## 任务书候选文案

> 回程阶梯出闸后先朝前走。去北部金吾玄室，在水银房两侧开门处左转过桥。走桥面中央，进东耳室后再左转，沿水渠北侧干石绕到北排。过北侧横桥后进宽敞玄室，留在室内交战。桥边跌入水银渠后无法原地走回桥面。
>
> 去工匠室则直穿水银房南门。到南部横桥再左转进入东南耳室，找瀑光后的裂纹石砖。沿玻璃外缘靠近，从东端用镐破出两格高通口，尽快穿过。进屋先沿北边绕开白骨，补给箱在左近，工作台在东侧。
