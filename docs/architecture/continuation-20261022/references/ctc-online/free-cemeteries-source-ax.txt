			58 text 簡介
		59 text 東華三院創辦初期，不僅為市民解決醫藥、教育及福利問題，更兼顧留醫死後蕭條先友，除設有施棺贈殮服務外，早期更顧及無地下葬之先友，設置義山多處。總括而言，東華義山可包括下列五項：
		60 text 1. 在東華醫院建院時，掘出之骸骨。
		61 text 2. 興建東華義莊時掘出之骸骨。
		62 text 3. 逝世後將產業捐與東華之善士。
		63 text 4. 因天災或浩劫而致遺骸無人認領者。
		64 text 5. 協助政府發展市區計劃，收回墳地，而將無人認領之墓塚遷葬。
		65 heading 馬場先難友墳場, Value: 4
			66 text 馬場先難友墳場
		67 text 位於掃桿埔正民村山頂，1918年2月26日，跑馬地馬場失火，造成浩劫，逃生不及而葬身火海者，不可勝數。當年主席唐溢川先生。遂請政府撥出上址安葬此批遺骸，命名為「馬場先難友墳場」。2015年10月23日，政府宣布將「馬場先難友紀念碑」列為法定古蹟並於同日刊憲。
		68 heading 新舊雞籠環義山, Value: 4
			69 text 新舊雞籠環義山
		70 text 1951年，政府為發展公共房屋建設計劃，收回雞籠環墳場土地，改建為『華富邨』；昔日雞籠環義山之骨殖(包括1874年風災先友)，亦被遷葬於和合石墓園義山。此外，該義山亦包括1874年風災先友。
		71 heading 西安墓園, Value: 4
			72 text 西安墓園
		73 text 安葬1947年西安號客輪失火98名死難者，1959年遷移至和合石墓園。
		74 heading 牛房義山, Value: 4
			75 text 牛房義山
		76 text 始於1869年，為最早期義山，原位於香港西環，安葬興建東華醫院時所掘出骸骨。1983年因政府收回土地，奉移至和合石墓園內。
		77 heading 大口環義山, Value: 4
			78 text 大口環義山
		79 text 位於東華義莊對面山腳，設置於1899年，為興建義莊時所發現之骨殖。1992年遷葬和合石墓園內。
		80 heading 義灰塜, Value: 4
			81 text 義灰塜
		82 text 歷年來於東華殯儀館辦理殯殮服務後而未被領取骨灰者，於1997年起移葬於和合石墓地內。
