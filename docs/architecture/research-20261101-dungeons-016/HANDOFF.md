# 第十六批：守望塔本体与设计族复核

固定本地TREK来源实际研究5份新模板、20幅整体／平剖／细节图；另为旧两项待查及四个旧对照制作并查看6幅补剖，重看14幅历史整体图。**有效独立布局新增1例，DUN03小占地独立守望塔由6/1000变为7/1000，缺993，仍禁止制作。** 驻防堡／营院4/1000、连厅守望楼1/1000保持不变，不跨范围借数。

F02/F03/F04各有870处被指定规则选中的柱、板、阶、墙、栏等结构位置。逐对占位相似约98.86%、99.54%、99.31%，梯原状态一致；保留全部差异位置与柱轴等属性，未宣称模板全字节一致。这个指标只测明确列出的类别，**不能称全建筑有99.5%一致**，也不能单靠比例自动判独立。结合实际整体、台面平面、剖面及同轴梯组织，三者最多同族一例。

新五份与188个既有archive/member身份做原始SHA和四向旋转分类／占位筛查，无精确匹配；身份中含组件和HOLD，188不是有效建筑数。本次发现F05与旧taiga近同族，说明无精确几何匹配、作者或包名不同都不能代替语义去重。几何最近的008-F04实际是低壳矿屋／凹工位，也不能用分数当守望塔同族结论。

旧011-F04、012-F03继续HOLD，计数均0。补剖已改取实际室层：中心柱组比较下室／上室围护及柱梯关系（包括014-F02的y23上室），端塔长厅组比较厅内平层、重复柱窗及塔厅顺接。保留楼层高度、围护尺寸及塔帽差异，仍未证明超出同一叠室塔或端塔长厅原型的尺度／屋盖变体。后续需逐层补全入口、隔墙开口与平台／塔厅间的邻接关系；整方块分类剖面不认证原生碰撞和完整通路。六幅旧建筑补剖不增加建筑例数。

这5份处于TREK对minecraft命名空间的覆盖资源中，来源为固定TREK Jar，不宣称是原版独立作品。每塔4个外部feature_plates接口的三种实际组件仅含路径方块、空气与进一步接口；另三种1×3×1组件各是单实体。六组件均未拼装、未看作新建筑，外围营地生成也未验。完整性验收只覆盖模板内的完整塔本体；源无大屋盖的开敞架塔按现存原貌研究，不补想恢复。

可用原则：先按围室、开台、轴线和承托关系识别设计族，再比较屋盖与材质；把留空、细旗、屋内空腔从实用层高判断中分开；梯位换面、单长梯和侧室转接分别记录，不能据梯数认证全程可走；完整塔和未拼装外围路径／营地不混计。
