# 第19批：围院堡与完整性待查的残塔

固定本地Terralith实际研究2份模板：各查看整体、通用平面、通用纵剖、选层细节，合8幅新图；另重看7幅历史整体图。**接纳019-F01整个围院堡1例，中型驻防堡／营院由4变5/1000，缺995；守望塔7/1000、连厅守望楼1/1000不变。**

F01为31×30×31方形四边围院，四角低塔和单侧中部高塔，内院留空、边带低棚与墙上平台分开。西侧四处门的原坐标与朝向保留；高塔内梯位于(28,15)y10..22。与旧010-F01破碎围院、F02叠台堡、F03中央长屋高篱院、F05高长厅横向低翼实际比较，主体平面和高低关系不同，不是换屋盖／材质或旋转。只算整个设计，不拆五塔加例。

来源归档的`village/desert/starts`精确选中这一完整本体。10个外接接口是5道路、4居民、1铁傀儡；只查单级JSON，未装配外村落、未运行处理器、未认证地形和原生路线。本体中的院、墙、房、塔已实际查看，不把完整本体误说成完整生成村落。

F02为23×27×23保存盒中的残石塔，实际y0..25，最高三层各仅1格残柱。无普通门／梯、完整屋盖、连续层板证据；归档JSON未见精确选择本体的记录。没有jigsaw不能单独证明它是完整相关建筑。保留`HOLD_COMPLETE_RELEVANT_BUILDING_EVIDENCE`，计0，不虚构修复原貌。已对照006-F04房屋、012-F01带长外梯废塔和013-F01多室塔，不凭外观不同就加例。
