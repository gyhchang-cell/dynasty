Dynasty 王朝｜中国历史与神话冒险整合包

Minecraft 1.20.1 · Forge 47.4.10 · Java 17

沿主线探索遗迹与异界，挑战龙帝、九霄天将和东海龙王等 Boss；也可以发展装备、炼丹配装、参加科举，或用虎符招募与指挥军队。

当前内容

- 任务引导：主线、支线及剑、弓、防御、道门四条战斗路线。
- 装备成长：原创武器与护甲，武器进化、锻造及 Curios 饰品配装。
- 探索与战斗：特色建筑、维度、生物与 Boss；结构罗盘和生物罗盘帮助寻找目标。
- 炼丹与生活：丹药、药水、食物、货币、科举和 NPC 服务。
- 虎符军队：招募兵员、自由安排一套军阵，并进行出阵、收阵和转向。
- 便利功能：JEI 配方与来源查询、地图、连锁采掘，以及性能优化模组。

近期更新

更新物品美术与品质边框，简化任务说明、饰品来源与药水属性介绍；修正名称和检索、木质配方、回血、缺失贴图及生命上限显示。虎符界面采用原版风格。导出流程新增严格检查，避免检查失败后仍生成发布包。

安装与更新

下载最新 MRPACK，使用支持该格式的启动器导入。任务与教程以中文为主，物品提供中英文名称。更新前备份存档；整合包仍在持续开发。
