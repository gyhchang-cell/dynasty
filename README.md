# 王朝 · Dynasty: Empire of the Dragon Throne

> Minecraft **1.20.1** · **Forge 47.x** · 完整东方王朝模组（不是简化版）

一个内容完整的中国王朝主题模组：两个**真实生成地形**的自定义维度、六个自定义生物群系、可 `/locate` 的**宏伟宫殿与帝陵结构**、**科举 GUI** 与官阶数值系统、**军队阵型**、十一种新生物与四个 Boss、**酿造台定制药水**、**现实节日**活动与**内置图鉴**。

---

> **本次更新（1.4.0 平衡重制）**：修复饰品槽打不开、武器从木矛 5 伤害起步并加入「Boss 信物」条件、护甲进化链与数值上调、5 种新建筑、物品名下一行简介、整合包新增 11 个优化/便利模组。详见 [`docs/更新日志-1.4.0.md`](docs/更新日志-1.4.0.md)。

## 内容总览

### 世界与维度
| 内容 | 说明 |
| --- | --- |
| **天朝·龙庭** | 使用原版级噪声地形生成器（大陆、山脉、洞穴、含水层）。默认石为 `汉白玉`，海平面 63，天光常亮但怪物白天也会出没。 |
| **地府** | 下界式地形（黑石地底、y=32 以下岩浆海、天顶封闭、无天光）。 |
| 自定义群系 | 天朝：`天朝平原`/`玉林`/`龙脊山脉`/`碧海云海`；地府：`幽冥荒原`/`忘川河畔` |
| 矿物 | 玉矿、龙晶矿（可在汉白玉与黑石中生成） |
| 入口 | `玉门`（jade portal）/ `冥门`（underworld portal） |

### 宏伟建筑（真实 worldgen 结构）
* **皇家宫殿**：48×48 宫殿群 —— 三层台基、带垛口的城墙、四座角楼、太和殿（重檐屋顶/金柱/龙椅/匾额）、御花园、廊庑宫灯、四处宝箱。支持 `/locate structure examplemod:palace`。
* **帝陵地宫**：地下墓道、东西耳室、主墓室、棺椁与陪葬宝箱。支持 `/locate structure examplemod:imperial_tomb`。

  * `dist/dynasty-modpack-1.4.0.zip` → 上传 **CurseForge**（项目类型选 Modpack）
  * `dist/dynasty-1.4.0.mrpack` → 上传 **Modrinth**（项目类型选 Modpack）
  * `dist/dynasty-1.4.0-manual.zip` → 发给朋友 / 服务端手动安装
  * 详细步骤见 [`docs/upload.md`](docs/upload.md)
* 详细说明见 [`modpack/README.md`](modpack/README.md)。

### 用 IDEA 跑得到吗？
详见 **[`docs/idea.md`](docs/idea.md)**（含常见报错对照表）。
* **开发本体**：可以。IDEA 打开 `~/Desktop/dynasty` → 等 Gradle 同步 → 右上角选 `runClient` 运行。Curios 只作为编译依赖；没有 Curios 时饰品效果依然生效（放副手/背包），但**槽位只由 Curios 提供**，启动日志会写 `Curios not present`。
* **想连 Curios / 血条模组一起在 IDEA 里跑**：不行（而且不要把它们的 jar 丢进 `run/mods/`）。它们都是 **Mixin 模组**，Mixin 目标名是 SRG 名称，而 Forge 开发环境用 official 映射，会 `Mixin apply failed ... f_19803_`——这是 Forge 开发环境的已知限制，与本模组无关。
* **真正玩整合包**：用启动器（PCL2 / HMCL / Prism / CurseForge），生产环境下 5 个模组同时生效。

### 兵器进化链（每把都有独门机制，Shift 悬停可见）
青铜剑 **1000** → 唐刀 **1000·攻速 2.8** → 环首刀 **1100·受击反击** → 官银剑 **1200** → 长枪 **1300·距离 +3** →
玉剑 **1500** → 巨阙重剑 **1700·击退+缓慢** → 破军战斧 **1750·破甲（无视一半士气减伤）** → 龙晶剑 **1900** → 方天画戟 **2048·横扫**
旁支：玉笛 **1450·范围虚弱**、龙吟弓（箭伤约三倍、穿透 3）、玉镐 2000、龙晶镐 2048。
每一级都是**合成升级**（前一把武器 + 材料），全部配方写在任务界面「图鉴」页里。

### 饰品系统（Curios 兼容）
* 饰品**只用 Curios 槽位**（不再有第二个存放界面）：本模组自带 `data/curios/tags/items/*.json` 标签（back / belt / body / bracelet / charm / curio / hands / head / necklace / ring 共 10 个标准槽 + 王朝饰品槽）+ 一个「王朝饰品」槽位定义（`data/curios/curios/slots/dynasty_trinket.json`），并通过 `data/dynasty/curios/entities/player.json` **在开局就把这 11 个槽全部给玩家**（每个标准槽至少 1 格、戒指 2 格，王朝饰品槽随官阶继续长）。
* 饰品**放在饰品槽、背包或 Curios 槽都生效**（同名饰品只算一次）。
* 每件都有独特意义：玉佩（减伤 8%）、玉璧（生命 +150）、金印（功名 +25%、回忠诚）、龙鳞护符（护甲 +12、抗击退）、凤羽翎（速度 +10%、缓降）、麒麟角坠（幸运 +3、回复）、狐尾坠（跳跃 II）、锦囊（水肺 + 夜视）、铜镜（每 30 秒净化负面）、司南（抗性 + 显示坐标）。

### 任务界面内置图鉴（来源 / 配方 / 妙用）
* 打开背包左上角「✦ 王朝任务」→「**图鉴**」页签：左侧 37 条物品列表（带图标），右侧显示
  **来源**（怎么获得）、**配方材料**（直接显示物品图标）、**妙用**（这把武器/饰品强在哪）。
* 同一份文案也用在 **Shift 悬停**提示里，两个入口数据一致（`DynastyCodex`）。

### 开局说明书
* 首次进入世界自动赠送 **王朝说明书**，并在聊天栏提示玩法与饰品槽位置。
* 说明书内含 16 页：开局路线、维度、建筑、科举、军队、神兽、Boss、节日、**数值一览、武器进化链、饰品、图鉴用法、开局 30 分钟路线** 等。

### 物品用法提示（Shift）
* 鼠标悬停任意王朝物品时只显示一行 `【按住 Shift 查看用法与数值】`，**按住 Shift** 后展开：
  * 用法说明（右键/左键能做什么，例如「虎符：右键打开调兵界面」）；
  * 数值（§c攻击力§7 / §b护甲§7 + 韧性 / §7耐久§7）；
  * §6套装加成§7（该件盔甲提供的减伤与生命）。
* 中英双语，随客户端语言自动切换。

### 大血量 HUD（不掉帧）
* 原版每 20 点生命画一行心，1000 血会画上百颗心（每帧上百个图标）→ 容易掉帧。
* 本模组在最大生命 > 80 时隐藏原版心形行，改为一条**紧凑血条 + 数值**，并在右侧显示 `护甲 / 减伤`，帧率不受影响。

### 王朝任务（遊历指南）
* 打开背包（E）后**左上角**会出现「✦ 王朝任务」按钮；也可右键`王朝手札`打开同一界面。
* 6 章 24 个任务，按顺序引导全部玩法：初入王朝 → 朝堂之路 → 军旅生涯 → 天朝·龙庭 → 地府幽冥 → 神兽与帝王。
* 任务状态分为 进行中 / 可领取 / 已完成，奖励为物品 + 功名；进度保存在玩家数据中，退出重进不丢失。
* 详见 [`docs/quests.md`](docs/quests.md)。

### 科举与王朝数值
* 右键`科举试卷`打开**答题 GUI**（三选一，聊天框不再接受答案）。
* **官阶** 12 级：布衣 → 童生 → 秀才 → 举人 → 贡士 → 进士 → 翰林 → 侍郎 → 尚书 → 大学士 → 丞相 → 摄政王。
* **功名 / 忠诚 / 叛乱** 三项数值，保存在玩家数据中；叛乱 ≥100 会引发**叛军起义**（含叛将）。
* 右键`玉玺`查看**王朝档案界面**（官阶 / 功名 / 忠诚 / 叛乱）。

### 军队
* 右键`虎符`打开**调兵界面**：选择 方阵 / 锋矢阵 / 雁行阵 / 横阵 / 圆阵 与人数（4–64），无需指令。
* 潜行右键`虎符`可对周围生物施加`威慑`。
* 禁军会跟随、战斗并在远离时传送归队；忠诚越高士气越高。

### 生物与 Boss
* 普通：`大臣`（可对话、赠予民心）、`刺客`（隐身毒击）、`弓兵`（远程射击）、`锦衣卫`（重甲）、`叛军`、`年兽`（怕爆竹）。
* 神兽：`麒麟`（可喂仙桃）、`凤凰`（飞行喷火）、`九尾狐`（受击瞬移）、`年兽`（怕爆竹）。
* 神兽与年兽使用**精细多部件模型**（128×128·胸腔/后躯/脖颈/口鼻/耳角/鬃毛/分段四肢/九尾/分层羽翼），并配有动效（摆尾、振翅、四足步态）。
* Boss：`龙帝`（400 血，龙息火球 + 召唤禁军）、`叛将`（冲锋 + 召叛军）、`宦官首脑`（失明/虚弱 + 放刺客）、`亡故始皇`（原有 Boss，三阶段）。
* 每种生物都有刷怪蛋、掉落表与中英文本地化。

### 药水、丹药与食物
* 酿造台药水：`龙威`/`铁壁`/`疾风`/`威慑`/`民心`/`天命`（含喷溅与滞留版本）。
* 丹药：长寿丹、凝神丹、金创药；食物：月饼、粽子/饺子、糖葫芦、龙须糖、火锅、茶、酒、仙桃。
* 新增美食：**粽子、汤圆、年糕、桂花糕、腊肉、烤鸭、长寿面、白酒**（附状态效果，均可合成）。

### 新增物品与工艺
* 材料：**生丝 → 丝绸 → 锦缎**、**竹简**、**徽墨 + 毛笔**、**铜镜**、**琉璃瓦**。
* 符箓（右键使用，消耗 1 张）：**御风符**（速度+缓降+跳跃）、**隐身符**、**回春符**、**火符**（掷出火球）、**雷符**（召来闪电）、**归乡符**（传回城郭）。
* 功能物品：**王朝手札**（任务）、**节令灯**（右键开启当令节日）、`虎符`、`玉玺`、`科举试卷` 均在生存中可合成。

## 命令速查（管理员 / 调试用）

正常游玩**完全不需要指令**：任务书、科举试卷、虎符、玉玺、节令灯、王朝图鉴都可在生存中合成并右键使用。以下指令仅供整合包作者或管理员调试。

```
/dynasty                  帮助
/dynasty keju             打开科举答题 GUI（也可右键科举试卷）
/dynasty answer <1-3>     界面外作答（权限 2，仅调试）
/dynasty stats            查看官阶 / 功名 / 忠诚 / 叛乱（也可右键玉玺）
/dynasty guide            获得一本《王朝图鉴》
/dynasty army formation <阵型> [1-64]
/dynasty army <1-10>      快速调兵
/dynasty rank <0-11>      设置官阶（权限 2）
/dynasty rebellion <±值>  调整叛乱值
/dynasty festival <id>    触发节日（权限 2）
/dynasty found            开国（获得天命与民心）
```

## 安装

1. 安装 **Minecraft 1.20.1** + **Forge 47.x**。
2. 将 `dynasty-1.0.0.jar` 放入 `.minecraft/mods/`。
3. 无需任何前置模组（完全独立运行）。

## 从源码构建

```bash
./gradlew build          # 产物：build/libs/dynasty-1.0.0.jar
./gradlew runClient      # 开发环境客户端
./gradlew runServer      # 开发环境服务端
```
